# 浮绘 FloatCanvas

<div align="center">

**简体中文** · [English](README.en.md)

</div>

Windows 屏幕标注工具。直接在桌面上绘画、贴图和调整对象，再切回下层应用操作，标注持续可见。

![浮绘 FloatCanvas 预览：透视网格、路线标注与浮动工具条](Docs/Images/floatcanvas-preview.png)

当前源码版本：**0.3.0**；已发布的版本与下载见 [Releases](https://github.com/yowynn/FloatCanvas/releases)，重要改动见[更新日志](CHANGELOG.md)，操作说明见[使用指南](Docs/User-Guide.md)。立牌与深度优先遮挡仍为默认关闭的实验性功能。

工具条分为灰色新建和红色扫把清空；新建按文件和修改状态确认，清空立即执行、可撤销且不入历史。绑定文件显示随折叠的文件名气泡；印章槽右键提供重命名、覆盖、删除和取消固定四项维护操作。

## 功能

- 自由画笔、荧光笔、直线、形状、文字、独立序号、符号和 Emoji；官方／自定义预设完整应用工具参数，旧预设缺少的新增参数使用默认值。每个工具的选中预设和修改后的参数跨重启保留，支持按默认尺寸单击创建形状。
- 导入 PNG、JPEG、BMP、GIF 和 WebP，可从文件、剪贴板或拖放贴图；GIF／动态 WebP 保留原数据并播放，对象可移动、旋转、缩放、编组和修改属性。图片与新截图支持沿可见像素轮廓向外描边，动图描边随帧更新。
- 两排对齐的工具条，工具和印章快捷键角标可统一显隐；可拖动、固定的工具参数板、属性与图层窗口。属性修改即时生效，支持数值输入、拖动微调和分段选项；颜色和参数拖动可取消，预设及色板管理与画布共用撤销／重做。
- 编辑状态与画布显隐独立；隐藏时仍可新增内容并只预览本轮操作，提交后显示完整画布，取消则保持隐藏。已有隐藏图层不会被误选或修改。
- “画布”是与画笔互斥的工具，单击或按 `C` 选中，蓝框表示当前工具，再次选择打开参数板。逻辑文档原点为左上角 (0,0)。非透视网格独立固定在参考屏幕中心交点，任意位置均可起拖缩放，包括图层像素上；开启透视后显示校准框和参考网格，九宫格钉点、原点与中央整体移动手柄各有独立职责。
- 独立的画布背景颜色与透明度、角点拖动或任意顺序四点透视定位、实线／虚线／点线网格和官方／个人画布预设。非透视使用单一“网格大小”，透视使用列数（横向）在前、行数（纵向）在后的数量设置。重置恢复普通文档1:1显示，按当前覆盖数在目标屏幕中心重建正方形网格。v8 工程保存钉点、固定默认参照与图层放置等设置，兼容读取 v1～v7。默认“贴面”随画布透视变形；实验性“立牌”先选等深线再绘制，面向屏幕并按落点远近缩放。
- 强透视允许天际线进入屏幕，网格与贴面止于安全边界；编辑时鼠标进入禁区会显示淡红色范围。调整松手后可取消、移回越界图层、明确删除，或保留原图层以便调回透视后恢复显示（慎用），整次一步撤销。
- 透视九宫格钉点默认左下角，支持奇数完整格；从固定默认参照和最终参数重新求解，切回相同参数不累积形变。可勾选“调整时锁定网格大小”，固定逻辑格长和钉点相位，使图层持续对齐原格线，四角自由拖动并自动显示精确小数覆盖数。显式修改非透视格长会建立新的参考框和格数，覆盖原透视形变。
- 在画布工具配置中勾选“启用透视画布”后，可开启“深度优先遮挡”：立牌按锚点远近与贴面交替合成，完全相同深度按图层顺序；底色和网格始终在对象下方，合成后统一应用整体不透明度。默认关闭，随画布和画布预设保存。
- 拖动移动时按住 `Shift`，沿本次拖动起点的画布水平／竖直轴约束；立牌主体移动锚点，中心手柄沿屏幕竖直调整高度，支持负高度和以中心为基准的角点缩放。
- 可从主菜单或托盘重新打开欢迎页；穿透模式默认显示较小、双手捧皇冠且无笔的浮动头像，支持点击绘画、双击显隐及独立开关。戴冠表示编辑，捧冠表示穿透；睁眼／闭眼表示画布显示／隐藏。
- 可编辑或合并为图片的印章库，支持搜索、连续滚动、拖动排序，以及按 `1`～`9`、`0` 排列的十格快捷栏；拖放或选槽点击即可固定。可编辑编组保留动图，重开库后盖出仍播放。
- 矩形、圆形与套索截图，矩形／圆形默认自由比例，按住 Shift 临时约束为 1:1；选区完成后将背景、背景＋画布或透明画布内容作为静像原位插入。贴面矩形／圆形选区跟随画布平面，套索沿屏幕圈选；立牌截图先选深度并保留屏幕像素外观。支持单图裁剪、实时模糊与马赛克及 PNG／JPEG 导出。新建画布与清空当前画布独立；清空可撤销并保留文件关联。历史自动过滤空白与重复版本，上限默认 60，可在设置调整。
- 自包含的可编辑 `.floatcanvas` 工程，可注册为 Windows 打开方式并交给已运行实例；文件名气泡的“还原改动”可重新载入上次保存的内容，并支持撤销。自动保存恢复数据，普通启动保持空白，按需手动恢复历史画布。可在设置中开启登录启动，默认关闭。
- 浅色／深色主题，新配置默认全部屏幕，也可选择仅主屏或具体屏幕；屏幕切换保留文档几何和撤销记录。
- 自动、增强、普通三种全屏覆盖模式，默认自动检测并在支持时使用增强覆盖。Windows 系统截图和 ShareX 全屏截图期间自动交接显示与输入，结束后恢复画布。
- 默认开启 GPU 优先：符合条件的滤镜场景交由 GPU 绘制，轻量画布使用 CPU 缓存；深度优先遮挡目前使用 CPU 合成。设置显示最近一帧实际后端和选择原因，GPU 不可用或失败时回退 CPU。
- 简体中文／英文界面，可自动跟随 Windows 显示语言。
- 应用内检查 GitHub Release；当前用户安装和 ZIP 版原地更新并重启，系统安装通过安装向导更新。

立牌开关默认关闭，只影响后续新建对象。不开启时保留原有工具流程；通用 Shift 移动约束和贴面截图选区修复单独生效。关闭透视会重置新建方式，但保留已有立牌数据。旧版应用不能读取新保存的 v8 工程；与旧版交换时请保留原文件。

动图需要来源提供原始文件或编码数据；只提供 PNG／Bitmap 的剪贴板来源只能得到静态图，浮绘不会联网追取原图。隐藏画布暂停刷新，穿透时继续播放；截图、导出及合并图片印章取当前静态帧，暂无动画导出或播放控制。

## 下载与使用

Windows x64 二进制包由仓库的 [Releases](https://github.com/yowynn/FloatCanvas/releases) 提供。已发布的 0.3.0 提供 ZIP；从下一次发布起，同一版本将同时提供以下两种无签名包，各附独立的 `.sha256` 校验文件：

- **安装版 `FloatCanvas-<version>-win-x64-Setup.exe`**：可选“仅为我安装”或“为所有用户安装”。首次默认当前用户，目录为 `%LOCALAPPDATA%\Programs\FloatCanvas`；所有用户安装默认使用 Program Files，需要管理员确认。更改系统安装目录时，请选择所有使用者都有读取和执行权限的目录。提供对应范围的开始菜单入口、Windows 卸载项和可选桌面快捷方式，不自动开启登录启动。
- **ZIP 版 `FloatCanvas-<version>-win-x64.zip`**：解压到当前用户可写的本地目录，保留全部文件，运行 `FloatCanvas.exe`，适合自行管理程序目录。

两种包使用相同的程序文件，不附带 .NET 运行时或调试符号文件（PDB）。同一用户默认共用 `%LOCALAPPDATA%\FloatCanvas` 中的资料；系统安装仍为每个用户分别保存资料。卸载默认保留资料，也可按账户和明确目录选择删除配置、预设、印章和历史；另存的作品及自定义资料目录保留。电脑已有兼容的 **.NET 10 Windows Desktop Runtime x64** 时可直接启动。也可按下文从源码构建；源代码检出不包含打包产物。

安装版提供简体中文和 English 界面，首次默认跟随 Windows 显示语言，也可手动选择。已有兼容运行时时直接跳过运行环境页；缺少时，点击“下载并安装 .NET”，安装器从微软下载正确的 x64 桌面运行时，校验后安装，并自动重新检测、继续。Windows 可能要求管理员确认，即使浮绘选择当前用户安装也是如此；不会自动重启电脑。失败时可重试或打开官方下载页。完成页默认勾选“启动浮绘”，可以取消。

ZIP 版缺少兼容运行时时，启动程序会显示 .NET 安装提示。点击 **Download** 前往微软官方下载页面，下载并运行 **Windows Desktop Runtime x64** 安装程序，完成后重新启动浮绘。也可从 [.NET 10 官方下载页](https://dotnet.microsoft.com/download/dotnet/10.0)选择该运行时；运行浮绘无需安装 SDK。

点击欢迎页底部的版本号打开“检查更新”；面板自动检查本项目的 GitHub Release，并始终提供[项目主页](https://github.com/yowynn/FloatCanvas)链接。当前用户安装和 ZIP 版使用官方 ZIP 原地更新、自动重启，安装版同时刷新卸载版本和文件清单。所有用户安装下载并校验新版 Setup，通过管理员确认后继续安装向导；浮绘会先保存当前画布，确认向导就绪后才退出。完成安装后，保留完成页的“启动浮绘”勾选并点击完成，即可用原用户身份恢复工作。默认只接收正式版本，可开启“接收预览版本更新”；没有更新时仍可查看当前版本日志。详见[更新说明](Docs/User-Guide.md#检查与安装更新)。

| 快捷键 | 操作 |
| --- | --- |
| `` Ctrl+` `` | 编辑／穿透切换；穿透时标注保留，下层应用可正常操作 |
| `` Ctrl+Shift+` `` | 隐藏画布／显示画布；保留当前编辑／穿透状态 |
| `Tab` | 编辑模式下展开／收起工具条；输入框、菜单和对话框保留自身按键行为 |
| `Esc` | 取消当前操作、关闭子面板或未固定面板；最后返回穿透 |
| `Ctrl+Z`／`Ctrl+Y`（或 `Ctrl+Shift+Z`） | 按顺序撤销／重做画布编辑及个人预设操作 |
| `Ctrl+S`／`Ctrl+O` | 保存／打开可编辑工程 |

单击工具条左侧应用图标延迟打开主菜单，右键立即打开；编辑和穿透模式下双击图标都切换画布显隐，拖动图标移动位置。按 `Tab` 或使用主菜单第一项“收起工具条／展开工具条”切换折叠状态，收起后仍可右键图标打开菜单。穿透图标的单击／右键只进入编辑，不打开主菜单。主菜单和系统托盘提供设置与退出入口；更多操作见[使用指南](Docs/User-Guide.md)。

工具键：`V` 选择、`E` 橡皮、`B` 自由画笔、`H` 荧光笔、`L` 直线、`R` 矩形、`O` 圆形、`T` 文字、`N` 序号、`S` 符号、`J` Emoji、`C` 画布。`A` 保留为箭头兼容键；`M` 打开“更多”，主键盘 `-` 打开印章库，`+` 保存选择为印章。输入文字时，字母用于正常输入。

## 语言与适用范围

在“主菜单 → 设置…”的“界面语言 / Language”中，可选择自动（`auto`）、简体中文（`zh-CN`）或 English（`en`），保存后重启生效。自动模式跟随 Windows 显示语言：中文系使用简体中文，其他语言使用英文。界面语言与标注内容、键盘布局和输入法相互独立。提供[中文指南](Docs/User-Guide.md)和[English guide](Docs/User-Guide.en.md)。

最低系统基线为 **Windows 10 1607（内部版本 14393）x64**，包含 LTSB 2016、LTSC 2019、LTSC 2021，亦面向 Windows 11 x64。需安装兼容的 .NET 10 Windows Desktop Runtime，并保持系统与运行时更新；微软官方支持范围还取决于具体系统版本、版本类型及生命周期。当前实测主要在 Windows 11，较早 Windows 10／LTSB／LTSC 尚待实机确认。新配置默认全部屏幕，可选择仅主屏；完整跨屏、混合 DPI 与双 4K 体验仍待完善。全屏应用的兼容性取决于具体应用和显示方式，不保证所有独占全屏场景。

全屏覆盖模式在“设置 → 性能与系统”中选择，重启生效。自动模式在当前检测、初始化或可恢复的运行故障时回退普通桌面窗口，保留画布与撤销记录；强制增强不做自动回退，普通模式不加载增强接口。启动遇到增强问题时，可先退出再用 `FloatCanvas.exe --desktop-mode` 打开设置。界面真正卡死时，输入释放仍需等待界面恢复，不能保证原地恢复；详见[启动与切换](Docs/User-Guide.md#启动与切换)。

**实时模糊与马赛克需要 Windows 10 2004（内部版本 19041）或更新版本。** 较早系统新建桌面滤镜区域时使用操作时的静态截图效果；冻结截图和图片效果仍可使用。打开含动态区域的旧工程时，较早系统以实色覆盖并提示，保留原对象以便在支持的系统继续编辑。

系统支持会话级窗口排除时，实时滤镜仅从浮绘自己的采集中排除界面，其他截图软件仍可捕获可见画布。较旧系统使用兼容采集，存在可见实时模糊或马赛克时，外部截图可能不包含画布；可使用浮绘内的导出保留完整合成，或删除、隐藏动态区域后再截图。Windows 自带截图的窗口识别仍有已知限制。

标注固定在屏幕坐标，不随网页滚动、游戏镜头或物体移动。HDR 色彩准确性、压感笔、触控、OCR、录屏、滚动截图、云同步和上传不在当前版本范围内。

透视校准需要在镜头变化后重新调整。高分辨率下的密集网格可能明显拖慢 CPU 绘制；可减少列数或行数，或关闭网格。

## 从源码构建

需要 Windows x64、.NET SDK 10.0.402（补丁版本由 `global.json` 解析），以及 Visual Studio / Build Tools 的“使用 C++ 的桌面开发”工作负载，包含 MSVC x64/x86 编译器和 Windows SDK。原生覆盖层与恢复启动器使用该工具链；仅安装 .NET SDK 不能完成构建。

可在 Visual Studio Installer 中勾选上述工作负载，或运行已下载的微软 Build Tools 安装器：

```powershell
./vs_BuildTools.exe --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended --passive --wait
```

默认测试包括不注入输入的原生输入契约检查；真实游戏与设备测试仍需单独执行。

```powershell
./scripts/Build.ps1
./scripts/Test.ps1
dotnet run --project src/FloatCanvas.App -c Release
```

生成不附带 .NET 运行时和 PDB 的 Windows Release 包，并检查解压启动；版本自动读取应用工程，运行检查需要已安装兼容的桌面运行时：

```powershell
./scripts/Publish.ps1
./scripts/Smoke-Package.ps1
./scripts/Publish-Installer.ps1 -ZipPath ./dist/FloatCanvas-0.3.0-win-x64.zip
```

安装包脚本从已验证的 ZIP 生成同目录下的 `-Setup.exe` 和 `.sha256`，自动获取固定版本的 Inno Setup 编译器，不需要代码签名证书。示例版本号应与本次构建一致。

可选跨盘输出：`./scripts/Publish.ps1 -OutputDirectory 'C:\FloatCanvas\dist' -ArtifactsPath 'C:\FloatCanvas\build'`；包和主要构建中间文件写入指定位置，少量发布依赖锁文件仍保留在源码的忽略目录 `obj` 中。

## 发布源码版本

推送到已启用 GitHub Actions 的仓库后，普通分支更新和 PR 会运行 CI。发布时，推送与应用工程 `Version` 一致的 `v<Version>` 标签，或手动运行发布工作流并选择已有标签；工作流会构建、测试、打包、检查解压启动，再创建同时附带 ZIP、EXE 安装包及各自 SHA-256 文件的 Release。两种包均不签名。仅修改版本号不会自动发布，已有 Release 和资产不会被覆盖。
