# 窗口与属性面板布局规范

## 窗口模式与标题

- 编辑模式打开的窗口只显示窗口名，例如“设置”“历史画布”“用户指南”；工具配置保留当前工具名称。
- 非编辑模式打开的窗口使用“浮绘·窗口名”，英文使用“FloatCanvas · Window name”。普通窗口不继承画布的置顶、原生所有者或输入策略，进入编辑前关闭。
- 设置与历史画布支持两种模式，标题按本次打开模式确定。欢迎和检查更新使用普通窗口。
- 标题统一由 `WindowTitles` 处理，移除旧资源中写死的产品前缀，再按模式添加；不要在各窗口手工拼接。
- 工具条、悬浮头像、拖拽影像和画布内文字输入属于交互基础设施；其中没有标题栏的表面不额外添加可见标题。

## 窗口内容边界

- 应用拥有的普通窗口、对话框和带标题弹出面板，内容区左右各留 **12 DIP**，不包含窗口自身的 1 DIP 边框。统一使用 `WindowLayout.ContentMargin`。
- 外边距放在滚动区域的外层；页脚按钮区使用同一条边界。垂直滚动条实际宽度为 **12 DIP**，仅在内容溢出时占用视口宽度。不要再用 `SystemParameters.VerticalScrollBarWidth` 预留一条空白。
- 顶部、底部间距按内容密度保留；卡片内边距、列表项内边距、图标自身留白，不作为窗口外边距计算。
- 素材/预设固定列数所需的滚动槽属于该列表内部。标题与新增按钮延伸至所在栏的右边界，不在窗口最右侧再预留一份滚动槽。
- 默认属性参数区宽 **440 DIP**；窗口缩小时允许控件自适应、组合属性换行、预设栏下移。窗口变宽时内容铺满可用空间，不用居中的最大宽度制造两侧额外空隙。

## 属性控件规范

- 属性名：12 DIP，普通字重；栏目名：13 DIP，半粗体。
- 数值、颜色、单行文本、下拉框编辑高度：34 DIP。
- 属性名列按窗口或独立面板共享：取当前名称所需宽度的最大值，并受面板上限约束，超出显示省略号。工具/属性/画布面板上限默认 96 DIP，软件设置每个分类上限 132 DIP；不是整个应用固定 96 DIP。列间距 8 DIP，右侧控件填满余宽；开关属性名可占满剩余宽度，开关靠右。
- 组合属性两个输入框等宽，中间固定 36 DIP。大小的链条按钮占用这条间隙；位置保持空白。
- 数值 A 拖动入口仅位于框内图标，名称保持被动；B 为直接输入，C 为底部有范围滑轨。滑轨两侧留白对称。
- 布尔属性统一拨动开关，宽高比使用链条状态按钮；下拉箭头区不画竖直分割线。
- Alpha 统一称为“不透明度”；数值标识采用统一线条图标，同一概念使用相同图标。

验证入口：`FloatCanvas.AppTests --window-spacing-only` 测量真实 WPF 布局边界及滚动溢出；`--numeric-controls-only <目录>` 检查组合控件、共享参数宽度，并输出中英文/明暗主题渲染。完整 AppTests 同时覆盖两组检查。
