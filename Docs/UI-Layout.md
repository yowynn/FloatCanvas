# 窗口与属性面板布局规范

## 共用组件入口

新增界面先使用下列入口。相同操作保留相同组件、尺寸、图标和状态表达，不在功能窗口里另写一套近似控件。

| 需求 | 入口 | 使用规则 |
| --- | --- | --- |
| 主题与基础控件 | `AppTheme` | 应用启动先应用主题；颜色使用 `Canvas*` 动态资源。普通 `Button`、`TextBox`、`ComboBox`、`ListBox` 等继承应用隐式样式；自定义同类 `Style` 时以现有样式为 `BasedOn`，避免退回系统模板。 |
| 窗口标题与外框 | `AppWindowChrome.Apply` / `ApplyDialog`、`WindowTitles` | 内容完成后应用共用外框；标题、帮助、页眉动作通过相应入口设置。窗口显示、关闭、模态结果交给 `SessionWindowCoordinator`，不自行拼接模式标题或用第二套模态循环。 |
| 内容边界 | `WindowLayout.ContentMargin` | 所有普通内容与页脚共享左右边界；顶部和底部可按内容密度传参。 |
| 属性面板 | `PropertyPanelLayout.Scope`、`PropertyLabel`、`Row`、`Pair` | 在窗口或独立表单建立标签共享域；用标准行放置编辑控件，用 `Pair` 放置位置/尺寸等双值。 |
| 数字 | `NumericValueField`、`NumericPropertyIcon` | 复用图标拖动、输入、滑轨及非法值/混合值处理；将字段的可编辑条件、预览和提交/取消事件接入所属编辑事务。 |
| 颜色 | `ColorField` | 复用色板、选色器、取色、混合值及手势；不要在功能面板中直接拼新的颜色输入。 |
| 启停与比例 | `BooleanRow`、`AspectRatioButton` | 布尔启停行使用右置开关；宽高比链条放在尺寸双值间，保留当前勾选或混合语义。 |
| 固定互斥状态 | `SegmentedChoice`、`SegmentedChoicePreviews` | 少量互斥状态优先分段；长列表或动态列表使用应用下拉。图示表达选项本身，不能让不同选项共享一个无关图示。 |
| 条件字段 | `PropertyChangeRegion` | 包裹实际改变的连续参数区，使用 `ReserveHighlightSpace` 保护滚动视口内的提示范围。 |

`AppTheme.EnsureDialogPalette` 供启动错误等独立对话框补足色板；它不替代应用初始化和基础控件样式。图片预览、键盘布局、裁剪等画布式编辑区可以自绘，但外围标签、参数、按钮和窗口仍使用共用组件。不要为了包住一个预览而引入应用未定义样式的默认 `GroupBox`；使用共用栏目标题和主题边框。

## 属性归属与复用

### 悬停提示与弹层

工具提示只属于当前有效的鼠标悬停，不因键盘焦点或点击后的焦点保留而出现。公共控件沿用 700 毫秒悬停延迟，关闭键盘焦点触发；显示前由 `TooltipLifecycle` 再次核对鼠标、可见性、连接状态及提示启用条件，迟到的请求不得复活旧提示。配置了 `ShowOnDisabled` 的控件仍可在悬停时解释禁用原因。

弹层、菜单和下拉框打开时，关闭并暂时抑制入口及其祖先的提示；弹层内部控件的悬停提示仍可用。常规弹层通过 `PopupHandle` 接入，增强覆盖层模板使用 `OverlayPopup`，菜单和下拉框由公共生命周期统一接入。关闭后释放抑制，不改写调用者的提示内容、启用绑定或键盘焦点。鼠标离开、入口隐藏或卸载、所属窗口失活及实际键鼠操作结束已有提示；WPF 的提示关闭请求必须同步关闭增强覆盖层提示。

### 编辑模式键盘与焦点

所有编辑窗口和属性浮层使用 `SessionKeyboardRouter` 与 `EditorShortcutPolicy` 分配按键，不以“整个控件属于输入控件”阻挡编辑快捷键。普通按钮、模式开关、分段选项、九宫格和收起的下拉框不消费 Space、Tab 或绘图命令；数值控件只保留数值调整键，列表只保留已有局部操作。真正的文字编辑、展开菜单及模态窗口分别拥有自己的按键。模态窗口经 `SessionWindowCoordinator` 进入，保证按住的 Space 被取消且不会在关闭后自动启动画布。

保留 WPF 焦点、捕获和辅助技术接口；不要在按钮按下期间清理焦点，也不要在点击后恢复先前文本框。使用 `WindowFocusLifecycle` 清理隐藏、禁用和卸载的输入目标。列表刷新通过 `TileCollection` 仅恢复仍有效的同一操作上下文。所有自定义样式必须取消 `FocusVisualStyle` 及单独的键盘焦点边框触发器；文本光标、选区、悬停、拖动、选中、错误和禁用状态保留。

工具参数控制以后创建的图层；图层属性修改当前选择。两者表达同一作者字段时应复用同一参数区和本地化资源，包括条件显隐、范围、布局、配色和撤销事务。创建时才有意义的配方（例如截图来源、下一个序号）不伪装成既有图层属性；运行时鼠标效果仍为全局工具状态。

默认图层名按实际类型和显示模式生成；优先保留用户命名。按键记录、键帽记录、实时键盘、窗口源应使用相应名称，不能统一回退为“元素”或“图片”。模式切换后未命名层的名称应同步反映当前模式。

画布显示方式是根级和组级常驻的两项互斥选择，使用 `SegmentedChoice`。独立画布的参数写入当前子工程预览配置；根工程画布的参数必须明确对应根工程，不能因为显示完整工程而把修改误写入草稿。外部源或共享草稿总览禁止修改宿主参数时，应通过现有反馈说明需切到独立画布，不能点击后无响应。颜色、数字和校准手势捕获当前编辑目标，目标变化时取消旧手势，避免迟到回调改到另一组或另一根。

## 窗口模式与标题

- 编辑模式打开的窗口只显示窗口名，例如“设置”“历史画布”“用户指南”；工具配置保留当前工具名称。
- 非编辑模式打开的窗口使用“浮绘·窗口名”，英文使用“FloatCanvas · Window name”。普通窗口不继承画布的置顶、原生所有者或输入策略，进入编辑前关闭。
- 设置与历史画布支持两种模式，标题按本次打开模式确定。欢迎和检查更新使用普通窗口。
- 标题统一由 `WindowTitles` 处理，移除旧资源中写死的产品前缀，再按模式添加；不要在各窗口手工拼接。
- 工具条、悬浮头像、拖拽影像和画布内文字输入属于交互基础设施；其中没有标题栏的表面不额外添加可见标题。

## 窗口内容边界

- 应用拥有的普通窗口、对话框和带标题弹出面板，内容区左右各留 **12 DIP**，不包含窗口自身的 1 DIP 边框。统一使用 `WindowLayout.ContentMargin`。
- 外边距放在滚动区域的外层；页脚按钮区使用同一条边界。垂直滚动条实际宽度为 **12 DIP**，仅在内容溢出时占用视口宽度。不要再用 `SystemParameters.VerticalScrollBarWidth` 预留一条空白。
- 使用条件变化提示的属性视口，可将外侧留白中的 10 DIP 纳入可绘制范围；属性内容仍沿用原有的 12 DIP 边界，高亮可伸入留白，滚动条不再额外加一份间距。
- 顶部、底部间距按内容密度保留；卡片内边距、列表项内边距、图标自身留白，不作为窗口外边距计算。
- 素材/预设固定列数所需的滚动槽属于该列表内部。标题与新增按钮延伸至所在栏的右边界，不在窗口最右侧再预留一份滚动槽。
- 默认属性参数区宽 **440 DIP**。工具配置、画布这类左右分栏窗口统一最小为 **640×420 DIP**，允许从默认大小适度缩小；属性栏与预设栏始终左右排列，不将预设下移。属性控件在栏内自适应，内容过长时纵向滚动。窗口变宽时内容铺满可用空间，不用居中的最大宽度制造两侧额外空隙。
- 主菜单和槽位右键等瞬时菜单高于所有一级编辑窗口，子菜单高于父菜单；提升菜单时不改变工具条与一级窗口的相对层级。一级窗口重排后仍应保留此顺序。
- 点击打开一级菜单后，同次鼠标事件不得把焦点同步回原工具条。右键按下打开菜单时，首次松开只结束打开手势；即使底边避让让菜单项出现在鼠标下，也不触发该菜单项。

工具条、悬浮入口、拖拽影像和画布内原位文字编辑器不属于普通内容窗口：它们的边界由按钮命中区或画布几何决定，不能加入额外表单外边距。系统文件选择器使用操作系统布局。

## 属性控件规范

- 属性名：12 DIP，普通字重；栏目名：13 DIP，半粗体。
- 常规属性的一单位高度为 34 DIP：按钮、数值、颜色、单行文本、下拉框及分段选项外框均使用这一高度。钉点九宫格为三单位（102 DIP），其中每个命中格为一单位；内容确需多行的编辑器、列表及预览不按单行控件压缩。
- 同一连续参数组内，控件外框之间的垂直间距为 8 DIP，由行上下各 4 DIP 统一提供。完整动作行沿用同一行距，不叠加组内外边距；章节和状态文字保持各自规范。
- 属性名列按窗口或独立面板共享：取当前名称所需宽度的最大值，并受面板上限约束，超出显示省略号。工具/属性/画布面板上限默认 96 DIP，软件设置每个分类上限 132 DIP；不是整个应用固定 96 DIP。列间距 8 DIP，右侧控件填满余宽；开关属性名可占满剩余宽度，开关靠右。
- 组合属性两个输入框等宽，中间固定 42 DIP，容纳 34 DIP 的属性图标按钮及左右各 4 DIP 留白。大小使用链条状态按钮；网格原点使用单次对齐按钮，常态有边框；没有中间动作时留空。窄窗口纵向排列后，仍保留 8 DIP 间距。
- 数值 A 拖动入口仅位于框内图标，名称保持被动；B 为直接输入，C 为底部有范围滑轨。滑轨两侧留白对称。
- 功能启停使用拨动开关，宽高比使用链条状态按钮；2～5 个固定、互斥且可命名/图示的状态优先使用 `SegmentedChoice`。字体、显示器等长列表或动态列表保留下拉菜单；下拉箭头区不画竖直分割线。
- Alpha 统一称为“不透明度”；数值标识采用统一线条图标，同一概念使用相同图标。

数值字段创建后设置 `SetScrubAnchor`，并为输入框与滑轨设置可访问名称。位置使用 X/Y，尺寸使用 Width/Height，不透明度使用 Opacity，旋转使用 Angle，描边/轨迹宽度使用 StrokeWidth，行列使用 Rows/Columns，半径与长度使用 Length；没有既定图标的数量、时长等使用 Number。单字段行用 `SetLabel` 关联实际标签，双字段用各自名称区分两个输入。可直接输入的字段也必须支持滑轨与图标拖动，不能仅更新其中一种交互的画面。

常规内容动作按钮最小高度使用 `PropertyPanelLayout.ControlHeight`（34 DIP）；取消与应用采用一致尺寸并保持完整文案。提交动作设置明确默认行为，取消设置 `IsCancel`，但输入控件先处理自己的 Enter/Esc。标题栏、工具条、面包屑导航及图层行内的图标命中区是专用紧凑表面，可保留28 DIP等既有尺寸，不把这些例外推广到表单操作；组上下文的导出、解除链接、完成和取消仍使用常规动作尺寸。

## 窄窗口、状态与可访问性

- 最小窗口尺寸必须由完整内容验证，不能只给 `MinWidth` / `MinHeight`。资源列表和预览应始终保留可用视口；较多的辅助动作、长路径或长错误状态使用受限的独立滚动区，不能将主要内容挤到零高度。固定页脚不能盖住滚动内容。
- 中文和英文、亮色与暗色均检查默认尺寸和最小尺寸。双值过窄时沿用 `Pair` 的堆叠逻辑，分段控件沿用自身响应布局；保持文字尺寸，不以缩小字体或裁掉按钮文案解决宽度问题。
- 正常说明、空结果、加载、不可用和失败分别表达。正常状态不重复页面顶部已有说明；选择或请求状态改变时同步清除旧错误。异步结果必须检查当前窗口、请求代次和编辑对象，关闭的窗口不重新发布选择。
- 操作按钮的显隐和禁用来自当前对象与权限条件；仅改变外观不能替代调用处的有效性检查。输入保留焦点时不被后台刷新覆盖，混合值不显示成错误，非法输入阻止应用并保留可读说明。
- 图标按钮、数值输入、选择器和自绘可操作元素有本地化的可访问名称；开关保留原生布尔语义，分段保留原生单选语义，比例链条保留切换语义。确认、取消、标题栏关闭和 Esc 应使用同一套草稿发布规则。

## 条件参数的变化提示

- 参数保持平级；不以常驻底色、边框、缩进或模式标签表示依赖关系。
- 用户切换开关后，布局立即采用新状态的高度，后续字段同步补位，不动画插值旧高度。仅在切换后可见的连续参数区域显示整体蓝色提示，提示在 1 秒内消退；全部隐藏时不保留提示或空白高度。开关本身不纳入其控制区域。
- 高亮左右各延伸 10 DIP，利用窗口已有外侧留白，文字和控件的对齐位置不变。滚动视口须为这部分绘制范围留出空间，不能切掉高亮。
- 初次展示、普通刷新和隐藏窗口中的同步不触发提示；关闭系统动画时保留短暂的静态提示。快速反复切换和隐藏窗口时清理旧动画。
- 画布的“画布类型”（平面/透视）、“显示网格”、校准的外框约束，以及工具/图层属性的“配色样式”（分离颜色/统一颜色）使用共享 `PropertyChangeRegion`，提示限于各自控制的字段。
- 工具窗口拉高后，两列内容仍从顶部排列，底部状态区保留在窗口底部。初始高度限制只用于内容自适应尺寸，不以面板最大高度使内容在手动调整后的窗口里居中。
- 鼠标演示总开关放在标题栏，复用两按钮宽的 `CaptionModeSwitch`。只控制演示效果运行，不影响参数章节的显示、可编辑性或布局；子功能开关仍控制各自配置的显隐。

## 分段单选控件

- 一个圆角容器内等分展示图示和名称；选中块约 160 ms 平移。每个选项使用原生 `RadioButton`，有明确的辅助技术名称；混合图层状态允许全部未选中。
- 普通参数高度为 34 DIP。窄窗口中可将属性名放到控件上方、图示放到名称上方，完整保留选项名称，不压缩字体或退回不可见的弹出选项。
- 应用位置：画布类型、配色样式、线型、文字对齐、箭头端点样式、截图形状/来源、贴面/立牌，以及软件设置的主题、语言、覆盖模式。显示网格、自动启动等仍为开关。
- 配色示意图随当前形状工具变化；界面更新名称和控件，不改变项目/预设中的 `LinkColors`、颜色值或枚举数据。设置仍在保存时应用，重启提示沿用原有逻辑。

## 当前根画布提示

- 图层窗口使用同一套 `SegmentedChoice` 选择前景、主、背景根，列表和面包屑只表达当前编辑范围；切根回到目标根顶层并清空选择。
- 非主画布状态使用 `RootCanvasToolbarHeader` 持续显示当前根及返回主画布入口，复用既有主题按钮、边框和返回图标。关闭图层窗口或收起工具条后仍能辨认当前根；主画布不增加提示或改变历史工具条尺寸。
- 根提示与 `BoundFileIndicator` 分列；文件名在剩余空间省略并保留完整路径提示和未保存标记，不能相互覆盖。提示刷新跟随正式工具条状态刷新，不能只在图层窗口点击时更新。
- 返回操作经统一根切换命令执行，显示时和点击时都检查当前编辑/事务/共享内容条件。中英、明暗、长文件名及收起状态沿用同一组件，不另做临时浮窗。

验证入口：`FloatCanvas.AppTests --window-spacing-only` 测量真实 WPF 布局边界及滚动溢出；`--numeric-controls-only <目录>` 检查组合控件、共享参数宽度；`--property-changes-only <目录>` 检查条件参数的整体提示、留白、快速切换及隐藏生命周期；`--segmented-choices-only <目录>` 检查分段选择、混合值、原生单选语义及中英文明暗主题的窄窗口排版，并输出渲染。完整 AppTests 同时覆盖这些检查。`--root-canvas-indicator-only` 另检查当前根提示、文件名、收起尺寸和生产命令接线。

功能窗口专项还包括 `--canvas-geometry-ui-only`、`--window-source-ui-only`、`--prefab-ui-only`、`--presentation-global-ui-only` 与 `--presentation-styles-ui-only`。隐藏窗口布局检查证明组件结构和排版；实际桌面中的点击、焦点、弹窗层级、屏幕缩放及多显示器行为仍需通过界面操作验收。
