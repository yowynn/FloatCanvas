# 浮绘 FloatCanvas 使用指南

简体中文 | [English](User-Guide.en.md)

本指南说明 Windows x64 当前源码的功能，包含尚未发布的改动；最新正式版为 **0.2.1**，发布情况见[更新日志](../CHANGELOG.md)。较早版本的界面和功能可能不同。建议将重要工作另存为工程文件。

在画布上按下鼠标开始绘制或移动后，整次拖动由画布处理；即使经过工具条或在按钮上松开，也不会触发按钮。从工具条上按下鼠标，则由工具条处理，不会在画布上留下笔迹。

界面支持自动跟随 Windows、简体中文和 English，可在设置中选择，保存后重启生效。

浮绘把标注和贴图留在屏幕上。进入编辑模式时绘制和调整；切换到穿透模式后，画面保留，可以继续点击、拖拽和滚动下层应用。

## 启动与切换

使用发行包时，解压对应版本的 Windows x64 ZIP，保留全部文件，运行其中的 `FloatCanvas.exe`。默认发行包不附带 .NET 运行时或调试符号文件（PDB）。电脑已有兼容的 **.NET 10 Windows Desktop Runtime x64** 时可直接启动。

若缺少兼容运行时，启动程序会显示 .NET 安装提示。点击 **Download** 打开微软官方下载页面，下载并运行 **Windows Desktop Runtime x64** 安装程序，安装后再次运行 `FloatCanvas.exe`。也可从 [.NET 10 官方下载页](https://dotnet.microsoft.com/download/dotnet/10.0)手动选择该运行时。无需 SDK；普通 .NET Runtime、ASP.NET Core Runtime 和 .NET Framework 不能替代所需的桌面运行时。

在**设置 → 性能与系统 → 全屏覆盖模式**中选择模式，保存后重启生效：

| 模式 | 行为 |
| --- | --- |
| 自动（默认） | 优先增强；本次检测或初始化失败时回退普通，可恢复的运行故障也可回退。 |
| 增强 | 直接增强，不做能力探测或自动回退；失败时直接报错。 |
| 普通 | 直接使用普通桌面窗口，不加载或检测增强接口。 |

自动模式每次启动重新检查当前接口能力；历史异常、诊断记录写入失败和探测超时不代表当前电脑不支持，探测超时后仍尝试实际初始化。自动模式运行中出现可恢复的输入接口故障时，会先释放输入，再以同一画布重建桌面界面，保留资源、文件绑定和撤销记录。也可从托盘选择“改用普通桌面模式”。普通模式保留绘画和文件功能，但可能无法覆盖部分全屏应用。

浮绘不会因绘制缓慢、界面长时间未响应或输入释放失败而主动结束进程；未响应应用的等待或关闭由 Windows 和用户处理。自动增强模式下，`Ctrl+Alt+Shift+F12` 请求正常释放输入；界面忙碌时，该请求会等待界面恢复处理，不会因此强制关闭浮绘。

打开 Windows 系统截图或 ShareX 全屏截图／编辑界面时，浮绘会退出编辑，让截图界面覆盖完整浮绘画面，避免实时画布继续叠在冻结截图和工具条影像上。截图期间不接管编辑输入，结束后恢复实时画布；重新编辑仍需点击浮动头像或使用编辑快捷键。自动交接仅支持这两个截图产品，普通设置和非全屏编辑窗口不触发。对其他先冻结画面的截图工具，可等选区界面出现后，再用画布显隐快捷键隐藏实时画布；截图完成或取消后，再按同一快捷键恢复显示。浮绘自身可见工具与画布的排序单独维护。

需要绕开增强接口时，先退出浮绘，再运行 `FloatCanvas.exe --desktop-mode`；它优先于保存的模式，也可用于强制增强启动失败后打开设置。`--retry-fullscreen` 为兼容旧命令保留，临时选择自动检测。两个参数不能同时使用，也不会修改保存的模式或画布数据。原生崩溃或卡死不能保证原地恢复，未保存内容可尝试从历史画布恢复。增强接口按实际可用性初始化，已验证的系统环境不代表所有 Windows 版本或全屏呈现方式都已通过验收。

1. 在欢迎界面选择“开始绘制”，或按 `` Ctrl+` `` 进入编辑。
2. 再按 `` Ctrl+` `` 返回穿透。工具条消失，标注仍显示，下层应用恢复操作。

每次正常启动在屏幕中央显示欢迎页，并使用空白画布，不自动展开上次的标注或截图。点击关闭、开始绘制或按切换快捷键进入绘制后，欢迎页关闭，本次启动不再自动显示。检测到历史记录时，欢迎页显示最近保存时间及“查看历史，继续上次工作”入口。也可单击工具条左侧应用图标，选择“文件 → 恢复历史画布…”，或使用托盘中的同名入口。打开历史列表会关闭欢迎页；双击条目与“恢复该版本”按钮效果相同。恢复成功后显示画布并进入绘制模式。

欢迎页用“绘制模式 / 穿透模式”和“隐藏画布 / 显示画布”说明两组快捷键，底部显示版本与带红色爱心的作者署名。隐藏画布不会清空内容。画布显隐与编辑／穿透独立，切换编辑不会自动显示已隐藏的内容；显示画布也不改变当前模式。隐藏时可调整画布或新增内容，操作中只预览本轮新内容，确认后自动显示完整画布；取消则保持隐藏。旧图层在隐藏期间不能被选中或移动。

标注在当前绘图范围内固定于屏幕位置，不会跟随网页滚动或游戏中的物体移动。

新配置的默认绘图范围为**全部屏幕**，也可选择**仅主屏**来限制标注和截图范围。已有保存的范围选择保持不变。切换到其他应用时，浮绘会进入穿透。

从“主菜单 → 设置…”打开设置，在“绘图范围”依次选择“全部屏幕”、“仅主屏”；连接多个屏幕时，分隔线下还列出“屏幕 1”、“屏幕 2”等具体屏幕，保存后立即生效，无需重启。启动参数 `--primary-screen` 或 `--all-screens` 可覆盖本次运行范围，不改变保存的偏好，二者不可同时使用；通过参数指定范围时，本次运行继续以该参数为准。屏幕连接变化会刷新已打开的范围列表；临时回退不会覆盖已保存或尚未保存的屏幕选择。具体屏幕按设备标识保存；断开时临时回退主屏，重新连接后恢复该屏幕。

选择具体屏幕时，画布以该屏幕中心为参考；“仅主屏”和“全部屏幕”以主屏中心为参考，不使用整个桌面的中心。切换范围或在另一屏幕打开工程时，内容按相对参考中心的位置显示：在屏幕 A 中心绘制的矩形，切到仅屏幕 B 后显示在 B 中心；从仅屏幕 B 切到全部屏幕后显示在主屏中心。对象的尺寸、几何和撤销记录不因屏幕切换而改写，编辑窗口的默认位置也遵循当前参考屏。完整混合 DPI 与物理热插拔体验仍待实机验收。仍完全落在当前范围外的对象，可用“主菜单 → 画布 → 将标注移回可见屏幕”找回。

编辑模式由浮绘接收普通窗口的键盘和鼠标消息；没有绑定工具的字母也不应发送给下层应用。切到其他应用会收起编辑工具并进入穿透，标注继续显示。进入编辑时若无法取得输入焦点，会保留穿透并提示原因。

浮绘内部窗口之间切换、完成重命名或关闭面板，不会退出编辑或收起工具条。单独关闭子面板时返回仍可用的父窗口；点击画布则同时收起相关临时子层和未固定面板，并正常处理这次画布操作。固定面板保留；重命名、删除确认等模态对话框需要先确认或取消，期间不能绘图。

退出编辑时仍打开的固定面板会在下次编辑时恢复。手动关闭工具配置或画布设置会重置固定；图层窗口始终按固定窗口处理。有关联的子窗口保持在来源窗口之上，同级面板按最近焦点排序。

从其他应用进入编辑时，会等待仍按下的键盘按键和鼠标按钮释放，再申请输入接管并显示工具条，避免下层应用残留按下状态。若已启用浮动头像，等待期间头像保持显示，工具条出现时再隐藏头像。

使用增强输入时，若超过 2 秒仍检测到按键按下，本次进入会取消，当前工程与撤销记录保留。托盘提示和浮动头像的悬停提示会列出相关按键；按下并释放这些键，再点击头像或使用编辑快捷键重试。该提示在成功进入编辑后清除。浮绘不会向其他应用模拟松键，也不会因此更改覆盖模式。

文字直接在画布上编辑；切换窗口、图层、工具或进入穿透时自动提交，文字保留在画布中。`Esc` 取消本次文字编辑。

| 快捷键 | 作用 |
| --- | --- |
| `` Ctrl+` `` | 编辑／穿透切换 |
| `` Ctrl+Shift+` `` | 隐藏画布／显示画布；保留当前编辑／穿透状态 |
| `Tab` | 编辑模式下展开／收起工具条；在输入框、菜单及对话框中不触发此命令 |
| `Esc` | 先取消当前操作或关闭颜色子面板，再关闭未固定面板，最后返回穿透 |
| `Ctrl+Z`／`Ctrl+Y` | 撤销／重做；`Ctrl+Shift+Z` 也可重做 |
| `Ctrl+A` | 全选可编辑元素 |
| `Ctrl+C`／`Ctrl+V` | 复制／粘贴 |
| `Ctrl+D` | 复制所选元素并略微错开 |
| `I`／`P` | 置入图片／选择截图工具 |
| `Ctrl+PageUp`／`Ctrl+PageDown` | 画布不透明度增加／减少 5%，支持长按 |
| `Ctrl+L`／`Ctrl+,`／`Ctrl+T` | 打开图层／设置／当前工具参数窗口；已打开时保持打开 |
| `Ctrl+G`／`Ctrl+Shift+G` | 编组／解组 |
| `1`～`9`、`0` | 选用十格快捷栏中对应的印章，再点击画布放置 |
| `M`／`-`／`+` | 更多工具／打开印章库／保存选择为印章；`-`、`+` 使用主键盘分区 |
| `Delete` | 删除所选未锁定元素 |
| 方向键／`Shift`＋方向键 | 所选元素移动 1／10 个文档像素 |
| `Ctrl+S`／`Ctrl+Shift+S` | 保存／另存当前工程 |
| `Ctrl+O` | 打开工程 |
| `Enter` | 为当前选中的一个或多个图层打开属性；文字编辑时保留完成输入的作用 |
| 按住鼠标中键 | 临时使用移动工具，松开后恢复原工具 |
| `Ctrl+N` | 新建画布；先归档当前内容，绑定工程按原流程询问保存 |
| `Ctrl+Backspace`／`Ctrl+Delete` | 清空当前画布，可一次撤销；文本输入框仍保留文字删除操作 |

按住 `Ctrl` 只会临时隐藏选框；松开后立即恢复，无需移动鼠标。复制保留原选择，粘贴和复制副本选中新图层。

快捷键随当前焦点分配：画布、工具条、属性、工具参数及画布设置的普通控件共用绘图命令；图层列表和印章库的方向键用于列表导航。文字框、下拉框、滑块和菜单保留自身输入、撤销、复制粘贴及删除操作；预设项的 Enter、F2、Delete 用于应用、重命名和删除预设。`Ctrl+S`／`Ctrl+O`／`Ctrl+N` 可从文字输入中执行，行内文字和图层重命名会先提交当前内容。印章库中的 `Ctrl+N` 仍用于保存选择为印章，`Ctrl+F` 搜索，Enter／F2／Delete 操作库中所选印章；Esc 先取消槽选择，再关闭库。设置、快捷键录制框和确认／文件对话框保留自己的操作。

工具、开窗、新建、保存和编组等命令每次按下只执行一次；方向键、删除及撤销／重做可长按重复。Alt／Win 系统组合不会被当作普通绘图快捷键。

从“主菜单 → 设置…”打开设置，可修改快捷键和浅色／深色主题。保存时检测到注册冲突会显示原因，原有效快捷键保留。部分组合可能先被系统或其他软件截获，导致录制框没有变化；遇到这种情况请换用其他组合。系统托盘也有编辑、显示、设置和退出入口。

“登录 Windows 时启动浮绘”默认关闭，勾选并保存后随当前用户登录启动，在托盘中等待，不自动进入编辑模式。取消勾选并保存即可关闭。

画布内容、透视网格和效果预览在独立线程绘制，选择框、透视手柄和控件响应保持在界面线程。预览忙碌时会跳过中间状态，完成后再读取最新值；松手后的最终值会保留。复杂画面允许延迟更新，操作框仍跟随当前操作。

简单与复杂画布共用这套后台机制。界面保留已经完成的内容，只传递变化的像素块并刷新受影响区域；仅移动或取消选择框不会重绘画布内容。动画时间信息和印章悬停预览也在后台准备。

设置中的“优先使用 GPU 加速”默认开启，已有配置也默认开启。动态模糊、马赛克和图片中的模糊／马赛克等滤镜会触发后台 GPU 路径；选用 GPU 时，这一帧的整幅画布（图形、文字、贴图和滤镜）都在 GPU 上绘制，并非只处理某个滤镜。普通标注、小型动图等轻量画布使用 CPU 缓存，减少额外的读回开销。界面合成已完成的预览像素和当前操作框。取消勾选则全部使用 CPU。保存后生效，无需重启；GPU 不可用或绘制失败时自动回退 CPU，切换不改变画布内容。

设置显示最近一帧实际后端、选择原因、可用 GPU 设备，以及最近绘制耗时和本次运行的 GPU／CPU 帧数。空闲时无需持续生成画布帧，查看状态也不会触发绘制。失败的详细原因可在 `diagnostics.log` 中查看。

GPU 绘制不代表整个程序只在 GPU 上执行：图片与动画解码、桌面采集的像素读回和最终窗口提交仍包含 CPU 工作；当前 GPU 画布也需要读回到窗口像素缓冲区。因此强制让轻量场景使用 GPU 未必更快，实际收益取决于设备与画布内容。

切换快捷键使用 Ctrl／Alt／Shift 组合；Win 和系统离开组合保留给 Windows。单纯按下 Win 不会立即退出编辑，`Win+空格` 可在编辑控件或保存文件名时切换输入法；实际打开开始菜单或切换到其他应用时仍释放输入。`Ctrl+Alt+Esc` 保留为紧急释放输入。界面无响应或输入接管中断时会回到穿透，不会向下层重放先前的绘图按键。

欢迎页关闭后，可从“主菜单 → 帮助 → 打开欢迎页面”或托盘菜单重新打开。在编辑模式中选择此项，会先退出编辑，再将欢迎页带到前台；进入编辑时会关闭欢迎页。点击左下版本号检查更新，点击右下署名打开 GitHub 项目主页。

## 设置与浮动图标

设置按“常规与外观”“画布与历史”“快捷键”“性能与系统”分类，右侧内容独立滚动，底部始终保留取消和保存。取消会丢弃本次设置草稿；无效的历史上限会切换到对应分类并提示。系统集成操作只在明确点击相应按钮时执行。

“显示浮动图标”默认开启，可从主菜单、托盘菜单或“设置 → 常规与外观”切换。穿透模式下，单击图标等待双击判定后进入绘画，右键立即进入绘画；两者都不会打开主菜单。双击与编辑模式一致，只切换画布显隐并同步睁眼／闭眼，保留当前模式和工具条折叠状态。显示或拖动图标不会抢走当前应用焦点。

穿透图标缩小为编辑头像的 75%，并带有“穿透”标识；工具条收起后，仍可通过大小与标识区分两种模式。标识只说明当前状态，不是按钮；睁眼／闭眼只表示画布显示／隐藏。

拖动图标可调整位置，位置在本次运行中保留。轻微抖动仍按单击或双击处理。

编辑模式下，右键按下头像立即打开主菜单。菜单已展开时，左键按下头像立即关闭菜单；这次按压仍可继续组成双击以切换画布显隐，或越过拖动阈值开始移动工具条。单击关闭菜单后不会再延迟重开。

## 检查与安装更新

点击欢迎页左下角的版本号打开“检查更新”。打开面板后会自动检查[浮绘 GitHub Release](https://github.com/yowynn/FloatCanvas/releases)，显示当前版本、可用的新版本和更新说明；点击“重新检查”可再次获取。面板底部始终保留[项目主页](https://github.com/yowynn/FloatCanvas)链接。

存在可用更新时，点击“立即更新”。应用显示下载进度，校验下载的文件，并在保存当前画布的恢复数据后退出、替换程序，再自动重启并恢复工作。设置、预设和画布数据保留。下载期间可以取消或关闭面板，继续使用当前版本；下载或校验失败不会替换程序，替换失败时会尝试恢复原版本并说明原因。

应用内安装更新适用于完整解压在**当前用户可写的本地目录**中的官方 Windows x64 ZIP 包。请保留发行包中的全部文件；只读目录、网络目录或源码开发运行无法直接安装更新，可以将完整发行包移到合适目录后使用。更新不会代为安装 .NET 运行时。

“接收预览版本更新”默认关闭，无论当前运行正式版还是预览版，都只提示更高的正式版本；开启后也提示更高的预览版本，不会降级。此偏好可在更新面板直接修改并保存，也可在“设置 → 性能与系统”中修改。切换更新面板中的开关会重新检查；正在检查或下载时暂时禁用开关。

没有可用更新时，仍显示与当前版本匹配的发行日志，当前版本为预览版时也一样，不受上述开关影响。若该版本没有公开日志，会显示暂无说明。网络失败或 GitHub 暂时限制请求时显示对应状态，并保留项目链接。

没有“检查更新”入口的旧版本，需要先从 GitHub Release 手动下载并安装一次包含此功能的发行包，此后即可在应用内更新。

## 工具条与工具参数

头像戴皇冠表示编辑；双手捧着皇冠、没有笔表示穿透，不再遮罩“穿透”文字。新组沿用原头像的画幅和其他轮廓，仅调整眼睛、双手与皇冠位置并移除笔。睁眼表示画布显示，闭眼表示隐藏；同一模式的两张图仅眼睛不同。托盘也显示当前模式和画布显隐状态。

托盘头像单击左键后，等待双击间隔结束再进入编辑；双击左键切换画布显隐。右键仍打开托盘菜单，快捷键提示显示在加宽菜单的右侧。

新建画布需要确认时，气泡位于按钮上方，小尾巴指向同一个确认按钮，气泡不会高过头像皇冠。

主菜单的功能分组、欢迎页、设置与悬浮头像使用各自的图标；托盘中的同一命令保持相同图标。

选中“更多工具”中的模糊或马赛克时，入口显示当前工具图标；切换其他工具后恢复三点图标。

隐藏画布期间也可清除内容；再次显示会先更新画面，再恢复可见，避免闪回旧内容。

工具参数与图层属性输入无效时保留当前有效值；改回有效数值、离开输入区域或重新打开面板后会移除过期提示并恢复当前值。忙碌时保留尚未应用的属性草稿，待操作完成后可继续应用。滚动内容、按钮和滑块不显示额外的键盘焦点虚框；输入框的编辑边框及工具、预设等的选中状态仍正常显示。

主菜单及右键菜单使用对应操作的图形。“切换为穿透”与工具条的“完成”使用同一对号；“检查更新”使用循环箭头。印章固定子菜单和快捷槽也有对应图标。

工具条左侧是应用图标，上下两排按列对齐：

- **上排**：选择、橡皮两项基础工具，随后是自由画笔、荧光笔、直线、矩形、椭圆、文字、序号、符号、Emoji、更多十项入口。“更多”仅提供模糊和马赛克，文字和序号各有独立入口。
- **下排**：印章库、新建印章，随后是与十项绘图入口对应的 `1`～`0` 印章方框；右侧为状态屏。空槽显示淡框，已绑定槽使用稍明显的淡框，当前快捷印章显示蓝框。

印章库按钮空闲时与“新建印章”一样显示灰色背景；从库中选用印章时显示该印章的缩略图和蓝色选框，切换到其他工具或快捷槽后恢复灰底。再次点击仍打开印章库。普通按钮和面板关闭按钮在悬停、按下时有更明显的背景反馈，浅色和深色主题保持一致。

右上方依次提供画布工具；导入、截图、裁剪；属性和图层；撤销／重做、新建空白画布、不透明度、显隐和完成操作，各组之间用分隔线区分。裁剪仅在单选一张可编辑图片时启用，禁用时仍可悬停查看提示。显隐按钮睁眼表示画布可见，琥珀色强调的闭眼表示已隐藏，应用角色图标也同步闭眼，睁闭状态仅眼部变化；托盘和任务栏图标同步切换；悬停提示显示下一步操作。模糊和马赛克从“更多”打开。不透明度滑块占两个按钮宽度；状态屏跟随浅色／深色主题，长文字默认省略，鼠标停留时滚动显示。工具条首次在主屏顶部水平居中，皇冠贴屏幕顶。工具条展开状态、窗口位置和大小只在本次启动内保留，重启后恢复默认布局；自定义快捷键和其他偏好仍保留。

- **单击应用图标**：打开主菜单。单击会等待系统双击间隔，以免和双击动作冲突；右键可直接打开菜单。
- **双击应用图标**：显示／隐藏画布并同步睁眼／闭眼；保留编辑模式和工具条折叠状态。
- **按 `Tab` 或选择主菜单第一项**：展开／收起工具条；菜单按当前状态显示“收起工具条”或“展开工具条”，并标注 `Tab`。收起后仅保留图标，仍可右键打开主菜单展开。`Tab` 在普通编辑操作时生效，按住不会连续切换，也不在按钮之间移动焦点；文字输入、输入框、菜单和对话框中不触发工具条切换。Windows 系统文件对话框保留原生的 `Tab` 导航。
- **拖动应用图标**：移动工具条，并记住位置。
- **单击工具图标**：切换当前工具。停留可查看名称与快捷键；主菜单的“绘图工具”和“图像与效果”也提供工具入口。
- **再次选择当前工具**：点击同一图标或再次按对应工具键，打开／关闭工具参数板。参数板打开时切换工具，会跟随显示新工具的设置。
- **按 `Ctrl+T`**：打开当前工具的参数板（画布工具打开画布设置）；已打开时保持打开，无参数窗口的工具不操作。

工具参数窗口以当前工具名作为标题，正文显示简短描述，参数与预设并排展示。展开工具条时，首次打开位于工具条上方或下方；之后可自由拖到其他位置，移动或收起工具条不带走该窗口。工具条收起时，再按当前工具键，可在鼠标附近打开，并限制在屏幕范围内。未固定时，点击画布或其他界面会关闭；固定后可继续绘图。`Esc` 先关闭颜色子面板，再关闭未固定的工具窗口；进入穿透时隐藏编辑面板。

线条工具统一设置起点和终点的箭头，可组合无箭头、单向或双向箭头，并选择实线、虚线或点线。矩形通过圆角半径变为圆角矩形；锁定宽高比后按配置比例绘制，正方形或圆可使用对应的 1:1 预设。符号工具提供三角形、星形、心形、勾叉等可改色图案；Emoji 工具提供表情选择，单击按“大小”插入，也可拖动确定本次尺寸；大小既可精确输入，也可在更大范围内拖动滑块。线型与箭头下拉选项带有图示，线宽下方显示粗细预览。闭合形状的描边向内占用指定线宽，不扩大外轮廓；描边与填色分别占用各自区域，半透明时不叠加变深。虚线从完整实线描边中裁去间隔，点线保留完整圆点。

常用工具键：`V` 选择、`E` 橡皮、`B` 自由画笔、`H` 荧光笔、`L` 直线、`R` 矩形、`O` 椭圆、`T` 文字、`N` 序号、`S` 符号、`J` Emoji、`C` 画布。`A` 未绑定工具；`Ctrl+A` 仅全选，不改变当前工具。`M` 打开“更多”，主键盘 `-` 打开印章库，`+`（`=/+` 键）保存当前选择为印章。输入文字时，这些字母用于文字输入。

上排快捷键角标统一压在右边框顶部，下排统一压在左边框底部；画布 `C`、置图 `I`、截图 `P` 与其他工具共用同一布局。相邻图标的大小与线条粗细保持一致。可在设置取消“显示工具快捷键角标”，同时隐藏上下两排的字母、印章数字及 `-`／`+` 角标；快捷键本身仍有效，偏好会保留到下次启动。

直线和箭头通过拖动绘制，不提供单击插入的默认长度或角度。矩形、椭圆和符号可设置默认宽高，在空白处单击时以点击位置为中心创建；拖动也可自行确定尺寸。矩形、椭圆、符号、序号和 Emoji 使用 **6 个逻辑像素**的拖拽容差，按按下时所在屏幕的缩放比例换算；容差内的轻微抖动仍按单击处理，达到容差后才按拖拽定大小。锁链开关决定是否保持配置的宽高比，按住 `Shift` 临时反转约束；截图的矩形／椭圆、图片裁剪及滤镜区域的等比约束仍为 1:1。工具参数的数值可直接输入，也可拖动对应滑块调整；输入框、下拉框、颜色谱面和滑块操作期间，按键用于当前控件，不切换工具或选择印章。

九种官方符号预设的单击插入默认尺寸均为 **72×72**。重新选择以前使用过的官方符号预设也会恢复该默认尺寸；个人预设和已有对象保留原尺寸。

序号和 Emoji 单击或轻微抖动时，仍按当前配置尺寸居中插入；按下后拖动则实时预览大小，松手完成。拖动起点作为选框一角，可向四个方向展开；整体等比缩放，序号保持圆形，Emoji 保持自身图案比例。本次拖动只改变新对象，不写回工具的配置尺寸，一次完成产生一个撤销步骤。

### 工具预设与颜色

官方文字字号为 36；符号、序号和 Emoji 大小为 72；矩形、椭圆至少一边为 108。序号和 Emoji 的“大小”直接控制图形选中框，序号文字自动适配。工具参数不提供等比开关，新图层默认勾选保持比例，可在图层属性中取消以分别拉伸宽高及图案。序号的“图形颜色”使用前景色板，“文字颜色”使用背景色板。形状的“配色样式”提供“分离颜色”和“统一颜色”，图示随形状变化；统一颜色将边框与填充合并为继承边框色的单一“颜色”控件，切回分离颜色会恢复原有填充色。该状态随预设、图层和恢复数据保存。

官方预设与“我的预设”统一为每排五个、只显示预览的圆角方形图块，名称放在悬停提示中。每个工具至少有一个官方预设；官方预设全部展开。“我的预设”只显示当前工具，区域至少容纳四排，并随左侧参数高度填满右侧剩余空间；更多预设在区域内滚动，不会撑高窗口。

首次使用工具时采用该工具自己的默认参数，官方默认前景色为色板红（`#E03E3E`），填充保持透明，序号则默认使用白色文字。每个工具分别记住基础预设及完整的当前参数；切换工具、关闭参数窗口、切换编辑／穿透模式或退出重启，都保留这些改动。工具状态在本机自动保存，频繁修改约合并 500 毫秒写入；正常退出或更新重启前等待落盘。窗口位置仍在每次启动时重置，序号的“下一个序号”仍属于画布文档。

单击预设立即应用并选中，每个工具保持一个选中项。官方预设和“我的预设”都包含完整的工具参数；每次应用都会恢复该预设确定的颜色、线宽、线型及其他参数。官方预览始终反映固定的官方定义，旧版首次使用时保存的官方基线不再影响应用或预览。旧个人预设缺少后来新增的参数时，应用会将该参数恢复为默认值，不继承点击前的当前值。

继续修改参数时保留选中项；再次点击预设会恢复其完整参数。临时改动保存在该工具的当前工作状态中，切换工具或重启后仍可继续使用；只有覆盖“我的预设”才会更新其定义。修改工具参数不会改变已有对象或保存的工程。

点击“我的预设”旁的加号保存，右键预设可覆盖、重命名或删除，保存和重命名使用统一命名窗口。左键拖动可调整顺序，右键和拖动不应用预设。删除当前关联的预设后，只将关联回退到第一个官方预设，保留当前全部工具参数；若参数与官方预设不同，继续显示改动角标。主动点击预设时才应用该预设的参数。

拖动个人工具／画布预设、我的色板、印章或图层排序时，会显示跟随鼠标的半透明预览；预览可移出滚动区和原窗口，不抢焦点或挡住鼠标。每个空隙只有一条蓝色插入线，两端各有蓝点，首行和边缘也完整显示。多选图层一起移动，预览带数量角标；把印章拖到快捷槽上时，目标槽会高亮。松手提交，按 `Esc` 或切换窗口取消，拖动不会触发点击应用。

颜色在工具参数窗口或属性窗口中调整。前景色用于描边或文字，背景色用于适用形状的填充。主行左侧用圆角色值按钮打开二级面板，右侧十个常用色按两排排列，点击即可直接设置。小色块统一为直角弱边框；二级面板的最近使用和我的色板每排十个，间距随显示缩放对齐像素。

颜色面板是带标题栏和关闭按钮的所属窗口，保持在来源窗口之上，失焦时关闭。标题栏不提供固定按钮；左侧调整颜色属性，右侧显示最近使用和我的色板，每排十个。保存／重命名色板时，命名对话框归属颜色窗口，暂时禁用下方窗口，确认或取消后返回颜色面板。

点击色值按钮打开二级面板，使用饱和度／明度谱面、色相条、不透明度和最近 20 种颜色调整。可拖动“前景色／背景色”标题区域移动颜色面板。有效颜色立即应用到一级色块、工具预览或所选图层；关闭时仅将最终颜色记入最近使用一次，无需确认按钮。色块和工具预览保留不透明度，与所在界面底色混合，不使用棋盘格。点击父参数窗口只关闭颜色面板，父窗口继续保留，并正常响应该次点击。只使用描边与填充的工具直接通过颜色设置不透明度，不再重复显示工具不透明度。

“我的色板”可为当前颜色命名保存，左键拖动排序，右键覆盖、重命名或删除；色板较多时滚动查看。新建、重命名对话框保留其下方的颜色面板。自定义输入接受 `#RGB`、`#RRGGBB` 或 `#AARRGGBB`，例如 `#FF2383E2`；`#00000000` 完全透明。取色时临时隐藏工具条以外的面板，尖头取色指针旁的气泡显示当前屏幕颜色；单击画布确认，`Esc` 或右键取消。完成后恢复原面板并返回二级选色器。

修改工具参数影响之后创建的元素；修改已有元素，请使用属性窗口。

## 绘制、选择和调整

- **选择**：点击或框选可见内容，文字留白、透明图片区域和空心形状内部不参与选择。`Shift` 点击增减选择；编组后的元素作为整体选择，按住 `Alt` 点击可选中组内单个元素。印章工具也显示已有选框，刚放置的印章仍不自动选中。
- **移动和缩放**：除橡皮擦和画布工具外，各工具均显示已有选框。选框可见时，左键优先操作当前选区，模糊、马赛克、裁剪、截图和文字工具也一致；从框体或边缘拖动可移动，角点用于缩放，旋转手柄用于旋转。按住 `Ctrl` 隐藏并绕过选框，执行当前工具本身的操作。
- **Shift 移动**：拖动主体时按住 `Shift`，仅沿画布平面 X／Y 轴移动。约束始终经过本次拖动最初的起点，中途按下、松开再按下都不重设起点；不包含 45° 方向。启用透视时，画布轴可能与屏幕方向不同。
- **旋转**：拖动选框上方的旋转手柄，按住 `Shift` 以 15° 吸附。普通单图层选框随图层旋转；透视放置的截图使用画布平面上的矩形外框，多图层使用整体包围盒。
- **线条端点**：单选直线或箭头后，拖动端点调整。
- **Shift 绘制**：自由画笔、荧光笔和自由套索在按住 `Shift` 的时段预览一段直线，松开时固定终点并继续自由绘制；可以在一次拖动中反复按下和松开形成折线。直线、箭头、双向箭头及其端点调整、多边形套索的下一条边，按住 `Shift` 时约束为水平、垂直或 45° 的八方向。
- **文字**：选文字工具后点击画布空白处，直接出现选框和光标。`Shift+Enter` 换行，`Enter` 完成并保留实体选中；`Esc` 取消本次输入。拖动可选字，常规光标键、复制粘贴和文字撤销可用。文字工具点击当前文本框外会提交并开始新的文字层，`Ctrl` 点击即使在框内也新建。切换图层、工具或窗口会提交；使用文字工具时，双击已选文字的字形可再次编辑。序号通过属性面板修改。

未进入文字输入时，已选文字的选框内部与边缘均用于移动，角点用于缩放，旋转手柄用于旋转；双击文字进入输入后，文本内部用于定位光标或选字，边框仍可直接开始变换。改变文字框宽高后，会重新换行并将字号适配整个新框，不保留已消失的自动换行高度；手动换行与空段落仍保留。
- **序号**：单击按配置大小加入并选中下一个序号，也可拖动确定大小；松开完成后才递增，按 `Esc` 或取消拖动不跳号。按住 `Ctrl` 可从已有选框内继续创建。数字始终单行显示，过长时自动缩小以适配标记，不改变标记外框或工具的大小设置。删除某一项不会重排其他序号。
- **擦除**：橡皮按整个元素擦除，一次拖动可整体撤销。

闭合形状、文字、序号和表情插入后自动选中，可直接拖动、缩放或旋转，无需先切换选择工具；再次点击空白会创建并选中新对象。自由画笔、荧光笔和印章放置后不自动选中，便于连续使用。直线、单箭头和双向箭头需拖动创建，在绘制中及完成后均不自动选中或显示新笔画选框；仍可用选择工具手动选中，再移动、调整端点或旋转。按住 `Ctrl` 临时隐藏并绕过已有选框，可从重叠位置直接创建新元素；松开恢复选框。按下鼠标时确定本次拖动是创建还是调整，中途按下或松开 `Ctrl` 不会切换操作。

图层的等比缩放开关随工程保存；拖动选框时，按住 `Shift` 临时反转该开关。矩形、椭圆和符号未约束比例时，可独立调整宽高；二次调整保持实际几何、线宽与圆角。文字默认不约束比例，调整边框时会改变字号和换行以适配边框，后续编辑也保留该边框。文字和序号的字体可从系统字体下拉列表中选择并预览。

序号工具可设置开始序号和步长，新建画布从开始序号计数。步长可为 0 或负数：0 连续放置相同序号，负数倒序计数。步长滑条为 -100～100，0 位于中间；开始序号、当前序号及图层序号的滑条仍从 1 开始，手填和图标拖动允许 0 或负数。到达整数边界后保持边界值，不绕回。“当前画布的下一个序号”独立保存在该画布中，可修改和撤销；切换工具、保存预设或程序设置不把它变成全局计数。调整“大小”会改变单击插入新序号的尺寸，拖动创建时以本次手势为准。

每种基础元素，包括自由曲线、文字、序号和图片，都保留为可选择的对象。

“属性”和“图层”是两个独立窗口，可从工具条或“主菜单 → 窗口”分别打开。属性窗口随选择自动刷新，输入有效的位置、宽高、角度、描边、填充、不透明度及文字设置时实时生效；短暂输入或离开字段会合并为一次可撤销操作，无需确认。多选时显示“选中多图层”，仅展示这些对象共同适用的属性；不同数值显示为空，改动后统一应用到所选对象。

类型专属参数也可在属性中继续调整：模糊与马赛克的强度、遮盖效果的颜色、符号的图形种类，以及序号和表情的字号。图片包含多个效果时，先从“效果”列表选择目标，再调整该项；其它效果及原作用区域保持不变。

这些工具窗口使用统一的悬浮面板：拖动顶部空白处移动，拖动边缘或右下角双斜线调整大小，右上角关闭按钮收起窗口；从原入口可再次打开。面板不提供最小化和最大化，双击顶部也不会放大。属性优先显示文字内容等不易在画布调整的项目，位置与尺寸放在最后；只显示当前选择共同适用的字段，底部保留状态提示。

双击画布中的图层，或选中一个或多个图层后按 `Enter`，会在鼠标附近打开属性；已显示的面板保持原位置。单击画布收起未固定面板后，仍需重新双击才能再次打开。文字编辑中的双击仍用于选字。属性右上角的固定按钮可保持面板显示；未固定时，移开焦点会收起面板，衍生颜色弹窗和子对话框仍属于同一个面板。关闭面板会重置固定状态。

固定按钮启用时，图标、边框和背景一起强调，与工具条显隐按钮采用相同的二态反馈。画布按钮的蓝框表示当前选中了画布工具；矩形／梯形图标分别表示透视关闭／开启，透视开启时保留琥珀色底和图标，未选中时还有琥珀色边框，选中后边框由蓝色覆盖。透视开关在参数板中调整。

拖动数值框左侧的 X、Y、W、H、角度或线宽标识，可以左右调整。属性名称只作说明，不响应拖动。`Shift` 精细调整，`Ctrl` 加速，松手提交为一次操作，`Esc` 取消本次拖动。X/Y 是元素在画布平面上外接框的左上角，启用透视后不等同于屏幕坐标；图片按本体位置计算，外侧描边不改变坐标数值；普通对象宽高沿自身方向计量，包含现有缩放但不含描边，透视放置的截图则显示不含描边的平面本体尺寸。修改宽高沿自身方向缩放，保留旋转角度；等比缩放时可以只改宽或高。路径某个方向的几何尺寸为零时，先调整端点再修改该方向尺寸。箭头可选择实心三角、开放箭头或菱形头部，头部尺寸设为 0 时随线宽自动调整。

图层列表中上方的元素显示在前。再次点击已选图层的名称，或按 `F2`，可重命名；`Enter` 或移开焦点保存，`Esc` 取消，留空恢复默认名称。名称随工程、恢复数据及撤销／重做保留。拖动每行左侧手柄调整顺序，右侧眼睛和锁图标分别切换显示、锁定。右键菜单提供复制、删除、置顶、置底、编组和解组；点击右上角关闭按钮旁的“？”可查看操作和快捷键说明。隐藏或锁定的元素仍可在列表中选择，以修改相应状态。选中多个可编辑元素后按 `Ctrl+G` 编组，`Ctrl+Shift+G` 解组。

属性、工具配置和画布设置使用统一的数值框：拖动框内左侧图标，短距离微调、长距离加速；中间直接输入；框底轨道可单击或拖动到常用范围内的值。仅框内图标显示横向拖动光标并响应数值拖动，外部名称保持普通标签语义。常用轨道范围不限制图标拖动和直接输入，但各属性仍有合法值约束。位置与大小分别组成一行属性，X/Y/W/H 四个框等宽；两框之间固定留 36 DIP，位置行留空，大小行放比例锁链。

数值框右侧显示对应单位，例如尺寸和线宽的 `px`、角度的 `°`、不透明度的 `%`，以及行、列和编号。单位不参与编辑，只需输入数字。工具预览和面板刷新会保留当前拖动，松手后更新预设状态。混合多选和自动值的占位状态也可以直接通过图标或底轨调整。

普通属性和开关名称统一使用 12 DIP 字号及相同字体、字重。栏目标题统一为 13 DIP 半粗体，首栏不加顶部分隔线；数值图标统一使用线条标识，同类属性共用图标。标准数值框、颜色编辑区、颜色值等单行文本框、下拉框与开关行统一为 34 DIP 高；长开关名称可以换行，图库和多行内容按需要增高。

属性、工具配置及画布面板的参数区默认为 440 DIP，标签列固定为 96 DIP，中英文共用尺寸。大小、位置及网格数量采用一个组名与两个数值框，其他普通属性各占一行；窗口过窄时，成组字段上下排列以保留输入空间。开关名称在左，控件固定靠右；名称可以超过普通标签列并换行。开关统一使用拨动样式；多选混合值用居中圆点和短横线表示，点击统一开启，再次点击关闭。常用标签采用简洁名称；少数超长普通标签悬停后自动滚动，按下拖动时停止文字动画。系统关闭界面动画时保留静态标签和完整提示。

普通窗口、对话框及带标题弹出面板的左右内容边距统一为 12 DIP，滚动条只在出现时占用空间，底部操作区与内容区沿用相同边界。

宽高中间的锁链按钮控制并保存“等比缩放”：蓝色连接表示锁定，断开表示独立调整，横线表示多选图层的状态不同。锁定后，输入或拖动任一尺寸都会即时更新另一尺寸；取消拖动恢复两边数值，图层改动可以撤销。工具预设也保存该状态和尺寸，锁定的非正方形预设按设定比例创建，正方形和圆形预设仍为 1:1。`Shift` 可在拖动创建时临时解除锁定；未锁定时按住 `Shift` 可临时绘制 1:1 图形。

颜色面板中按 `Esc` 会先取消正在进行的不透明度拖动，再按一次才关闭面板。

隐藏属性窗口或切换选择会提交已生效的有效文本输入；尚未松手的数值拖动会取消并恢复原值。不完整或无效的数值不会写入对象，选择新对象时自动载入它的当前属性。

工具条右上方的画布不透明度滑块调节标注与贴图的不透明度，截图底图保持正常亮度；旁边提供新建画布和显隐按钮。灰色空白页加号用于新建，右侧红色扫把用于立即清空。隐藏不会删除内容，也不改变编辑／穿透状态；隐藏期间不能添加新元素。

标注因显示器变化完全落到屏幕外时，可用“主菜单 → 画布 → 将标注移回可见屏幕”找回。已有任何部分在当前绘图范围的屏幕内时保持原位；完全屏外的可见、未锁定对象移到最近的可放置位置，分组作为整体处理并保留可编辑成员间距。对象大小和截图裁剪框不变，超大对象仅移到可操作的位置；整次操作可一步撤销，重复点击不会继续偏移。

### 画布工具、网格与透视

画布工具的 `Esc` 与普通工具同级：先取消未完成的拖动或四点放置，再关闭非固定配置，空闲时直接返回穿透，保留所选画布工具。

单击工具条的“画布”，或按 `C`，选中画布工具；它与画笔等其他工具互斥，蓝框表示当前选中。矩形／梯形图标分别表示透视关闭／开启。再次选择画布，打开或关闭参数板。首次位置、再次打开的位置和右上角固定按钮与其他工具参数板一致；关闭参数板后仍可继续调整画布。输入文字时，`C` 仍用于输入，`Ctrl+C` 仍为复制。

选中画布工具后，参考网格默认显示，与“显示网格”开关独立。非透视时，格长拖动以**当前参考屏幕中心**为缩放中心：选择具体屏幕时使用该屏幕，“仅主屏”和“全部屏幕”使用主屏，不改用整个桌面的中心。从画布空白处按下并拖动，远离缩放中心放大格子，靠近缩放中心缩小；格子始终为正方形。一次拖动只产生一步撤销，`Esc` 取消本次拖动。在已有对象上按下不开始调节格长。

参数板可设置独立的画布背景颜色与不透明度；默认背景透明；画布底色与实体网格始终位于所有图层下方，并与标注一起受工具条整体不透明度控制。非透视时，逻辑文档原点保持左上角 (0,0)，网格独立围绕主屏中心部署，屏幕中心始终是网格交点，不跟随透视钉点或图层平移。选中画布工具后可从画布任意位置起拖缩放网格，包括图层像素上；整次拖动可撤销。此时只显示“网格大小”，表示一个格子的边长，采用与矩形宽高相同的像素单位，可输入精确小数或拖动滑块。手动设置范围为 1～1,000,000；已有工程中更小的合法格长仍保留，不会仅因打开参数板被取整或放大。新建画布默认恢复第一个官方画布预设；在“设置 → 画布与历史”开启“新建时保留画布参数”后可沿用当前背景、网格、透视及钉点等参数。清空已有标注始终保留当前画布设置。

开启透视时显示行列数量，行数在左、列数在右，可输入或使用整数滑块，范围为 1～256；调整数量会改变网格密度，同时保留已校准的目标四角。单纯关闭、再开启透视会保留原有数量与校准，不根据显示文本重新换算。**显式修改非透视格长时，会按当前参考屏尺寸生成接近屏幕六成大小的一对行列数，并建立新的平直参考框，覆盖之前的透视形变。**精确格长单独保留，不会从取整后的行列数反推并舍入。

“重置透视画布”恢复图层在普通画布坐标下的 1:1 显示，清除透视形变与普通模式平移，图层数据不变。按目标屏幕和当前格数重建正方形网格：8列×6行是横框，6列×8行是竖框；保留钉点选择，并把新的矩形对应点绑定到同一内容点。锁定时保留自动覆盖数和开关状态，重新计算重置后的格长。只有一个活动屏幕时显示普通按钮，不显示下拉区域；多个活动屏幕时，菜单包括默认的“主屏幕”，以及“屏幕 1”“屏幕 2”等每块屏幕的显式选项。默认项使用无括号的按钮名称，显式选项显示“重置透视画布（屏幕 N）”；默认主屏与编号主屏是两个独立选项。下拉选择只更新并保存按钮目标，不立即重置，再点击主按钮才执行；目标不可用时回到默认项。重置目标不改变绘图范围或左上角的逻辑文档零点；重置会建立新的默认参照，随后的四角调整从该参照重新求解。

选中画布工具并开启透视后，校准框、中央整体移动手柄和参考网格自动出现。网格从所选钉点延伸；原点标记表示逻辑 (0,0)，中心手柄只负责整体移动。未锁格长且横纵格数为偶数时，四条边和四角始终位于对应格线上，不随透视调整相对漂移。拖动中央四向手柄或框内空白处可整体移动校准框，在“全部屏幕”范围内可跨屏搬移；四角和边缘用于调整透视。单角拖动靠近相邻角的水平或竖直方向时会轻微吸附，按 `Ctrl` 暂停吸附，按 `Shift` 沿拖动起点的水平或竖直轴移动。“参考网格透明度”可设为 0%～100%，0% 隐藏参考网格；仅在本次运行中保留，重启后恢复 100%，不写入画布、预设或用户设置。开启“显示网格”时，参考线原有的减淡效果与该值乘算。参考线是编辑辅助叠加，实体网格始终位于图层下方。调整参考透明度不会隐藏锚点或移动手柄。切换到其他工具后隐藏校准框和参考线，只保留已开启的自定义网格。`Esc` 先取消拖动；空闲时切回选择工具。失焦或隐藏画布会取消未完成的拖动。

“四点定位画布”是独立的主按钮。点击后临时隐藏工具条以外已打开的窗口，再按任意顺序点击四个角点：先预览线，再预览三角形，最后预览带网格的四边形；钉点位于九宫格所选位置，原点标记表示逻辑 (0,0)。第四点确认后完成定位，可一步撤销；`Esc` 取消未完成的定位。完成或取消后恢复此前显示的窗口，原本关闭的窗口不会被打开。画布工具选中时始终可以调整锚点，无需“完成画布调整”操作。

整体移动只改变画布的屏幕位置，保持透视形状、格长与默认参照。半透明笔迹与形状支持连续预览，并保留原来的不透明度和叠加效果；无需先将内容改为不透明。一次调整仍可整体撤销，取消则恢复调整前的状态。

地平线可以进入屏幕。调整受凹四边形、交叉边、退化、不可逆几何与数值稳定性约束；触及这些限制时，边框变为琥珀色并显示提示。网格、底色和贴面只绘制到安全边界，四点框外的安全区域仍可使用；校准时以琥珀色虚线标出远处边界。正常编辑时，鼠标进入禁区会用淡红色标出禁止区域，回到安全区或离开画布后隐藏；此提示不进入导出。创建或拖动对象进入禁区时显示禁止指针，松手取消无效创建或恢复拖动前的位置；自由笔画穿越禁区会断开，保留安全片段。立牌只检查地面锚点和有效尺度，上半部分可伸到天际线上方。

调整期间持续预览，越界部分临时裁剪。确认弹窗仅显示并突出需处理的图层数量，各选项说明可从关闭按钮旁的问号查看。松手或确认第四点后，如有越界图层，会询问取消本次调整、应用并移回图层（推荐）、应用并删除，或“应用并保留图层（慎用）”。保留时只应用透视，图层内容、位置、组合及显隐锁定状态均不变；当前不安全的部分会被裁剪或暂时隐藏，调整回安全透视后恢复显示，保存工程和重开也保留这些图层。迁回优先选择四点框内部或屏幕上的开阔位置，组合整体移动、独立图层错开，保留原始内容和逻辑尺寸；隐藏和锁定图层也计入提示。无法找到安全且可操作的位置时禁用迁回，不会自动缩小或删除。透视调整及所选处理合成一次撤销；选择前的恢复快照保持调整前状态。

“钉点”通过九宫格点选择器选择，默认左下角。钉点定义网格交点和尺度参照，与逻辑原点 (0,0)、中央整体移动手柄分开。角点钉点允许任意整数行列完整填满四点框；中心或边中点遇到奇数数量时，会显示边缘半格提示。切换钉点时，从固定默认参照重新映射到当前四边形；默认状态切换不移动内容，变形后切回左下角可让原本位于默认左下角的内容重新贴回该角。同一默认参照、四角、数量和钉点总是产生相同显示，不累积中间操作。图层逻辑坐标和宽高保持，视觉允许压缩。“调整时锁定网格大小”与钉点独立：开启时固定逻辑格长和网格相位，调整四角后图层仍贴住原来的格线，覆盖数自动变化，允许部分格。关闭时输入整数格数。数量始终按列（横向）在前、行（纵向）在后显示。

网格使用前景色预设，可调整颜色、不透明度和线宽，并通过图示与文字选择实线、虚线或点线；点线会绘制为可见的圆点。网格延伸到校准边框之外，并与参考线共享原点和格长。屏幕间距不足 8 像素的远端网格局部按层级抽稀，保留近景可分辨的格线；虚线／点线周期低于可分辨阈值时不再展开远端线段。参考、自定义和四点定位预览共用这一绘制规则。高分辨率密网格仍会增加 CPU 绘制开销；可增加非透视格长、减少透视行列数，或关闭“显示网格”。参考线在切换离开画布工具后隐藏。

画布参数板左侧显示属性，右侧为官方预设和“我的预设”。加号保存当前设置；个人预设支持覆盖、重命名、删除和拖动排序，应用可一次撤销。预设库 v3 保存背景、网格样式、精确非透视格长、深度优先遮挡，以及已有的四角位置和完整透视校准；目标画布的非透视网格原点和应用的重置屏幕偏好不属于预设。预设保存钉点、固定默认参照及普通模式放置；应用预设会退出网格锁定；非透视预设保留保存的精确格长。

官方预设关闭透视并恢复默认参考平面。旧个人预设缺少校准时，按参考屏幕及预设的行列、格长生成默认参考几何，不再继承应用前的四角；缺少深度优先遮挡开关时恢复为默认关闭。旧预设未保存的校准位置无法自动恢复，需要时重新校准后覆盖保存。更换屏幕布局后，按需重新调整或选择目标屏幕重置。

透视作用于形状、文字、贴图和动图，默认“贴面”对象随画布平面变形；实验性“立牌”采用下节的朝向与深度规则。动态模糊与马赛克区域随放置方式变换，但采样量仍以屏幕像素计算。透视以所选钉点的等深方向定标，平行四边形让最大伸展方向保持 1:1；接近仿射时平滑过渡以避免比例跳变；这只是尺度约定，并不能还原真实相机。游戏镜头移动后需要重新校准。截图首次粘贴时通过逆变换放回所选屏幕位置，此后随画布投影变化。

## 贴面与立牌（实验性）

“放置方式”有两种：**贴面**随画布透视变形；**立牌**始终面向屏幕，保留图案自身的比例和旋转，按地面锚点远近整体缩放。立牌开关默认关闭，位于工具条的画布调整组，主菜单也提供入口。不开启时沿用原有创建流程；通用 Shift 移动和贴面截图选区修复独立生效。

工具条和主菜单的入口统一为“放置方式”。工具提示只显示名称和当前的“默认模式”或“立牌模式”；默认模式对应贴面。先启用画布透视，再通过该按钮切换立牌模式（实验性）。全局开关只决定后续新对象的初始方式，不转换已有图层，也不随各工具预设单独保存。关闭透视时，开关置灰并重置为默认模式；已有立牌标记、锚点和高度仍保留，再次开启透视后恢复投影。属性中的“放置方式”和“离地高度”在透视开启时可用。

### 先选深度，再按原工具绘制

1. 选择能创建图层的工具，移动鼠标预览经过当前位置的等深线；点击固定深度。此时只显示线，不在点击处画点，也不同时开始工具输入。
2. 按原工具操作绘制：矩形仍可从一个角拖向另一个角；套索、多点工具和文字沿用各自的完成方式。等深线继续显示，并实时显示轮廓中心与到等深线的屏幕竖直连线。
3. 中心竖线与等深线的交点成为地面锚点。中心横向变化时，锚点沿等深线移动，深度不变；第一次点击的位置只用于选深度，不固定最终锚点。
4. 一次有效创建完成后，等深线消失。中心、锚点和连接线成为选中手柄的一部分，与选中轮廓共同显示或隐藏。需要再次创建时重新选深度。

截图也先选深度，再正常框选或套索；立牌截图保留选中的屏幕像素外观。文件导入、普通位图粘贴、外部图片拖入，以及合并位图印章，先准备图片，再在画布点击选择深度、第二次点击确定图片中心；选深度不会先生成空图层或撤销记录。切换工具、按 Esc 或取消操作会清理未完成的深度选择；异步失败或切换工程后不会插入迟到结果。

### 深度优先遮挡（实验性）

画布工具配置在勾选“启用透视画布”后显示“深度优先遮挡”，默认关闭。开启后，立牌按地面锚点深度从远到近叠放；只有深度完全相同才使用图层顺序。贴面之间仍按图层顺序叠放，列表不会随锚点移动重新排序。“置顶”不能越过不同深度的空间关系。

贴面属于公共画布平面，沿等深线与立牌交替合成，因此同一贴面可以局部位于立牌前方、局部位于后方。画布底色和实体网格始终位于所有对象下方，不参与遮挡立牌；底色、网格和对象合成后再统一应用工具条整体不透明度。桌面和背景图保持背景角色；图片内部的物体没有独立深度。负高度可以使立牌部分或全部被遮住，仍可从图层列表选中并使用选中手柄。

开关随工程、恢复记录和画布预设保存，可撤销。关闭透视时隐藏并暂停生效，重新启用透视会恢复选择；切换贴面／立牌创建工具保留选择，套用画布预设则恢复预设中保存的值，缺少该参数时默认关闭。屏幕截图与图片导出使用同一遮挡规则，平面内容印章继续使用平面语义。实时模糊和马赛克只采样当前深度片段之前已经合成的后方内容；模糊边缘不读取尚未合成的近端片段，避免相交滤镜循环采样。启用后的贴面分段绘制可能增加复杂画布的渲染开销。

v8 工程保存此开关并兼容读取 v1～v7；缺少此开关的旧工程默认关闭，旧版应用不能读取新保存的 v8 格式。

### 逻辑尺寸与视觉大小

所有立牌共用画布的深度比例，没有各自的“首次落点 100% 基准”。屏幕拖出的宽高除以深度比例，得到保存的逻辑宽高；描边预设本身就是逻辑值，直接投影显示。例如深度比例为 0.25，拖出屏幕 100×100 的矩形，逻辑宽高为 400×400；描边预设 5 仍为 5，预览和完成后视觉粗细均为 1.25。

移动到远处时，宽高、描边和离地高度一起变小，保存的逻辑值不变。关闭透视后显示逻辑尺寸：上述矩形在普通 100% 显示倍率下为 400×400、描边 5。不会强制恢复创建时的屏幕大小。

| 操作 | 效果 |
| --- | --- |
| 拖动图层主体 | 移动画布平面上的地面锚点；按新深度缩放，保留逻辑尺寸、高度和自身角度 |
| 主体移动时按住 Shift | 沿本次拖动起点的画布 X／Y 轴约束锚点，与屏幕轴、等深线方向和图案角度无关 |
| 拖动中心点 | 仅使用屏幕竖直分量改变离地高度，整个图层上下移动；锚点和逻辑尺寸保持不变 |
| 拖动外侧旋转手柄 | 在面向屏幕的平面内旋转图案，保留锚点与高度 |
| 拖动选框角点 | 以图层中心缩放，保留锚点与高度；Shift 继续临时反转等比偏好 |
| 点击地面锚点或连线 | 只作参考，不提供拖动或重新绑定入口 |

离地高度可以为负：中心点可经过锚点继续向下，不会自动夹为零。高度为零时中心和锚点重合，中心高度手柄仍可拖动。属性 X／Y 对立牌表示地面锚点在画布平面上的位置。等深线与屏幕竖线无法形成稳定交点时，会提示当前角度无法确定落点，需选择有效位置或调整校准，不会暗改深度。

### 组合、转换与文件

可编辑组合印章、浮绘内部对象复制、历史恢复和工程重开保留每个成员的放置方式、锚点、高度与图案，不被全局开关覆盖；可编辑印章不额外要求选深度。合并位图印章保存当前可见外观，之后作为一张新图片放置，不保留内部深度关系。混合组合旋转只改变贴面成员，立牌成员的锚点、高度和自身角度全部保持不动，因此两类成员的相对布局会改变。远近不自动改变图层顺序。

透视开启时，可在属性中切换已有图层的放置方式。转换保留原始内容与逻辑几何，允许外观改变；把透视变形的贴面改为正面立牌，不能同时保持全部屏幕角点。图片不因移动或切换方式反复重采样。

## 印章库与快捷栏

库窗口上方提供按 `1`～`9`、`0` 排列的紧凑十槽。把下方印章拖到槽位上可固定或替换；也可先单击选中一个槽，再单击印章固定，再次点击已选槽可退出槽位选择。槽位右上角的 `×` 清空绑定，印章仍留在库中。搜索框内有放大镜，与操作按钮共用一行；操作说明收在关闭按钮旁的 `?` 中。默认窗口按完整的印章列宽展开，全部印章在同一个列表中连续滚动。库内印章支持拖动排序，并显示“组合／图片”类型及带首个固定槽数字的图钉角标；顺序会保存。

工具条印章槽的右键菜单仅提供重命名、覆盖、删除和取消固定四项维护操作；使用和使用可编辑源仍位于印章库。槽位取消固定只移除当前槽，删除印章会清除所有对应槽位。

未固定印章的右键菜单提供“固定”二级菜单；已固定时改为“取消固定”，每次按快捷栏顺序（`1`～`9`、`0`）取消一个绑定。同一印章可以固定到多个槽，需重复取消才会全部清空。

印章用于复用自己绘制的图案。选中一个或多个元素，点击工具条下排的“新建印章”，或从“印章库”使用保存选择的操作，输入名称并选择保存方式。新印章会自动填入第一个空快捷槽；槽位已满时仍保存在库中：

| 保存方式 | 放置后的内容 |
| --- | --- |
| 可编辑编组 | 保留形状、文字、裁剪图片、动图及各自的样式和变换；可整体调整，也可用 `Alt` 选择组内元素继续编辑 |
| 合并为图片 | 将当前一帧合并为静态图片，同时在库中保留可编辑源对象；选择“以源对象使用”可重新放置原始元素 |

可编辑编组保留 GIF／动态 WebP 的原始数据；保存、重新打开印章库后再盖出，动图仍会播放。工具条和印章库列表中的小缩略图保持静止，普通动图印章在悬停的大预览中播放。含实时桌面模糊或马赛克的组合使用保存时的静态缩略图预览，即使其中还包含动图；放到画布后仍按对象类型工作。从库中选用印章时，印章库按钮保持选中并显示该印章预览；再次点击仍打开印章库。

在库中搜索或滚动选择印章，点击“使用”或双击缩略图，再在画布点击放置。每次点击按保存时的视觉尺寸和旋转关系放置，中心对准点击位置；无需拖出大小，可以连续盖印。每次放置可单独撤销，放置后不自动选择副本。鼠标停留在快捷槽或库内印章上，可查看名称、快捷键、大图及预览与实际尺寸的比例。可编辑印章的大预览按平面坐标展示，保留普通图形与立牌之间的相对位置及离地高度；保存的小缩略图保留保存时的透视外观。

选中库内印章后，可重命名、用当前画布选择覆盖，或删除。修改已经放到画布上的副本不会自动改写库内原件；需要更新原件时使用覆盖保存。

将印章固定到 `1`～`9`、`0` 中的某个位置，即可从工具条第二行或对应数字键选用。数字键先选择印章，随后点击画布放置；文字输入期间数字用于输入。取消固定只清除快捷位置，删除印章则同时清除它占用的快捷位置。当前选用的快捷印章失效时，工具返回“选择”。

## 贴图、替换和裁剪

可以按 `Ctrl+V` 粘贴剪贴板图片，或点击“贴图”选择一个或多个文件。新图片默认放在当前可见画布区域中央。支持 PNG、JPEG、BMP、GIF 和 WebP，透明图片保留透明区域；GIF 和动态 WebP 保留原始数据并播放。

也可以从文件管理器或浏览器拖住图片，保持拖动，按编辑／穿透切换快捷键（默认 `` Ctrl+` ``）展开画布，再在目标位置松开鼠标。图片中心对准落点；同时拖入多张图片时，后续图片会略微错开，整次导入可一步撤销。

拖动或粘贴来源需要提供实际图像数据或受支持的图片文件。文件导入、文件复制粘贴／拖入，以及提供原始 GIF／WebP 数据的剪贴板来源可以保留动画。若来源只提供 PNG 或 Bitmap，导入结果就是静态图，无法恢复原动画。网址、网页链接本身不能作为图片导入，浮绘不会联网追取原图；浏览器未提供原始动图时，可以先保存文件再导入。

隐藏画布会停止动画刷新，重新显示后继续；进入穿透时仍播放。动画推进不修改画布内容，不增加撤销步骤，也不触发自动保存。工程、恢复文件和浮绘内部的对象复制保留动画数据。截图、PNG／JPEG 导出及“合并为图片”印章取操作时的静态一帧；暂不支持播放控制、跨重启保存播放进度或导出动画。

贴图是独立对象，不会自动替换背景。选中图片后，可以移动、旋转、缩放、调整不透明度，以及设置描边宽度和颜色。图片与新截图按当前可见像素的轮廓描边：将所有非全透明像素向外扩展指定宽度，在原图下方铺上描边色。透明 PNG 的边沿跟随主体；主体的半透明部分会与下方描边色混合，完全透明的图片不产生描边。动图的描边随每帧轮廓更新。位置和宽高数值均按图片本体计算；选择框与命中范围包含全部外边，并保留原图的透明边距，不随动图轮廓跳动。

图片置入仍直接选择文件，不增加工具配置面板。旧图片默认不新增边框；旧截图中已经合成进像素的边框保留原样，新截图的描边可在属性面板中修改或设为 0。

图片描边的底图按需缓存，静图和动图中已出现的各帧均可复用。改变源图、裁剪、效果、本体尺寸或边宽后，下次绘制时重新生成；只修改颜色或整体不透明度时复用底图。缓存按实际显示清晰度生成，放大或改变透视后按需重建，避免放大低分辨率底图。缓存有内存上限，较久未使用的内容会被淘汰，需要时再生成。

- **替换原图**：单选图片，使用“主菜单 → 图像与效果 → 替换选中图片…”。保留原对象的位置、尺寸、裁剪和效果区域。
- **裁剪图片**：只选择一张可编辑、未锁定的图片，再点击主工具条导入与截图后方的“裁剪”，拖出保留范围。未选、多选、图文混选或图片锁定时按钮禁用，不会在空选时裁剪截图背景。原图片资源保留，裁剪可撤销。
- **模糊／马赛克**：从“更多”选择工具并拖出区域。在实时画布上，区域持续处理下方桌面及更低图层的浮绘对象，即使已选中图片也按屏幕区域处理；可移动、缩放、旋转并保存到工程。移动区域后会处理新位置的内容。冻结截图和图片中的对应效果仍为静态处理。
- 旧工程中的实色效果继续显示；不再提供创建实色工具的入口。图片效果随目标图片变换。

实时模糊和马赛克需要 Windows 10 2004（内部版本 19041）或更新版本，以可靠排除浮绘自身窗口。应用最低系统基线仍为 Windows 10 1607。较早系统新建这两种桌面区域时，使用操作时的静态截图效果并显示说明；已有动态区域用实色占位并提示，原对象保持不变。冻结截图和图片效果不受此版本门槛影响。

新建实时滤镜时先准备有效画面，成功后才添加对象；准备期间隐藏、切换工具、离开浮绘或修改文档会取消添加。隐藏画布停止采集，重新显示时先沿用同一画布的最后有效画面，再替换为新帧；切换文档或显示布局后不复用旧缓存。采集失败时提示原因，有兼容缓存则保留最后画面，否则用实色覆盖。

动态区域按桌面新帧更新，采集目标跟随显示刷新率、最高 60 FPS；实际速度取决于区域大小、设备和系统调度，不能保证与下层应用逐帧同步。导出、复制为图片或合并印章取操作时的快照，工程中的动态区域保持可编辑；效果和区域变换可撤销。

**外部截图兼容：**系统支持会话级窗口排除时，实时滤镜仅在浮绘自己的采集中排除浮绘界面，其他截图软件仍可捕获可见的标注。应用根据实际接口能力选择采集方式；不支持时使用兼容采集，并在状态屏提示画布可能不会出现在第三方截图中。兼容采集期间，需要完整合成时可使用浮绘内的导出，或删除、隐藏所有动态区域后再截图。此机制不表示 Windows 截图的窗口识别限制已解决。

## 截图与原位静像

点击工具条的截图工具，或使用“主菜单 → 画布 → 截图”。先在实时画面上选择范围，完成后才采集该时刻的内容，并将一张静态图片按原位置、原尺寸插入当前画布。不会切换到另一张画布，范围外的桌面继续实时显示。

再次选择截图工具可打开参数板，设置选区形状、内容来源和可选边框。默认为矩形、只截背景、不加边框；这些设置和当前预设会随工具状态保存。

| 选区形状 | 操作 |
| --- | --- |
| 矩形／椭圆 | 按住鼠标拖动，松开完成；`Shift` 临时反转等比开关 |
| 自由套索 | 按住鼠标沿轮廓拖动；按住 `Shift` 拉直当前段，松开 `Shift` 继续曲线，松开鼠标自动闭合 |
| 多边形套索 | 单击逐个添加顶点，移动鼠标预览下一条边，`Shift` 约束八方向；回到起点单击、双击或 `Enter` 完成，`Backspace` 撤回最后一个顶点 |

透视开启、放置方式为贴面时，矩形和椭圆是画布平面上的形状，圈选预览会随平面投影；关闭透视后截图内容的轮廓恢复为对应矩形或椭圆。自由／多边形套索始终沿屏幕上的鼠标轨迹圈选。立牌截图则先选等深线，再按屏幕轮廓选区，反算逻辑尺寸并保留捕获像素；可选边框预设使用逻辑粗细，预览时已按深度缩放。

截图不会因单击而创建默认大小的图片；没有面积的选区不会插入对象。套索交叉时按奇偶规则填充，跨越轮廓的次数为偶数的区域保留透明。

| 内容来源 | 图片包含什么 |
| --- | --- |
| 仅背景 | 下层桌面及应用，不含浮绘标注和工具界面 |
| 背景＋画布 | 下层画面与当前可见的浮绘内容合成为一张图片 |
| 仅画布 | 只截浮绘自身内容，保留透明通道 |

三种来源都排除工具条、面板、选框和圈选提示。非矩形选区外保持透明；仅画布模式下，动态滤镜取当前画面，其余空白仍透明。若结果完全透明，会提示选区内没有内容，不插入不可见图片。

选区使用黑白轮廓预览，不会先冻结整个桌面。正在选择时按 `Esc` 只取消本次选区，继续编辑；没有进行中的操作时，`Esc` 仍按通用规则关闭面板或进入穿透。取消、空选区或采集失败不会清空已有内容。系统保护区域可能无法采集，届时会提示。

新图片自动选中，截图工具保持启用，便于继续截取。可以直接移动、旋转、缩放、裁剪或删除图片，也可一步撤销插入。从已选中对象内部开始新选区时，按住 `Ctrl`，避免变成调整该对象。可选边框写入图片，之后随图片整体变换。

采集背景时，浮绘保留当前编辑和输入状态，并从结果中排除自己的界面；必要时，部分界面会短暂隐藏，完成后恢复。不会为了截图先退出再进入绘制。每次都重新采集当前桌面，不复用上一次截图；画面静止时也无需先移动鼠标或改变内容。

采集失败不会清空已有内容；只要仍在浮绘中正常编辑，就会保留编辑状态。切换到其他应用、主动退出编辑、隐藏画布或切换／修改当前画布会取消正在进行的采集，不插入迟到的图片，也不会抢回前台。意外失败会提示诊断日志的位置，便于排查原因。

原有标注始终保留。选择“背景＋画布”或“仅画布”得到的是静态副本；透明内容与原标注原位重叠时，颜色可能加深。截图不会随下层应用继续变化。保存工程会保留这张可编辑图片；选中后复制可取得截图，或通过文件菜单导出画布的合成结果。

旧版的独立冻结截图工程和历史草稿仍可打开、编辑和导出。旧草稿在进入穿透时保留，并切回实时画布。

关联文件时，工具条上方显示文件名气泡，未保存修改显示独立的“未保存”标识，悬停可查看完整路径。气泡随工具条折叠隐藏；右键菜单依次提供“还原改动”“打开文件所在位置”，分隔线下方为“取消文件关联”。“还原改动”从关联文件重新载入上次保存的内容，无未保存改动时置灰；还原作为一步撤销记录，可按 Ctrl+Z 回到还原前，按 Ctrl+Y 重做。取消关联保留当前内容和撤销记录，之后作为未命名画布编辑。

### 新建、清空和历史版本

工具条灰色空白页加号用于新建画布并解除文件关联，默认恢复第一个官方画布预设；“新建时保留画布参数”开启时沿用当前参数。未绑定文件且有新绘制内容时，再点一次原按钮确认；空画布、未修改的历史副本、已保存且无修改的工程均一次新建。已绑定工程有修改时直接提示保存、保留到历史并离开或取消。右侧红色扫把立即清空绘制对象，保留背景、网格、校准及文件关联；无需确认，不推入历史，可用 Ctrl+Z 撤销。清空后的工程只有再次保存才更新磁盘文件。

历史按进入画布时的内容判断新版本，在切换、新建或退出时归档。临时画布自动保留；工程编辑后即使保存过，离开时仍记录最终版本。仅打开未编辑、纯空白（包括只改画布参数）和重复内容不新增。恢复得到未命名副本，不自动覆盖原工程；只查看不改变旧条目时间和排序，继续编辑后再形成新的置顶版本。后台自动恢复独立保存空状态。

设置中的“历史版本上限”默认为 60，接受 0–1000 的整数，滑动条覆盖 0–200。0 表示不保留历史版本。保存设置或新增历史时移除超出上限的最旧版本；当前画布的恢复数据和故障隔离备份不计入。历史是有限容量的本地记录，长期保留请保存工程。

印章提示中的预览按图像本身的比例展示。带透视实时效果的印章使用保存时的截图缩略图，可能与平面中的标称宽高不同；预览不会拉伸，必要时分别显示水平和竖直比例。

## 保存工程、导出和恢复

普通启动时会为当前用户注册 `.floatcanvas` 打开方式，也可在设置中点击“注册 .floatcanvas 打开方式”。双击工程，或在 Windows“打开方式”中选择浮绘，即可打开文件；应用已运行时会把文件交给同一实例，并保留替换前的保存确认。Windows 已有的默认应用选择不会被覆盖；如需默认使用浮绘，请在“打开方式”中选择“始终”。移动便携目录后，先从新位置运行一次以更新注册路径。命令行也支持 `FloatCanvas.exe "工程.floatcanvas"` 或 `FloatCanvas.exe --open "工程.floatcanvas"`。

| 操作 | 得到什么 | 之后能否继续编辑对象 |
| --- | --- | --- |
| 保存／另存工程 | `.floatcanvas` 文件，包含当前画布、原图片和效果 | 可以；使用“打开工程”重开 |
| 导出合成图片 | 背景、标注和贴图合成的 PNG／JPEG | 结果是图片；当前工程仍可编辑 |
| 导出透明标注 | 只有标注和贴图的透明 PNG | 结果是图片；当前工程仍可编辑 |
| 选中对象后复制 | 浮绘内可编辑对象，同时提供通用图片 | 在浮绘内粘贴继续编辑；其他软件通常取得图片 |

新截图作为图片随当前画布保存；旧版独立截图草稿仍分别保留。导出不会清空当前内容。工程保存原图以便再次编辑；需要分享遮盖后的结果时使用导出的合成图片。

当前工程格式为 **v8**，可打开旧 **v1～v7** 工程。工程保存背景、精确非透视格长与原点、透视、钉点、固定默认参照、普通模式平移及图层放置设置，包括立牌锚点、逻辑离地高度和深度优先遮挡。旧文件缺少放置标记时按贴面处理，缺少深度开关时默认关闭；旧版应用不能读取新保存的 v8 工程。需要与旧版交换工程时，请保留原文件。

浮绘会在提交编辑后约 1 秒保存恢复数据，退出前等待恢复保存完成。正常启动仍为空白画布；从“主菜单 → 文件 → 恢复历史画布…”选择最近或更早的工作区，可以一起恢复实时画布和截图草稿。恢复成功、取消或失败均保留发起时的编辑／穿透模式；中途切到其他应用或主动退出编辑时，不会再抢回前台。撤销历史不跨重启保留。

历史列表显示保存时间和画布缩略图，便于区分同名记录。缩略图保存浮绘自身的透明标注图层，不采集桌面背景，也不包含工具条或选择控制点。没有预览的旧历史会按需生成；无法生成时显示“暂无预览”，不妨碍恢复。

默认数据位置：

“主菜单 → 系统与调试”可以打开安装目录或当前用户数据目录。设置、工具状态、工具预设、画布预设和颜色配置会兼容读取未知字段及枚举；缺失、无法解析或越界的字段在内存中使用默认值，其余配置保持可用。正常读取不会改写文件，之后修改其他设置也会保留未知字段和未更改的原始值，便于切换版本。旧序号工具预设会保留原来的图形颜色与白色文字。

如果 JSON 损坏、存在重复字段或结构无法安全读取，启动时可选“退出”保留全部文件，或“备份并修复配置”。修复会先将上述五类配置复制到当前用户数据目录的 `configuration-backups` 时间戳子目录，再仅重置出错文件；任一备份失败便停止修复。正常使用中，只有保存确实需要替换当前版本无法读取的原值时，才另行提示备份确认；取消会保留原文件。工程、画布、印章和恢复数据不会重置。完整技术错误保存在日志中。

- 设置：`%LOCALAPPDATA%\FloatCanvas\settings.json`
- 最近恢复：`%LOCALAPPDATA%\FloatCanvas\recovery\workspace.floatcanvas`
- 前代恢复：`%LOCALAPPDATA%\FloatCanvas\recovery\workspace.previous.floatcanvas`
- 历史画布：`%LOCALAPPDATA%\FloatCanvas\recovery\history`
- 工具预设：`%LOCALAPPDATA%\FloatCanvas\tool-presets.json`
- 画布预设：`%LOCALAPPDATA%\FloatCanvas\canvas-presets.json`
- 各工具当前状态与选中预设：`%LOCALAPPDATA%\FloatCanvas\tool-state.json`
- 颜色历史与我的色板：`%LOCALAPPDATA%\FloatCanvas\colors.json`
- 印章库：`%LOCALAPPDATA%\FloatCanvas\stamps`
- 运行诊断：`%LOCALAPPDATA%\FloatCanvas\diagnostics.log`
- 未处理异常：`%LOCALAPPDATA%\FloatCanvas\errors.log`

遇到疑似错误时，请记下发生时间和操作步骤，并保留 `diagnostics.log`；发生未处理异常时也保留 `errors.log`。可在资源管理器地址栏输入 `%LOCALAPPDATA%\FloatCanvas` 找到它们。日志自动记录采集方式、准备和取帧阶段、选区边界、显示信息、取消／失败原因、版本与异常堆栈；相关输入附带类别、时间及是否被本应用抑制，可区分按键尾流与真正外部操作。日志不保存按键内容、连续鼠标轨迹、画布图像或标注正文，异常信息可能包含文件路径。每类日志最多保留当前文件及 `.1`、`.2` 两个旧文件，每个不超过 1 MiB；自定义 profile 的日志保存在对应目录。

手动恢复时，如果所选工作区的最新数据损坏，会尝试其前代；读取失败会提示并保留原文件。空白启动后尚未编辑便退出，不会用空白覆盖之前的恢复内容。恢复数据用于找回最近工作，重要内容仍应保存为自己的工程文件。

关闭工具条或返回穿透不会退出软件。需要结束运行时，使用系统托盘或“主菜单 → 退出浮绘”。默认不开机自启。

## 操作方式、提示与个人资源

浮绘以鼠标绘画和选取为主，快捷键用于加快操作。应用内不使用 `Tab`／`Shift+Tab` 遍历按钮和表单控件，也不追加键盘焦点虚框；`Tab` 保留展开／收起工具条的作用。Windows 系统文件对话框仍使用原生键盘导航。Windows 高对比度启用时，界面跟随系统窗口、文字和选中颜色；普通浅色／深色偏好在关闭高对比度后继续使用。预设和印章槽以边框显示当前项，不叠加勾号；基于选中预设改动参数后，在选中框右上角内侧显示与边框同色的三角封角，保持预览图标完整。错误同时显示文字及警示符号。

工具预设、画布预设和“我的色板”的新建、删除、覆盖、重命名和排序，与画布编辑共用当前画布的操作历史，按实际操作顺序使用 `Ctrl+Z` 撤销、`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做，也可使用工具条及编辑菜单的撤销／重做。切换到另一画布后使用该画布的历史；历史不跨应用重启保留。撤销新建会移除该预设，重做可恢复；撤销色板更改不影响最近使用的颜色。颜色输入框、预设命名框等文字编辑区域优先使用本地文字撤销。名称不能为空或只含空格，修正前保存按钮不可用。

没有可撤销／重做的内容，或对象选择不满足命令要求时，相应操作不可用，悬停可查看原因。混合选择包含锁定对象时，属性面板显示锁定数量，并说明需先解锁这些对象才能编辑属性。文字所用字体未安装时，字体栏保留原名称并说明实际替代字体；选择已安装字体才会替换原设置。

点击工具条状态屏，可阅读并复制本次运行中最近 20 条完整消息。关闭 Windows 界面动画时，长消息不再自动滚动。历史列表和印章库按可见区域加载预览；印章库继续连续滚动，空库、无搜索结果、加载失败各有说明和后续操作。工具参数和画布设置缩窄时，预设区移到参数下方。

## 帮助、诊断与卸载

“主菜单 → 帮助”提供随程序附带的离线用户指南、快捷键和“报告问题”。报告问题先显示版本、系统信息及填写提示；只有点击“打开反馈页面”才打开浏览器，不会自动发送或上传内容。

从“主菜单 → 系统与调试 → 导出诊断包…”先预览即将导出的版本、系统、运行模式和脱敏日志，也可取消包含日志。确认后选择本地 ZIP 保存位置；应用不自动上传。附给维护者前仍应检查包内信息。诊断包不包含画布、工程、印章或设置文件；原始日志继续留在用户数据目录。

删除便携安装前，先退出浮绘，在该安装目录运行 `FloatCanvas.exe --unregister-integration`，移除属于此安装的当前用户启动项和文件打开方式注册。其他安装的注册、Windows `UserChoice` 和用户资料保留。命令完成后可删除这个便携程序目录；`%LOCALAPPDATA%\FloatCanvas` 中的预设、印章和历史不会自动删除，重要资料请自行备份。若正在使用自定义 `--profile`，资料位于指定目录。

从源码开发构建需要 **.NET SDK 10.0.402** 或仓库 `global.json` 允许的后续补丁，以及 **Visual Studio C++ Build Tools**（含 MSVC 和 Windows SDK），用于构建原生组件。普通用户运行已发布包只需前文所述桌面运行时。签名验证和发布签名的配置取决于发布流程，不应把本地成功构建视为已签名发行版。

## 支持范围与限制

最低系统基线为 **Windows 10 1607（内部版本 14393）x64**，包含 LTSB 2016、LTSC 2019、LTSC 2021，亦面向 Windows 11 x64。应用不再以 Windows 10 22H2 作为启动门槛；较新系统专有功能单独降级或提示，不阻止基本绘图功能启动。

需安装该系统可用的 **.NET 10 Windows Desktop Runtime x64**，并保持系统与运行时更新。应用的最低版本基线与微软官方支持承诺不同；微软的支持范围还取决于具体 Windows 版本、版本类型及生命周期，详见 [.NET 10 支持平台](https://github.com/dotnet/core/blob/main/release-notes/10.0/supported-os.md)。当前实测仍主要在 Windows 11，较早 Windows 10／LTSB／LTSC 尚待实机确认，源码检查与兼容分支测试不能替代这些设备上的实际验收。

新配置默认全部屏幕，也可选择仅主屏；完整跨屏、混合 DPI、竖屏、热插拔、锁屏恢复及双 4K 体验仍在完善。不同设备和应用的表现可能有所差异。

浮绘面向普通桌面与全屏应用，不要求统一改成窗口化或无边框；具体全屏兼容性取决于应用和显示方式，不保证所有独占全屏场景。

系统打开／另存为文件框使用 Windows 自身的输入与前台；关闭或取消后返回浮绘编辑。弹出文件框时，部分游戏可能离开全屏。

使用 Windows 截图工具或其他截图软件的窗口吸附功能时，绘图层可能成为截图目标。需要保留标注时，可使用浮绘自己的截图或导出功能；只需要下层应用画面时，可先按“隐藏画布／显示画布”快捷键（默认 `` Ctrl+Shift+` ``）隐藏画布，截图后再显示。穿透模式不会隐藏标注；画布显隐保持当前编辑／穿透状态，按编辑／穿透切换快捷键可另行切换输入方式。

HDR 色彩准确性、压感笔、触控、OCR、录屏、滚动截图、云同步和上传不在当前版本范围内。
