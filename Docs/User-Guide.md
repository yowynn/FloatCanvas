# 浮绘 FloatCanvas 使用指南

简体中文 | [English](User-Guide.en.md)

本指南适用于 Windows x64 的 **0.1.1-preview.6**。预览版仍在完善功能与稳定性，建议将重要工作另存为工程文件。

界面支持自动跟随 Windows、简体中文和 English，可在设置中选择，保存后重启生效。

浮绘把标注和贴图留在屏幕上。进入编辑模式时绘制和调整；切换到穿透模式后，画面保留，可以继续点击、拖拽和滚动下层应用。

## 启动与切换

使用发行包时，解压对应版本的 Windows x64 ZIP，保留全部文件，运行其中的 `FloatCanvas.exe`。自包含发行包带有所需的 .NET，无需另装开发工具。

1. 在欢迎界面选择“开始绘制”，或按 `Ctrl+Alt+F` 进入编辑。
2. 再按 `Ctrl+Alt+F` 返回穿透。工具条消失，标注仍显示，下层应用恢复操作。

标注固定在屏幕位置，不会跟随网页滚动或游戏中的物体移动。

默认绘图范围为**仅主屏**，只在主屏标注和截图。副屏上的其他应用可继续运行；切换到其他应用时，浮绘会进入穿透。

从“更多 → 快捷键与主题…”打开设置，在“绘图范围”选择“全部屏幕”，保存后下次启动生效。启动参数 `--primary-screen` 或 `--all-screens` 可覆盖本次运行范围，不改变保存的偏好，二者不可同时使用。完整跨屏和混合 DPI 体验仍待完善。原工程的屏幕外对象坐标保留，可用“将标注移回可见屏幕”找回。

编辑模式由浮绘接收普通窗口的键盘和鼠标消息；没有绑定工具的字母也不应发送给下层应用。切到其他应用会收起编辑工具并进入穿透，标注继续显示。进入编辑时若无法取得输入焦点，会保留穿透并提示原因。

切走时未提交的文字会保留，重新进入同一画布后恢复；显式取消或切换穿透会关闭文字编辑。

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Alt+F` | 编辑／穿透切换 |
| `Ctrl+Alt+Shift+F` | 隐藏／恢复全部标注；隐藏时同时释放输入 |
| `Esc` | 先取消正在进行的操作；没有操作时返回穿透 |
| `Ctrl+Z`／`Ctrl+Y` | 撤销／重做；`Ctrl+Shift+Z` 也可重做 |
| `Ctrl+A` | 全选可编辑元素 |
| `Ctrl+C`／`Ctrl+V` | 复制／粘贴 |
| `Ctrl+D` | 复制所选元素并略微错开 |
| `Delete` | 删除所选未锁定元素 |
| 方向键／`Shift`＋方向键 | 所选元素移动 1／10 个文档像素 |
| `Ctrl+S`／`Ctrl+Shift+S` | 保存／另存当前工程 |
| `Ctrl+O` | 打开工程 |

从工具条“更多 → 快捷键与主题…”打开设置，可修改快捷键和浅色／深色主题。保存时检测到注册冲突会显示原因，原有效快捷键保留。部分组合可能先被系统或其他软件截获，导致录制框没有变化；遇到这种情况请换用其他组合。工具条可以拖动位置；系统托盘也有编辑、显示、设置和退出入口。

切换快捷键使用 Ctrl／Alt／Shift 组合；Win 和系统离开组合保留给 Windows，`Ctrl+Alt+Esc` 保留为紧急释放输入。界面无响应或输入接管中断时会回到穿透，不会向下层重放先前的绘图按键。

## 界面语言与输入法

在“更多 → 快捷键与主题…”的“界面语言 / Language”中选择，保存后重启浮绘生效：

| 设置 | 启动时的界面语言 |
| --- | --- |
| 自动（跟随 Windows，`auto`，默认） | 跟随 Windows 显示语言；中文系显示简体中文，其他语言回退英文 |
| 简体中文（`zh-CN`） | 简体中文 |
| English（`en`） | 英文 |

界面语言不会翻译或改写已有标注、工程文字、文件名和剪贴板内容，也不会切换 Windows 键盘布局或输入法方案。英文界面可以输入中文，中文界面也可以输入英文，不要求使用特定输入法或双拼方案。

浮绘的语言选择适用于自身工具条、菜单、设置、提示，以及文件对话框的标题和文件类型筛选；Windows 自带的“打开／保存／取消”等按钮可能仍按系统显示语言呈现。切换浮绘界面语言不改变 Windows 的语言设置。

## 绘制、选择和调整

在工具条的工具列表选择画笔、荧光笔、直线、箭头、双向箭头、矩形、圆角矩形、椭圆、三角形、文字、序号或橡皮。颜色和线宽可直接在工具条调整。

常用工具键：`V` 选择、`B` 自由画笔、`L` 直线、`A` 箭头、`R` 矩形、`O` 椭圆、`T` 文字、`N` 序号、`E` 橡皮。输入文字时，这些字母用于文字输入。

- **选择**：点击元素，或从空白处拖出选择框。`Shift` 点击增减选择。
- **移动和缩放**：拖动元素移动；拖动选框角上的控制点缩放。
- **旋转**：拖动选框上方的旋转手柄，按住 `Shift` 以 15° 吸附。
- **线条端点**：单选直线或箭头后，拖动端点调整。
- **文字**：点击文字工具并在画布点击，输入多行文字；点击“完成”或按 `Ctrl+Enter`。选择模式下双击文字可再次编辑。
- **序号**：每次点击加入下一个序号，删除某一项不会重排其他序号。
- **擦除**：橡皮按整个元素擦除，一次拖动可整体撤销。

每种基础元素，包括自由曲线、文字、序号和图片，都保留为可选择的对象。

点击“属性”打开属性与图层面板。单选时可以输入位置、宽高、角度、描边、填充、透明度及文字设置，再点击“应用属性”。一次应用可整体撤销。

颜色支持 `#AARRGGBB`，例如 `#FF2383E2`；`#00000000` 是完全透明的填充。X/Y 是元素屏幕外接框的左上角；宽高沿元素自身方向计量，包含现有缩放但不含描边。修改宽高沿自身方向缩放，保留旋转角度；等比缩放时可以只改宽或高。路径某个方向的几何尺寸为零时，先调整端点再修改该方向尺寸。箭头可选择实心三角、开放箭头或菱形头部，头部尺寸设为 0 时随线宽自动调整。

图层列表中上方的元素显示在前。点击“图层”标题可单独收起或展开列表，属性输入继续保留。可直接选择隐藏或锁定的图层，修改显示／锁定状态，再用图层操作调整前后顺序。隐藏属性面板会保留未应用的输入；切换元素后，可返回原元素应用，或点击“重载当前选择”载入新元素。

工具条的整体透明度只影响标注和贴图，截图背景保持正常亮度。标注因显示器变化落到屏幕外时，可以使用“更多 → 将标注移回可见屏幕”。该操作平移未隐藏且未锁定的对象，保留彼此间距和截图裁剪框。

## 贴图、替换和裁剪

可以按 `Ctrl+V` 粘贴剪贴板图片，点击“贴图”选择一个或多个文件，或使用“更多 → 拖入图片…”。支持 PNG、JPEG、BMP 和 WebP，透明图片会保留透明区域。

“拖入图片…”会打开一个临时小窗口，并进入实时画布的穿透模式，方便从资源管理器拖入文件。图片仍会导入打开窗口前的画布或截图草稿；窗口会显示目标名称。成功后点击“继续编辑”回到该画布，或直接关闭窗口继续操作电脑。关闭不会自动恢复冻结截图；导入过程中关闭会取消尚未提交的导入。每次打开窗口接受一次导入，可同时拖入多张图片并整体撤销。

贴图是独立对象，不会自动替换背景。选中图片后，可以移动、旋转、缩放和调整透明度。

- **替换原图**：单选图片，使用“更多 → 替换选中图片…”。保留原对象的位置、尺寸、裁剪和效果区域。
- **裁剪图片**：先选中图片，再选择“裁剪”，拖出保留范围。图片原资源保留，可撤销裁剪。
- **模糊／马赛克／实色遮盖**：先选中图片，再选对应工具并在图片内拖出范围。在冻结截图中，没有选中贴图时，对截图背景应用效果。

裁剪和图片效果每次处理一张未锁定的图片；多选图片时需要先单选，锁定图片需要先解锁。

这些效果随目标图片一起移动和变换，不会实时处理下层桌面。修改或取消效果、裁剪可通过撤销完成。

## 截图与返回实时画布

1. 点击“截图”。桌面冻结后，拖动选择截图范围；也可从“更多”菜单直接截取当前绘图范围。
2. 用同一套工具继续标注、贴图、加文字或处理图片。已有标注会进入独立的截图草稿。
3. 用“裁剪”调整截图范围；若当前选中了图片，裁剪针对该图片。需要裁剪截图画布时先取消图片选择。
4. 用“更多 → 导出合成图片…”保存 PNG 或 JPEG，或在没有选中元素时按 `Ctrl+C` 复制合成结果。
5. 用“更多 → 返回实时画布”回到原画布；“继续上一张截图”可重新进入草稿。

截图中的改动不会修改原实时画布。截图编辑时按 `Ctrl+Alt+F`，会保留草稿、返回实时画布并进入穿透，避免隔着冻结画面操作电脑。

恢复截图草稿或显示布局变化时，只有截图裁剪范围完全离开所有活动绘图屏幕，浮绘才会把截图视图平移到主屏；仍部分可见时保留原位置。原图、裁剪范围和已提交的标注保持不变。

开始新截图前，若旧截图尚未保存，会提供另存、放弃或取消。捕获失败时保留原内容。部分受系统保护的区域可能显示遮盖，软件会提示，其余截图可以继续编辑。

## 保存工程、导出和恢复

| 操作 | 得到什么 | 之后能否继续编辑对象 |
| --- | --- | --- |
| 保存／另存工程 | `.floatcanvas` 文件，包含当前画布、原图片和效果 | 可以；使用“打开工程”重开 |
| 导出合成图片 | 背景、标注和贴图合成的 PNG／JPEG | 结果是图片；当前工程仍可编辑 |
| 导出透明标注 | 只有标注和贴图的透明 PNG | 结果是图片；当前工程仍可编辑 |
| 选中对象后复制 | 浮绘内可编辑对象，同时提供通用图片 | 在浮绘内粘贴继续编辑；其他软件通常取得图片 |

实时画布和截图草稿分别保存。导出不会清空当前内容。工程保存原图以便再次编辑；需要分享遮盖后的结果时使用导出的合成图片。

浮绘会在提交编辑后约 1 秒保存恢复数据，退出前等待恢复保存完成。再次启动会尝试恢复实时画布和截图草稿，并保持穿透。撤销历史不跨重启保留。

默认数据位置：

- 设置：`%LOCALAPPDATA%\FloatCanvas\settings.json`
- 最近恢复：`%LOCALAPPDATA%\FloatCanvas\recovery\workspace.floatcanvas`
- 前代恢复：`%LOCALAPPDATA%\FloatCanvas\recovery\workspace.previous.floatcanvas`

如果当前恢复数据损坏，会尝试前代；读取失败会提示并保留原文件。恢复数据用于找回最近工作，重要内容仍应保存为自己的工程文件。

关闭工具条或返回穿透不会退出软件。需要结束运行时，使用系统托盘或“更多 → 退出浮绘”。默认不开机自启。

## 支持范围与限制

当前预览主要适用于 Windows 11 x64。Windows 10 22H2 为兼容目标，尚未确认完整兼容性。

默认仅主屏；完整跨屏、混合 DPI、竖屏、热插拔、锁屏恢复及双 4K 体验仍在完善。不同设备和应用的表现可能有所差异。

浮绘面向普通桌面与全屏应用，不要求统一改成窗口化或无边框；具体全屏兼容性取决于应用和显示方式，不保证所有独占全屏场景。

HDR 色彩准确性、压感笔、触控、OCR、录屏、滚动截图、云同步和上传不在首版范围内。
