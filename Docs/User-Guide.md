# 浮绘 FloatCanvas 使用指南

简体中文 | [English](User-Guide.en.md)

本指南适用于 Windows x64 预览版 **0.2.0-preview.1**。较早版本的界面和功能可能不同，请结合[更新日志](../CHANGELOG.md)使用。建议将重要工作另存为工程文件。

在画布上按下鼠标开始绘制或移动后，整次拖动由画布处理；即使经过工具条或在按钮上松开，也不会触发按钮。从工具条上按下鼠标，则由工具条处理，不会在画布上留下笔迹。

界面支持自动跟随 Windows、简体中文和 English，可在设置中选择，保存后重启生效。

浮绘把标注和贴图留在屏幕上。进入编辑模式时绘制和调整；切换到穿透模式后，画面保留，可以继续点击、拖拽和滚动下层应用。

## 启动与切换

使用发行包时，解压对应版本的 Windows x64 ZIP，保留全部文件，运行其中的 `FloatCanvas.exe`。默认发行包不附带 .NET 运行时或调试符号文件（PDB）。电脑已有兼容的 **.NET 10 Windows Desktop Runtime x64** 时可直接启动。

若缺少兼容运行时，启动程序会显示 .NET 安装提示。点击 **Download** 打开微软官方下载页面，下载并运行 **Windows Desktop Runtime x64** 安装程序，安装后再次运行 `FloatCanvas.exe`。也可从 [.NET 10 官方下载页](https://dotnet.microsoft.com/download/dotnet/10.0)手动选择该运行时。无需 SDK；普通 .NET Runtime、ASP.NET Core Runtime 和 .NET Framework 不能替代所需的桌面运行时。

1. 在欢迎界面选择“开始绘制”，或按 `` Ctrl+` `` 进入编辑。
2. 再按 `` Ctrl+` `` 返回穿透。工具条消失，标注仍显示，下层应用恢复操作。

每次正常启动在屏幕中央显示欢迎页，并使用空白画布，不自动展开上次的标注或截图。点击关闭、开始绘制或按切换快捷键进入绘制后，欢迎页关闭，本次启动不再自动显示。需要继续之前的工作时，单击工具条左侧应用图标，选择“文件 → 恢复历史画布…”，或使用托盘中的同名入口。选择历史后保持穿透，按切换快捷键继续编辑。

欢迎页用“绘制模式 / 穿透模式”和“隐藏画布 / 显示画布”说明两组快捷键，底部显示版本与带红色爱心的作者署名。隐藏画布不会清空内容。画布显隐与编辑／穿透独立，切换编辑不会自动显示已隐藏的内容；显示画布也不改变当前模式。隐藏时可操作工具界面，但不能在画布添加内容。

标注固定在屏幕位置，不会跟随网页滚动或游戏中的物体移动。

默认绘图范围为**仅主屏**，只在主屏标注和截图。副屏上的其他应用可继续运行；切换到其他应用时，浮绘会进入穿透。

从“主菜单 → 快捷键与主题…”打开设置，在“绘图范围”选择“全部屏幕”，保存后下次启动生效。启动参数 `--primary-screen` 或 `--all-screens` 可覆盖本次运行范围，不改变保存的偏好，二者不可同时使用。完整跨屏和混合 DPI 体验仍待完善。原工程的屏幕外对象坐标保留，可用“主菜单 → 画布 → 将标注移回可见屏幕”找回。

编辑模式由浮绘接收普通窗口的键盘和鼠标消息；没有绑定工具的字母也不应发送给下层应用。切到其他应用会收起编辑工具并进入穿透，标注继续显示。进入编辑时若无法取得输入焦点，会保留穿透并提示原因。

切走时未提交的文字会保留，重新进入同一画布后恢复；显式取消或切换穿透会关闭文字编辑。

| 快捷键 | 作用 |
| --- | --- |
| `` Ctrl+` `` | 编辑／穿透切换 |
| `` Ctrl+Shift+` `` | 隐藏画布／显示画布；保留当前编辑／穿透状态 |
| `Esc` | 先取消当前操作或关闭颜色子面板，再关闭未固定面板，最后返回穿透 |
| `Ctrl+Z`／`Ctrl+Y` | 撤销／重做；`Ctrl+Shift+Z` 也可重做 |
| `Ctrl+A` | 全选可编辑元素 |
| `Ctrl+C`／`Ctrl+V` | 复制／粘贴 |
| `Ctrl+D` | 复制所选元素并略微错开 |
| `Ctrl+G`／`Ctrl+Shift+G` | 编组／解组 |
| `1`～`9`、`0` | 选用十格快捷栏中对应的印章，再点击画布放置 |
| `M`／`-`／`+` | 更多工具／打开印章库／保存选择为印章；`-`、`+` 使用主键盘分区 |
| `Delete` | 删除所选未锁定元素 |
| 方向键／`Shift`＋方向键 | 所选元素移动 1／10 个文档像素 |
| `Ctrl+S`／`Ctrl+Shift+S` | 保存／另存当前工程 |
| `Ctrl+O` | 打开工程 |

从“主菜单 → 快捷键与主题…”打开设置，可修改快捷键和浅色／深色主题。保存时检测到注册冲突会显示原因，原有效快捷键保留。部分组合可能先被系统或其他软件截获，导致录制框没有变化；遇到这种情况请换用其他组合。系统托盘也有编辑、显示、设置和退出入口。

切换快捷键使用 Ctrl／Alt／Shift 组合；Win 和系统离开组合保留给 Windows，`Ctrl+Alt+Esc` 保留为紧急释放输入。界面无响应或输入接管中断时会回到穿透，不会向下层重放先前的绘图按键。

## 检查与安装更新

点击欢迎页左下角的版本号打开“检查更新”。打开面板后会自动检查[浮绘 GitHub Release](https://github.com/yowynn/FloatCanvas/releases)，显示当前版本、可用的新版本和更新说明；点击“重新检查”可再次获取。面板底部始终保留[项目主页](https://github.com/yowynn/FloatCanvas)链接。

存在可用更新时，点击“立即更新”。应用显示下载进度，校验下载的文件，并在保存当前画布的恢复数据后退出、替换程序，再自动重启并恢复工作。设置、预设和画布数据保留。下载期间可以取消或关闭面板，继续使用当前版本；下载或校验失败不会替换程序，替换失败时会尝试恢复原版本并说明原因。

应用内安装更新适用于完整解压在**当前用户可写的本地目录**中的官方 Windows x64 ZIP 包。请保留发行包中的全部文件；只读目录、网络目录或源码开发运行无法直接安装更新，可以将完整发行包移到合适目录后使用。更新不会代为安装 .NET 运行时。

正式版本只检查更高的正式版本；版本号含 `preview` 等预发布标记的版本，也检查更高的预发布版本。不会安装低于当前版本的发行包。没有新版本、网络失败或 GitHub 暂时限制请求时，面板会显示相应状态，仍可通过项目链接查看发行页面。

没有“检查更新”入口的旧版本，需要先从 GitHub Release 手动下载并安装一次包含此功能的发行包，此后即可在应用内更新。

## 界面语言与输入法

在“主菜单 → 快捷键与主题…”的“界面语言 / Language”中选择，保存后重启浮绘生效：

| 设置 | 启动时的界面语言 |
| --- | --- |
| 自动（跟随 Windows，`auto`，默认） | 跟随 Windows 显示语言；中文系显示简体中文，其他语言回退英文 |
| 简体中文（`zh-CN`） | 简体中文 |
| English（`en`） | 英文 |

界面语言不会翻译或改写已有标注、工程文字、文件名和剪贴板内容，也不会切换 Windows 键盘布局或输入法方案。英文界面可以输入中文，中文界面也可以输入英文，不要求使用特定输入法或双拼方案。

浮绘的语言选择适用于自身工具条、菜单、设置、提示，以及文件对话框的标题和文件类型筛选；Windows 自带的“打开／保存／取消”等按钮可能仍按系统显示语言呈现。切换浮绘界面语言不改变 Windows 的语言设置。

## 工具条与工具参数

工具条左侧是应用图标，上下两排按列对齐：

- **上排**：选择、橡皮两项基础工具，随后是自由画笔、荧光笔、直线、矩形、椭圆、文字、序号、符号、Emoji、更多十项入口。“更多”提供马赛克等工具，文字和序号各有独立入口。
- **下排**：印章库、新建印章，随后是与十项绘图入口对应的 `1`～`0` 印章方框；右侧为状态屏。空槽显示淡框，已绑定槽使用稍明显的淡框，当前快捷印章显示蓝框。

右上方提供撤销／重做、导入、截图、属性、图层、新建画布、画布透明度、显隐和完成操作；马赛克等效果从“更多”打开。透明度滑块占两个按钮宽度；状态屏跟随浅色／深色主题，长文字默认省略，鼠标停留时滚动显示。工具条首次在主屏顶部水平居中，皇冠贴屏幕顶。工具条展开状态、窗口位置和大小只在本次启动内保留，重启后恢复默认布局；自定义快捷键和其他偏好仍保留。

- **单击应用图标**：打开主菜单。单击会等待系统双击间隔，以免和双击动作冲突；右键可直接打开菜单。
- **双击应用图标**：展开／收起工具条，收起后仅保留图标。
- **拖动应用图标**：移动工具条，并记住位置。
- **单击工具图标**：切换当前工具。停留可查看名称与快捷键；主菜单的“绘图工具”和“图像与效果”也提供工具入口。
- **再次选择当前工具**：点击同一图标或再次按对应工具键，打开／关闭工具参数板。参数板打开时切换工具，会跟随显示新工具的设置。

工具参数窗口以当前工具名作为标题，正文显示简短描述，参数与预设并排展示。展开工具条时，首次打开位于工具条上方或下方；之后可自由拖到其他位置，移动或收起工具条不带走该窗口。工具条收起时，再按当前工具键，可在鼠标附近打开，并限制在屏幕范围内。未固定时，点击画布或其他界面会关闭；固定后可继续绘图。`Esc` 先关闭颜色子面板，再关闭未固定的工具窗口；进入穿透时隐藏编辑面板。

线条工具统一设置起点和终点的箭头，可组合无箭头、单向或双向箭头，并选择实线、虚线或点线。矩形通过圆角半径变为圆角矩形；等比选项可绘制正方形或圆。符号工具提供三角形、星形、心形、勾叉等可改色图案；Emoji 工具提供表情选择，并按“大小”插入；大小既可精确输入，也可在更大范围内拖动滑块。线型与箭头下拉选项带有图示，线宽下方显示粗细预览。

常用工具键：`V` 选择、`E` 橡皮、`B` 自由画笔、`H` 荧光笔、`L` 直线、`R` 矩形、`O` 椭圆、`T` 文字、`N` 序号、`S` 符号、`J` Emoji。`A` 保留为箭头兼容键；`M` 打开“更多”，主键盘 `-` 打开印章库，`+`（`=/+` 键）保存当前选择为印章。输入文字时，这些字母用于文字输入。

上排快捷键角标位于右上角，下排位于左下角。可从主菜单或设置取消“显示工具快捷键角标”，同时隐藏上下两排的字母、印章数字及 `-`／`+` 角标；快捷键本身仍有效，偏好会保留到下次启动。

直线和箭头通过拖动绘制，不提供单击插入的默认长度或角度。矩形、椭圆和符号可设置默认宽高，在空白处单击时以点击位置为中心创建；拖动也可自行确定尺寸。启用等比或按住 `Shift` 可创建正方形或圆。工具参数的数值可直接输入，也可拖动对应滑块调整；输入框、下拉框、颜色谱面和滑块操作期间，按键用于当前控件，不切换工具或选择印章。

### 工具预设与颜色

官方预设与“我的预设”统一为每排五个、只显示预览的圆角方形图块，名称放在悬停提示中。每个工具至少有一个官方预设；官方预设全部展开。“我的预设”只显示当前工具，区域至少容纳四排，并随左侧参数高度填满右侧剩余空间；更多预设在区域内滚动，不会撑高窗口。

首次使用工具时采用该工具自己的默认参数；切回已使用过的工具时恢复它上次的参数。单击预设立即应用并选中，每个工具保持一个选中项。继续修改参数时，选中项与官方预览保持；再次点击同一项可恢复改动。官方预设初次显式应用保留当前工具的颜色，之后可回到本次选用时的参数；我的预设保存完整配置。点击“我的预设”旁的加号保存，右键预设可覆盖、重命名或删除，保存和重命名使用统一命名窗口。左键拖动可调整顺序，右键和拖动不应用预设。删除当前项后回到第一个官方预设。

颜色在工具参数窗口或属性窗口中调整。前景色用于描边或文字，背景色用于适用形状的填充。主行左侧用圆角色值按钮打开二级面板，右侧十个常用色按两排排列，点击即可直接设置。小色块统一为直角弱边框；二级面板的最近使用和我的色板每排十个，间距随显示缩放对齐像素。

点击色值按钮打开二级面板，使用饱和度／明度谱面、色相条、透明度和最近 20 种颜色调整草稿。关闭或点击面板外时自动应用一次，无需确认按钮；点击父参数窗口只关闭颜色面板，父窗口继续保留。只使用描边与填充的工具直接通过颜色设置透明度，不再重复显示工具透明度。

“我的色板”可为当前颜色命名保存，左键拖动排序，右键覆盖、重命名或删除；色板较多时滚动查看。自定义输入接受 `#RGB`、`#RRGGBB` 或 `#AARRGGBB`，例如 `#FF2383E2`；`#00000000` 完全透明。取色器启用后点击画布取色，`Esc` 取消。

修改工具参数影响之后创建的元素；修改已有元素，请使用属性窗口。

## 绘制、选择和调整

- **选择**：点击元素，或从空白处拖出选择框。`Shift` 点击增减选择；编组后的元素作为整体选择，按住 `Alt` 点击可选中组内单个元素。
- **移动和缩放**：拖动元素移动；拖动选框角上的控制点缩放。
- **旋转**：拖动选框上方的旋转手柄，按住 `Shift` 以 15° 吸附。
- **线条端点**：单选直线或箭头后，拖动端点调整。
- **文字**：点击文字工具并在画布点击，输入多行文字；点击“完成”或按 `Ctrl+Enter`。选择模式下双击文字可再次编辑。
- **序号**：点击加入并选中下一个序号；按住 `Ctrl` 可从已有选框内继续插入。删除某一项不会重排其他序号。
- **擦除**：橡皮按整个元素擦除，一次拖动可整体撤销。

形状、文字、序号和表情插入后自动选中，可直接拖动、缩放或旋转，无需先切换选择工具；再次点击空白会创建并选中新对象。自由画笔、荧光笔和印章放置后不自动选中，便于连续使用。直线与箭头需拖动创建。按住 `Ctrl` 临时隐藏选框，可从重叠位置直接创建新元素；松开恢复选框。

矩形、椭圆和符号未约束比例时，可独立调整宽高；二次调整保持实际几何、线宽与圆角，不是将一张图片拉长。文字和序号的字体可从系统字体下拉列表中选择并预览。

序号工具可设置开始序号和正整数步进，新建画布从开始序号计数。“当前画布的下一个序号”独立保存在该画布中，可修改和撤销；切换工具、保存预设或程序设置不把它变成全局计数。调整字号会改变新序号的实际尺寸。

每种基础元素，包括自由曲线、文字、序号和图片，都保留为可选择的对象。

“属性”和“图层”是两个独立窗口，可从工具条或“主菜单 → 窗口”分别打开。单选时，在属性窗口输入位置、宽高、角度、描边、填充、透明度及文字设置，再点击“应用属性”。一次应用可整体撤销。

这些工具窗口使用统一的悬浮面板：拖动顶部空白处移动，拖动边缘或右下角双斜线调整大小，右上角关闭按钮收起窗口；从原入口可再次打开。面板不提供最小化和最大化，双击顶部也不会放大。属性按位置尺寸、外观和文字编号连续排列，只显示当前对象适用的字段；内容较多时滚动查看，底部的“应用属性”“重载当前选择”和状态提示保持可见。

拖动 X、Y、宽、高、角度或线宽等数值前的标签，可以左右调整；`Shift` 精细调整，`Ctrl` 加速，松手提交为一次操作，`Esc` 取消本次拖动。X/Y 是元素屏幕外接框的左上角；宽高沿元素自身方向计量，包含现有缩放但不含描边。修改宽高沿自身方向缩放，保留旋转角度；等比缩放时可以只改宽或高。路径某个方向的几何尺寸为零时，先调整端点再修改该方向尺寸。箭头可选择实心三角、开放箭头或菱形头部，头部尺寸设为 0 时随线宽自动调整。

图层列表中上方的元素显示在前。再次点击已选图层的名称，或按 `F2`，可重命名；`Enter` 或移开焦点保存，`Esc` 取消，留空恢复默认名称。名称随工程、恢复数据及撤销／重做保留。拖动每行左侧手柄调整顺序，右侧眼睛和锁图标分别切换显示、锁定。右键菜单提供复制、删除、置顶、置底、编组和解组；点击右上角关闭按钮旁的“？”可查看操作和快捷键说明。隐藏或锁定的元素仍可在列表中选择，以修改相应状态。选中多个可编辑元素后按 `Ctrl+G` 编组，`Ctrl+Shift+G` 解组。

隐藏属性窗口会保留未应用的输入；切换元素后，可返回原元素应用，或点击“重载当前选择”载入新元素。

工具条右上方的画布透明度滑块调节标注与贴图的透明度，截图底图保持正常亮度；旁边提供新建画布和显隐按钮。新建画布会先将当前工作区归档到历史，再从空白开始；需要找回时使用“恢复历史画布”。隐藏不会删除内容，也不改变编辑／穿透状态；隐藏期间不能添加新元素。标注因显示器变化落到屏幕外时，可以使用“主菜单 → 画布 → 将标注移回可见屏幕”。该操作平移未隐藏且未锁定的对象，保留彼此间距和截图裁剪框。

## 印章库与快捷栏

印章用于复用自己绘制的图案。选中一个或多个元素，点击工具条下排的“新建印章”，或从“印章库”使用保存选择的操作，输入名称并选择保存方式。新印章会自动填入第一个空快捷槽；槽位已满时仍保存在库中：

| 保存方式 | 放置后的内容 |
| --- | --- |
| 可编辑编组 | 保留形状、文字、裁剪图片及各自的样式和变换；可整体调整，也可用 `Alt` 选择组内元素继续编辑 |
| 合并为图片 | 作为一张图片放置，同时在库中保留可编辑源对象；选择“以源对象使用”可重新放置原始元素 |

在库中搜索、翻页选择印章，点击“使用”或双击缩略图，再在画布点击放置。每次点击按保存时的视觉尺寸和旋转关系放置，中心对准点击位置；无需拖出大小，可以连续盖印。每次放置可单独撤销，放置后不自动选择副本。鼠标停留在快捷槽或库内印章上，可查看名称、快捷键、大图及预览与实际尺寸的比例。

选中库内印章后，可重命名、用当前画布选择覆盖，或删除。修改已经放到画布上的副本不会自动改写库内原件；需要更新原件时使用覆盖保存。

将印章固定到 `1`～`9`、`0` 中的某个位置，即可从工具条第二行或对应数字键选用。数字键先选择印章，随后点击画布放置；文字输入期间数字用于输入。取消固定只清除快捷位置，删除印章则同时清除它占用的快捷位置。当前选用的快捷印章失效时，工具返回“选择”。

## 贴图、替换和裁剪

可以按 `Ctrl+V` 粘贴剪贴板图片，或点击“贴图”选择一个或多个文件。新图片默认放在当前可见画布区域中央。支持 PNG、JPEG、BMP 和 WebP，透明图片会保留透明区域。

也可以从文件管理器或浏览器拖住图片，保持拖动，按编辑／穿透切换快捷键（默认 `` Ctrl+` ``）展开画布，再在目标位置松开鼠标。图片中心对准落点；同时拖入多张图片时，后续图片会略微错开，整次导入可一步撤销。

拖动来源需要提供实际图像数据或受支持的图像文件。网址、网页链接本身不能作为图片导入；不同网站和浏览器提供的拖动内容可能不同，不保证每个网站都能直接拖入。无法拖入时，可使用“复制图像”后粘贴，或保存图片后选择文件导入。

贴图是独立对象，不会自动替换背景。选中图片后，可以移动、旋转、缩放和调整透明度。

- **替换原图**：单选图片，使用“主菜单 → 图像与效果 → 替换选中图片…”。保留原对象的位置、尺寸、裁剪和效果区域。
- **裁剪图片**：先选中图片，再选择“裁剪”，拖出保留范围。图片原资源保留，可撤销裁剪。
- **模糊／实色遮盖**：从“更多”或“主菜单 → 图像与效果”选择工具。所选元素中恰有一张图片时，即使同时选中了文字或形状，效果仍针对该图片；在图片内拖出范围，锁定图片需先解锁。未选图片或选中多张图片时，冻结截图针对背景处理；实时画布的模糊保存操作时的区域图像，实色遮盖创建覆盖形状。
- **马赛克**：实时画布中从“更多”选择马赛克，拖出持续更新的屏幕区域。该区域同时处理其下方的桌面内容和浮绘标记，不因选中图片而变成静态图片效果；可继续移动、缩放、旋转并保存到工程。在冻结截图中，马赛克仍是针对图片或底图的静态效果。

图片裁剪每次处理选择中的一张未锁定图片；若选中了多张图片，需要先将所选图片减为一张，锁定图片需要先解锁。

动态马赛克在有可见区域时持续刷新；暂时无法采集桌面时，以实色覆盖该区域。导出、复制为图片或合并印章使用操作时的快照，工程中的动态区域则保持可编辑。静态图片效果随目标图片一起移动和变换，效果与裁剪均可撤销。

**外部截图限制：**存在可见动态马赛克时，为避免采样自身造成画面反馈，浮绘的显示与输入层会被系统捕获排除，外部截图可能不包含其他标注。需要完整合成时使用浮绘内的导出；删除或隐藏所有动态区域后自动恢复。此机制不表示 Windows 截图的窗口识别限制已解决。

## 截图与返回实时画布

1. 点击“截取屏幕并编辑…”。这个入口把桌面冻结为独立截图草稿，适合裁剪、遮盖后导出；原实时画布会保留。桌面冻结后拖动选择截图范围，也可从“主菜单 → 画布”直接截取当前绘图范围。
2. 用同一套工具继续标注、贴图、加文字或处理图片。已有标注会进入独立的截图草稿。
3. 用“裁剪”调整截图范围；若当前选中了图片，裁剪针对该图片。需要裁剪截图画布时先取消图片选择。
4. 用“主菜单 → 文件 → 导出合成图片…”保存 PNG 或 JPEG，或在没有选中元素时按 `Ctrl+C` 复制合成结果。
5. 用“主菜单 → 画布 → 返回实时画布”回到原画布；“继续上一张截图”可重新进入草稿。

截图中的改动不会修改原实时画布。截图编辑时按 `` Ctrl+` ``，会保留草稿、返回实时画布并进入穿透，避免隔着冻结画面操作电脑。

恢复截图草稿或显示布局变化时，只有截图裁剪范围完全离开所有活动绘图屏幕，浮绘才会把截图视图平移到主屏；仍部分可见时保留原位置。原图、裁剪范围和已提交的标注保持不变。

开始新截图前，若旧截图尚未保存，会提供另存、放弃或取消。捕获失败时保留原内容。部分受系统保护的区域可能显示遮盖，软件会提示，其余截图可以继续编辑。

## 保存工程、导出和恢复

| 操作 | 得到什么 | 之后能否继续编辑对象 |
| --- | --- | --- |
| 保存／另存工程 | `.floatcanvas` 文件，包含当前画布、原图片和效果 | 可以；使用“打开工程”重开 |
| 导出合成图片 | 背景、标注和贴图合成的 PNG／JPEG | 结果是图片；当前工程仍可编辑 |
| 导出透明标注 | 只有标注和贴图的透明 PNG | 结果是图片；当前工程仍可编辑 |
| 选中对象后复制 | 浮绘内可编辑对象，同时提供通用图片 | 在浮绘内粘贴继续编辑；其他软件通常取得图片 |

实时画布和截图草稿分别保存。导出不会清空当前内容。工程保存原图以便再次编辑；需要分享遮盖后的结果时使用导出的合成图片。

当前工程格式为 **v2**：仍可打开旧 **v1** 工程，新保存的工程使用 v2。使用 v1 格式的旧版浮绘会明确拒绝 v2 工程，避免忽略编组、线型等新信息后重新保存造成数据丢失。需要与旧版交换工程时，请保留原 v1 文件。

浮绘会在提交编辑后约 1 秒保存恢复数据，退出前等待恢复保存完成。正常启动仍为空白画布；从“主菜单 → 文件 → 恢复历史画布…”选择最近或更早的工作区，可以一起恢复实时画布和截图草稿，恢复后保持穿透。撤销历史不跨重启保留。

默认数据位置：

- 设置：`%LOCALAPPDATA%\FloatCanvas\settings.json`
- 最近恢复：`%LOCALAPPDATA%\FloatCanvas\recovery\workspace.floatcanvas`
- 前代恢复：`%LOCALAPPDATA%\FloatCanvas\recovery\workspace.previous.floatcanvas`
- 历史画布：`%LOCALAPPDATA%\FloatCanvas\recovery\history`
- 工具预设：`%LOCALAPPDATA%\FloatCanvas\tool-presets.json`
- 颜色历史与我的色板：`%LOCALAPPDATA%\FloatCanvas\colors.json`
- 印章库：`%LOCALAPPDATA%\FloatCanvas\stamps`

手动恢复时，如果所选工作区的最新数据损坏，会尝试其前代；读取失败会提示并保留原文件。空白启动后尚未编辑便退出，不会用空白覆盖之前的恢复内容。恢复数据用于找回最近工作，重要内容仍应保存为自己的工程文件。

关闭工具条或返回穿透不会退出软件。需要结束运行时，使用系统托盘或“主菜单 → 退出浮绘”。默认不开机自启。

## 支持范围与限制

当前预览主要适用于 Windows 11 x64。Windows 10 22H2 为兼容目标，尚未确认完整兼容性。

默认仅主屏；完整跨屏、混合 DPI、竖屏、热插拔、锁屏恢复及双 4K 体验仍在完善。不同设备和应用的表现可能有所差异。

浮绘面向普通桌面与全屏应用，不要求统一改成窗口化或无边框；具体全屏兼容性取决于应用和显示方式，不保证所有独占全屏场景。

使用 Windows 截图工具或其他截图软件的窗口吸附功能时，绘图层可能成为截图目标。需要保留标注时，可使用浮绘自己的截图或导出功能；只需要下层应用画面时，可先按“隐藏画布／显示画布”快捷键（默认 `` Ctrl+Shift+` ``）隐藏画布，截图后再显示。穿透模式不会隐藏标注；画布显隐保持当前编辑／穿透状态，按编辑／穿透切换快捷键可另行切换输入方式。

HDR 色彩准确性、压感笔、触控、OCR、录屏、滚动截图、云同步和上传不在首版范围内。
