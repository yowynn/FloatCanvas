# 浮绘 FloatCanvas 使用指南

简体中文 | [English](User-Guide.en.md)

本指南对应 Windows x64 **0.4.0** 源码。已发布安装包见 [Releases](https://github.com/yowynn/FloatCanvas/releases)，版本变化见[更新日志](../CHANGELOG.md)。较早版本的界面和功能可能不同。建议将重要工作另存为工程文件。

在画布上按下鼠标开始绘制或移动后，整次拖动由画布处理；即使经过工具条或在按钮上松开，也不会触发按钮。从工具条上按下鼠标，则由工具条处理，不会在画布上留下笔迹。

界面支持自动跟随 Windows、简体中文和 English，可在设置中选择，保存后重启生效。

浮绘把标注和图片留在屏幕上。进入编辑模式时绘制和调整；切换到穿透模式后，画面保留，可以继续点击、拖拽和滚动下层应用。

## 前景、主画布与背景

图层窗口顶部可以选择创作画布，默认是主画布。前景画布和背景画布固定在屏幕平面；主画布可设置透视。画面始终按背景、主画布、前景的顺序合成，鼠标演示效果显示在最上方，不属于图层。

图层列表和选择操作仅作用于当前根画布，组内仍使用面包屑导航。切换根画布不修改内容，会回到目标根顶层并清空选择，不记忆各根的进入路径和选择；新建、粘贴、文字、截图及置入内容写入当前根。打开画布工具会回到主画布设置透视与网格。清空当前画布仅清空当前根的内容，可以撤销；新建画布创建整个空工程。

历史工程兼容打开，原有内容和画布设置全部保留在主画布；保存后使用 v20 格式，需要新版本打开。完整工程保存三根内容及其独立预览配置；主画布平面内容导出只含主画布。将 `.floatcanvas` 或 `.floatprefab` 置入或链接为子工程时，只取源主画布的图层，忽略源前景、背景以及画布参数对宿主的影响。源画布参数仍保留给独立编辑和预览使用。“预览扭正”处理四点框内的屏幕合成截图，可包含前景和背景的可见像素，但不改变这些原图层。

## 启动与切换

0.3.0 提供 Windows x64 ZIP；0.3.1 新增 EXE 安装程序，同一版本同时提供无签名 ZIP 和 EXE，各附独立 `.sha256` 校验文件。两种方式使用相同程序文件：

- **安装版**：运行 `FloatCanvas-<version>-win-x64-Setup.exe`，选择“仅为我安装”或“为所有用户安装”。首次默认当前用户，目录为 `%LOCALAPPDATA%\Programs\FloatCanvas`；系统安装默认使用 Program Files，需要管理员确认，并为所有用户创建入口。可选择其他目录，但系统安装目录必须让所有使用者都有读取和执行权限，个人账户的私有目录可能不适用。两种范围均可选桌面快捷方式，不自动开启登录启动。
- **ZIP 版**：解压到当前用户可写的本地目录，保留全部文件，运行其中的 `FloatCanvas.exe`。

同一 Windows 用户使用的两种方式默认共用 `%LOCALAPPDATA%\FloatCanvas` 中的配置、预设、印章和历史；系统安装不把不同用户的资料合并。发行包均不附带 .NET 运行时或调试符号文件（PDB）；电脑已有兼容的 **.NET 10 Windows Desktop Runtime x64** 时可直接启动。

**安装版的流程**：

1. 选择简体中文或 English；首次默认跟随 Windows 显示语言。标准向导、运行时检查和错误说明使用所选语言。
2. 选择安装范围、阅读欢迎说明。已有兼容的稳定版 **.NET 10 Windows Desktop Runtime x64** 时直接跳过运行环境页；只有 x86、其他主版本、预览版、普通 .NET Runtime 或 ASP.NET Core Runtime 均不能替代。
3. 缺少运行环境时，点击“下载并安装 .NET”。安装器从微软下载正确的运行时、检查文件完整性，再执行安装。必要时完成 Windows 管理员确认；即使浮绘只安装给当前用户，共享运行时的安装仍可能需要管理员权限。安装结束后自动重新检测，通过后继续安装浮绘。下载失败、取消或安装失败可以重试，也保留手动下载与重新检测入口；若需要重启，会提示先保存工作，安装器不会自动重启电脑。
4. 阅读许可证、选择安装目录，以及是否创建桌面快捷方式，确认后安装。桌面快捷方式首次默认不勾选，开始菜单入口会正常创建。
5. 完成页默认勾选“启动浮绘”；保留勾选并点击完成即可启动，也可取消后稍后从开始菜单打开。

静默安装同样检查运行时；缺少时默认返回错误，不写入应用文件或卸载注册。只有显式传入 `/INSTALLRUNTIME` 才允许静默流程下载并安装共享运行时，仍可能需要管理员确认。`/CURRENTUSER` 和 `/ALLUSERS` 选择安装范围；`/NORESTART` 禁止自动重启。静默安装完成后不会自动启动浮绘。

**ZIP 版**缺少兼容运行时时，启动程序会显示 .NET 安装提示。点击 **Download** 打开微软官方下载页面，下载并运行 **Windows Desktop Runtime x64** 安装程序，安装后再次运行 `FloatCanvas.exe`。也可从 [.NET 10 官方下载页](https://dotnet.microsoft.com/download/dotnet/10.0)手动选择该运行时。无需 SDK；普通 .NET Runtime、ASP.NET Core Runtime 和 .NET Framework 不能替代所需的桌面运行时。

在**设置 → 性能与系统 → 全屏覆盖模式**中选择模式，保存后重启生效：

| 模式 | 行为 |
| --- | --- |
| 自动（默认） | 优先增强；本次检测或初始化失败时回退普通，可恢复的运行故障也可回退。 |
| 增强 | 直接增强，不做能力探测或自动回退；失败时直接报错。 |
| 普通 | 直接使用普通桌面窗口，不加载或检测增强接口。 |

自动模式每次启动重新检查当前接口能力；历史异常、诊断记录写入失败和探测超时不代表当前电脑不支持，探测超时后仍尝试实际初始化。自动模式运行中出现可恢复的输入接口故障时，会先释放输入，再以同一画布重建桌面界面，保留资源、文件绑定和撤销记录。也可从托盘选择“改用普通桌面模式”。普通模式保留绘画和文件功能，但可能无法覆盖部分全屏应用。

浮绘不会因绘制缓慢、界面长时间未响应或输入释放失败而主动结束进程；未响应应用的等待或关闭由 Windows 和用户处理。自动增强模式下，`Ctrl+Alt+Shift+F12` 请求正常释放输入；界面忙碌时，该请求会等待界面恢复处理，不会因此强制关闭浮绘。

打开 Windows 系统截图或 ShareX 全屏截图／编辑界面时，浮绘会退出编辑，让截图界面覆盖完整浮绘画面，避免实时画布继续叠在冻结截图和工具条影像上。截图期间不接管编辑输入，结束后恢复实时画布；重新编辑仍需点击浮动头像或使用编辑快捷键。自动交接仅支持这两个截图产品，普通设置和非全屏编辑窗口不触发。对其他先冻结画面的截图工具，可等选区界面出现后，再用画布显隐快捷键隐藏实时画布；截图完成或取消后，再按同一快捷键恢复显示。浮绘自身可见工具与画布的排序单独维护。

需要绕开增强接口时，先退出浮绘，再运行 `FloatCanvas.exe --desktop-mode`；它优先于保存的模式，也可用于强制增强启动失败后打开设置。`--retry-fullscreen` 为兼容旧命令保留，临时选择自动检测。两个参数不能同时使用，也不会修改保存的模式或画布数据。原生崩溃或卡死不能保证原地恢复，未保存内容可尝试从历史画布恢复。增强接口按实际可用性初始化，已验证的系统环境不代表所有 Windows 版本或全屏呈现方式都已通过验收。

1. 在欢迎界面选择“开始绘制”，或按 `` Ctrl+` `` 进入编辑。
2. 再按 `` Ctrl+` `` 返回穿透。工具条消失，标注仍显示，下层应用恢复操作。

每次正常启动在屏幕中央显示欢迎页，并使用空白画布，不自动展开上次的标注或截图。点击关闭、开始绘制或按切换快捷键进入绘制后，欢迎页关闭，本次启动不再自动显示。检测到历史记录时，欢迎页显示最近保存时间及“查看历史，继续上次工作”入口。也可单击工具条左侧应用图标，选择“文件 → 恢复历史画布…”，或使用托盘中的同名入口。打开历史列表会关闭欢迎页；双击条目与“恢复该版本”按钮效果相同。恢复成功后显示画布并进入绘制模式。

欢迎页用“绘制模式 / 穿透模式”和“隐藏画布 / 显示画布”说明两组快捷键，底部显示版本与带红色爱心的作者署名。隐藏画布不会清空内容。画布显隐与编辑／穿透独立，切换编辑不会自动显示已隐藏的内容；显示画布也不改变当前模式。隐藏时可调整画布或新增内容，操作中只预览本轮新内容，确认后自动显示完整画布；取消则保持隐藏。旧图层在隐藏期间不能被选中或移动。

标注在当前绘图范围内固定于屏幕位置，不会跟随网页滚动或游戏中的物体移动。

新配置的默认绘图范围为**全部屏幕**，也可选择**仅主屏**来限制标注和截图范围。已有保存的范围选择保持不变。切换到其他应用时，浮绘会进入穿透。

从“主菜单 → 设置…”打开设置，在“绘图范围”依次选择“全部屏幕”、“仅主屏”；连接多个屏幕时，分隔线下还列出“屏幕 1”、“屏幕 2”等具体屏幕，保存后立即生效，无需重启。启动参数 `--primary-screen` 或 `--all-screens` 可覆盖本次运行范围，不改变保存的偏好，二者不可同时使用；通过参数指定范围时，本次运行继续以该参数为准。屏幕连接变化会刷新已打开的范围列表；临时回退不会覆盖已保存或尚未保存的屏幕选择。具体屏幕按设备标识保存；断开时临时回退主屏，重新连接后恢复该屏幕。

选择具体屏幕时，画布以该屏幕中心为参考；“仅主屏”和“全部屏幕”以主屏中心为参考，不使用整个桌面的中心。切换范围或在另一屏幕打开工程时，内容按相对参考中心的位置显示：在屏幕 A 中心绘制的矩形，切到仅屏幕 B 后显示在 B 中心；从仅屏幕 B 切到全部屏幕后显示在主屏中心。对象的尺寸、几何和撤销记录不因屏幕切换而改写，编辑窗口的默认位置也遵循当前参考屏。完整混合 DPI 与物理热插拔体验仍待实机验收。仍完全落在当前范围外的对象，可用“主菜单 → 画布 → 将标注移回可见屏幕”找回。

编辑模式由浮绘接收普通窗口的键盘和鼠标消息；没有绑定工具的字母也不应发送给下层应用。切到其他应用会收起编辑工具并进入穿透，标注继续显示。进入编辑时若无法取得输入焦点，会保留穿透并提示原因。

增强编辑模式也会隔离空格等普通按键及浮绘快捷键，避免触发资源管理器中的 Peek 预览等下层应用操作。文字仍使用当前输入法；`Alt+Tab`、Windows 快捷键、锁定键和音量／媒体键仍可使用，切换应用时退出编辑。

浮绘内部窗口之间切换、完成重命名或关闭面板，不会退出编辑或收起工具条。单独关闭子面板时返回仍可用的父窗口；点击画布则同时收起相关临时子层和未固定面板，并正常处理这次画布操作。固定面板保留；重命名、删除确认等模态对话框需要先确认或取消，期间不能绘图。

退出编辑时仍打开的固定面板会在下次编辑时恢复。手动关闭工具配置或画布设置会重置固定；图层窗口始终按固定窗口处理。有关联的子窗口保持在来源窗口之上，同级面板按最近焦点排序。

从其他应用进入编辑时，会等待仍按下的键盘按键和鼠标按钮释放，再申请输入接管并显示工具条，避免下层应用残留按下状态。若已启用浮动头像，等待期间头像保持显示，工具条出现时再隐藏头像。

使用增强输入时，若超过 2 秒仍检测到按键按下，本次进入会取消，当前工程与撤销记录保留。托盘提示和浮动头像的悬停提示会列出相关按键；按下并释放这些键，再点击头像或使用编辑快捷键重试。该提示在成功进入编辑后清除。浮绘不会向其他应用模拟松键，也不会因此更改覆盖模式。

所有工具切换命令的主键和备用键都支持临时使用，包括自行绑定的工具。仅短按且未进行鼠标操作时正式切换；按住超过 250 毫秒或已进行鼠标操作时，松开返回。连续按下多个工具键时，以最后按下的键为准。导入图片、打开窗口等动作命令不适用。

文字直接在画布上编辑；切换窗口、图层、工具或进入穿透时自动提交，文字保留在画布中。`Esc` 取消本次文字编辑。

| 快捷键 | 作用 |
| --- | --- |
| `` Ctrl+` `` / `` Ctrl+Shift+` `` | 编辑/穿透切换；画布显隐 |
| 工具切换键（如 `V`、`B`、`H`、`E`） | 短按正式切换；按住临时使用，松开恢复原工具及参数；正在绘制、编辑文字或截图时，先完成当前操作 |
| `Ctrl+Z` / `Ctrl+Shift+Z` 或 `Ctrl+Y` | 撤销/重做 |
| `Ctrl+A` / `Ctrl+Shift+A` | 全选/取消选择 |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 复制/剪切/粘贴；剪切先确认复制成功再删除 |
| `Ctrl+D` / `Delete` | 复制副本/删除选择 |
| `Ctrl+G` / `Ctrl+Shift+G` | 成组/解组 |
| `Ctrl+[` / `Ctrl+]` | 下移/上移一层；加 Shift 置底/置顶 |
| `Ctrl+S` / `Ctrl+Shift+S` / `Ctrl+O` / `Ctrl+N` | 保存/另存/打开/新建画布 |
| `Ctrl+0` / `Ctrl+1` / `Ctrl+2` / `Ctrl+Shift+0` | 适配内容/100%/适配选择/重置视图 |
| `F4` / `Ctrl+L` / `Ctrl+,` | 工具参数/图层/设置 |
| `~` / `+` | 印章库/保存选择为印章 |
| `Ctrl+Shift+P` | 搜索命令；未绑定命令也可在这里执行 |
| `Enter` / `F2` | 画布选择的属性/重命名 |
| `Tab` | 普通编辑操作中折叠/展开工具条；不遍历控件焦点 |
| 方向键 / `Shift`+方向键 | 移动选择 1/10 个文档像素 |
| `Ctrl+PageUp` / `Ctrl+PageDown` | 画布不透明度增加/减少 5% |
| `1`～`9`、`0` | 选择十个印章槽；空槽不执行 |
| `Esc` | 逐级取消局部输入、手势、选择、编辑层级，最后退出编辑 |

中键拖动平移视图，Ctrl+滚轮围绕鼠标缩放，Ctrl+中键上下拖动连续缩放。Space+左键也可平移。普通滚轮和 Shift+滚轮不改变画布视图。查看不改变作品或内容撤销记录。

选择工具中 Ctrl+点击深入选择组内元素，Shift+点击增减选择，Alt+拖动复制；Alt+单击不复制。拖动对象时 Shift 约束方向，矩形类创建与缩放时 Shift 临时反转比例锁定。普通缩放固定对角，Alt 缩放固定中心；Alt 创建矩形类以落点为中心。右键在活动手势中只取消该手势，空闲时打开上下文菜单。未定义组合不会忽略多余修饰键执行其他动作。

普通编辑控件上的 Space 用于临时平移，Tab 折叠/展开工具条，Enter 执行编辑命令；Shift+Tab、F6 不进行隐藏的焦点遍历。文本、搜索、重命名及输入法优先接收文本按键。数值滑轨方向键按属性步长调整，Shift 精细、Ctrl 粗调、Ctrl+Shift 精细，计数型最小步长为 1。PageUp/PageDown 粗调，Home/End 到滑轨端点；合法轨外数值不会被钳回。按住调值到释放是一轮操作，Esc 回滚。图层/印章列表保留局部导航、重命名与删除；印章库 Ctrl+N 保存印章、Ctrl+F 搜索。菜单、下拉及模态窗口不把按键传给背后的画布。

设置中的快捷键编辑器可按名称或实际键位搜索，录制主键/备用键、清空、恢复默认、导入/导出 JSON。只有一套默认方案；自定义覆盖保存后立即生效，工具提示显示实际绑定。组合精确匹配，额外修饰键不会隐式触发；工具切换、删除、复制、开窗不连发，移动与撤销/重做可长按。清空画布默认无绑定，可在菜单或命令搜索执行。

全局保留上述两个默认快捷键，另提供默认未绑定的“开启/关闭鼠标演示”和“进入区域截图”。鼠标快捷键直接切换鼠标演示总开关；键盘演示由可见图层决定是否采集，不另设暂停快捷键。工具快捷键只对应实际工具入口，箭头、圆角矩形等样式在工具预设中选择。快捷键帮助表只显示已绑定项目，未绑定的可配置命令仍可在设置中录制。全局录制支持清空并检测冲突，注册失败恢复原可用集合；录制时暂停普通全局命令。Ctrl+Alt+Esc 为固定紧急释放键，系统离开组合与 Win 键保留给 Windows。

全局区域截图先冻结当前屏幕并显示暗色选区，沿用截图工具的形状与描边配置；不使用工具的截取层级选项。完成后显示画布、进入编辑并置入截图，保留原工具。隐藏画布时截取桌面，显示画布时截取合成画面；透视画布中的矩形与圆形选区仍沿画布平面生成。Esc 或右键取消，不改变原模式。印章入口的 ~ 与 + 标签分别表示反撇号键和等号键，均不需要 Shift。

“登录 Windows 时启动浮绘”默认关闭，勾选并保存后随当前用户登录启动，在托盘中等待，不自动进入编辑模式。取消勾选并保存即可关闭。

画布内容、透视网格和效果预览在独立线程绘制，选择框、透视手柄和控件响应保持在界面线程。预览忙碌时会跳过中间状态，完成后再读取最新值；松手后的最终值会保留。复杂画面允许延迟更新，操作框仍跟随当前操作。

简单与复杂画布共用这套后台机制。界面保留已经完成的内容，只传递变化的像素块并刷新受影响区域；仅移动或取消选择框不会重绘画布内容。动画时间信息和印章悬停预览也在后台准备。

设置中的“优先使用 GPU 加速”默认开启，已有配置也默认开启。动态模糊、马赛克和图片中的模糊／马赛克等滤镜会触发后台 GPU 路径；选用 GPU 时，这一帧的整幅画布（图形、文字、图片和滤镜）都在 GPU 上绘制，并非只处理某个滤镜。普通标注、小型动图等轻量画布使用 CPU 缓存，减少额外的读回开销。界面合成已完成的预览像素和当前操作框。取消勾选则全部使用 CPU。保存后生效，无需重启；GPU 不可用或绘制失败时自动回退 CPU，切换不改变画布内容。

设置显示最近一帧实际后端、选择原因、可用 GPU 设备，以及最近绘制耗时和本次运行的 GPU／CPU 帧数。空闲时无需持续生成画布帧，查看状态也不会触发绘制。失败的详细原因可在 `diagnostics.log` 中查看。

GPU 绘制不代表整个程序只在 GPU 上执行：图片与动画解码、桌面采集的像素读回和最终窗口提交仍包含 CPU 工作；当前 GPU 画布也需要读回到窗口像素缓冲区。因此强制让轻量场景使用 GPU 未必更快，实际收益取决于设备与画布内容。

切换快捷键使用 Ctrl／Alt／Shift 组合；Win 和系统离开组合保留给 Windows。单纯按下 Win 不会立即退出编辑，`Win+空格` 可在编辑控件或保存文件名时切换输入法；实际打开开始菜单或切换到其他应用时仍释放输入。`Ctrl+Alt+Esc` 保留为紧急释放输入。界面无响应或输入接管中断时会回到穿透，不会向下层重放先前的绘图按键。

欢迎页关闭后，可从“主菜单 → 帮助 → 打开欢迎页面”或托盘菜单重新打开。在编辑模式中选择此项，会先退出编辑，再将欢迎页带到前台；进入编辑时会关闭欢迎页。点击左下版本号检查更新，点击右下署名打开 GitHub 项目主页。

## 设置与浮动图标

设置按“常规与外观”“画布与历史”“快捷键”“性能与系统”分类，右侧内容独立滚动，底部始终保留取消和保存。取消会丢弃本次设置草稿；无效的历史上限会切换到对应分类并提示。系统集成操作只在明确点击相应按钮时执行。

“显示浮动图标”默认开启，可从主菜单、托盘菜单或“设置 → 常规与外观”切换。穿透模式下，单击图标等待双击判定后进入绘画，右键立即进入绘画；两者都不会打开主菜单。双击与编辑模式一致，只切换画布显隐并同步睁眼／闭眼，保留当前模式和工具条折叠状态。显示或拖动图标不会抢走当前应用焦点。

穿透图标缩小为编辑头像的 75%，并带有“穿透”标识；工具条收起后，仍可通过大小与标识区分两种模式。标识只说明当前状态，不是按钮；睁眼／闭眼只表示画布显示／隐藏。

拖动图标可调整位置，位置在本次运行中保留。轻微抖动仍按单击或双击处理。

编辑模式下，右键按下头像立即打开主菜单。菜单已展开时，左键按下头像立即关闭菜单；这次按压仍可继续组成双击以切换画布显隐，或越过拖动阈值开始移动工具条。单击关闭菜单后不会再延迟重开。

## 检查与安装更新

点击欢迎页左下角的版本号打开“检查更新”。打开面板后会自动检查[浮绘 GitHub Release](https://github.com/yowynn/FloatCanvas/releases)，显示当前版本、可用的新版本和更新说明；点击“重新检查”可再次获取。面板底部始终保留[项目主页](https://github.com/yowynn/FloatCanvas)链接。

更新说明跟随软件语言，按新功能、改进、修复和兼容性提示分组。跨版本更新会汇总当前版本之后到目标版本之间的日志，每条标明来源版本；历史旧格式统一放在“历史更新”。部分日志缺失或读取不完整时会明确提示，不妨碍安装已找到的更新包；“查看更多日志”可打开完整记录。

面板底部始终提供“手动下载安装包”。自动检查、下载或安装失败，或程序目录缺文件／不可写时，点击它打开官方发布页；已找到目标版本时直接打开该版本。先保存作品并退出浮绘，再运行 `Setup.exe`，或将完整 ZIP 解压到新目录；保留个人资料和工程文件。重启后的更新失败提示也提供打开发布页的选择。

当前用户安装或 ZIP 版存在可用更新时，点击“立即更新”。应用显示下载进度，校验下载的文件，并在保存当前画布的恢复数据后退出、替换程序，再自动重启并恢复工作。设置、预设和画布数据保留。下载期间可以取消或关闭面板，继续使用当前版本；下载或校验失败不会替换程序，替换失败时会尝试恢复原版本并说明原因。

当前用户安装和 ZIP 版需要位于**当前用户可写的本地目录**。它们下载官方 ZIP 更新；安装版同时维护 Windows 卸载版本和最新文件清单，因此更新新增的程序文件仍可正常卸载。ZIP 更新保留原卸载器本体；新版安装器或卸载界面的变化需要运行新版 Setup 才会获得。请保留发行包全部文件，ZIP 更新不会代为安装 .NET 运行时。

使用 `FloatCanvas.exe` 启动程序和创建快捷方式；`FloatCanvas.Host.exe` 是内部宿主。ZIP 文件夹保留旧版本名称不影响更新。若更新面板指出某个文件缺失或为空，请从**相同版本**的完整官方发行包恢复文件，或将完整发行包解压到新目录；修复后点击“重新检查”。启动时显示的更新失败通知会注明上次尝试安装的版本，可能来自此前的更新；请保留相关备份，直到确认程序和资料正常。

**所有用户安装**使用“下载并打开安装程序”：下载并校验对应版本的 Setup，先保存当前画布，再由安装程序请求管理员确认。只有向导确认初始化成功后，浮绘才退出；取消管理员确认或初始化失败会保留正在运行的浮绘。按向导更新原系统安装位置，完成页保留“启动浮绘”勾选可用原用户身份恢复工作。此流程不会让普通浮绘进程或 ZIP 更新助手获得管理员权限。若新版本只有 ZIP，会显示原因并提供该版本的发布页。普通 ZIP 版位于只读、网络或开发目录时，仍需改用当前用户可写的完整发行包目录。

“接收预览版本更新”默认关闭，无论当前运行正式版还是预览版，都只提示更高的正式版本；开启后也提示更高的预览版本，不会降级。此偏好可在更新面板直接修改并保存，也可在“设置 → 性能与系统”中修改。切换更新面板中的开关会重新检查；正在检查或下载时暂时禁用开关。

没有可用更新时，仍显示与当前版本匹配的发行日志，当前版本为预览版时也一样，不受上述开关影响。若该版本没有公开日志，会显示暂无说明。网络失败或 GitHub 暂时限制请求时显示对应状态，并保留项目链接。

没有“检查更新”入口的旧版本，需要先从 GitHub Release 手动下载并安装一次包含此功能的发行包，此后即可在应用内更新。

## 工具条与工具参数

头像戴皇冠表示编辑；双手捧着皇冠、没有笔表示穿透，不再遮罩“穿透”文字。新组沿用原头像的画幅和其他轮廓，仅调整眼睛、双手与皇冠位置并移除笔。睁眼表示画布显示，闭眼表示隐藏；同一模式的两张图仅眼睛不同。托盘也显示当前模式和画布显隐状态。

托盘头像单击左键后，等待双击间隔结束再进入编辑；双击左键切换画布显隐。右键仍打开托盘菜单，快捷键提示显示在加宽菜单的右侧。

新建画布需要确认时，气泡位于按钮上方，小尾巴指向同一个确认按钮，气泡不会高过头像皇冠。

主菜单的功能分组、欢迎页、设置与悬浮头像使用各自的图标；托盘中的同一命令保持相同图标。

“更多工具”收起时，入口显示当前选中的额外工具图标；切换其他工具后恢复“工具托盘合上”图标；展开时显示橙色“工具托盘打开”图标，细线连接扩展工具条。

隐藏画布期间也可清除内容；再次显示会先更新画面，再恢复可见，避免闪回旧内容。

工具参数与图层属性输入无效时保留当前有效值；改回有效数值、离开输入区域或重新打开面板后会移除过期提示并恢复当前值。忙碌时保留尚未应用的属性草稿，待操作完成后可继续应用。应用控件不额外显示键盘焦点框或焦点高亮；文字光标、选中文字、悬停、拖动、工具／模式／预设选中状态及错误反馈仍保留。Windows 原生文件对话框使用系统样式。

主菜单及右键菜单使用对应操作的图形。“切换为穿透”与工具条的“完成”使用同一对号；“检查更新”使用循环箭头。印章固定子菜单和快捷槽也有对应图标。

工具条左侧是应用图标，上下两排按列对齐：

- **上排**：选择、橡皮两项基础工具，随后是自由画笔、荧光笔、直线、矩形、圆形、文字、序号、符号、Emoji、更多十项入口。“更多”提供模糊、马赛克、键盘演示和鼠标演示，文字和序号各有独立入口。
- **下排**：印章库、新建印章，随后是与十项绘图入口对应的 `1`～`0` 印章方框；右侧为状态屏。空槽显示淡框，已绑定槽使用稍明显的淡框，当前快捷印章显示蓝框。

印章库按钮空闲时与“新建印章”一样显示灰色背景；从库中选用印章时显示该印章的缩略图和蓝色选框，切换到其他工具或快捷槽后恢复灰底。再次点击仍打开印章库。普通按钮和面板关闭按钮在悬停、按下时有更明显的背景反馈，浅色和深色主题保持一致。

右上方依次提供画布工具；导入、截图、裁剪；属性和图层；撤销／重做、新建空白画布、不透明度、显隐和完成操作，各组之间用分隔线区分。裁剪仅在单选一张可编辑图片时启用，禁用时仍可悬停查看提示。显隐按钮睁眼表示画布可见，琥珀色强调的闭眼表示已隐藏，应用角色图标也同步闭眼，睁闭状态仅眼部变化；托盘和任务栏图标同步切换；悬停提示显示下一步操作。模糊和马赛克从“更多”打开。不透明度滑块占两个按钮宽度；状态屏跟随浅色／深色主题，长文字默认省略，鼠标停留时滚动显示。工具条首次在主屏顶部水平居中，皇冠贴屏幕顶。工具条展开状态、窗口位置和大小只在本次启动内保留，重启后恢复默认布局；自定义快捷键和其他偏好仍保留。

- **单击应用图标**：打开主菜单。单击会等待系统双击间隔，以免和双击动作冲突；右键可直接打开菜单。
- **双击应用图标**：显示／隐藏画布并同步睁眼／闭眼；保留编辑模式和工具条折叠状态。
- **按 `Tab` 或选择主菜单第一项**：展开／收起工具条；菜单按当前状态显示“收起工具条”或“展开工具条”，并标注 `Tab`。收起后仅保留图标，仍可右键打开主菜单展开。`Tab` 在普通编辑操作时生效，按住不会连续切换，也不在按钮之间移动焦点；文字输入、输入框、菜单和对话框中不触发工具条切换。Windows 系统文件对话框保留原生的 `Tab` 导航。
- **拖动应用图标**：移动工具条，并记住位置。
- **单击工具图标**：切换当前工具。停留可查看名称与快捷键；主菜单的“绘图工具”和“图像与效果”也提供工具入口。
- **再次选择当前工具**：点击同一图标或再次按对应工具键，打开／关闭工具参数板。参数板打开时切换工具，会跟随显示新工具的设置。
- **按 `F4`**：打开当前工具共用的参数窗口；已打开时保持打开，选择和印章也遵守这一规则。画布沿用同一窗口的位置、大小和固定状态。参数和预设分别滚动，错误显示在底部；需要说明作用对象时，目标标识紧跟固定工具名称。

拖动时按当前绘图范围实时限制工具条位置：展开时，应用图标和整条工具条都保持在实际显示区域内；收起时，整个图标保持在区域内。选择“仅主屏”或某块屏幕时，不能越过所选屏幕边界；选择“全部屏幕”时，可以跨越相邻屏幕连续的接缝，但不会占用屏幕之间的空隙。靠近边缘展开时会自动调整位置，避免工具条右端或下缘移出屏幕。如果所选显示区域本身小于完整工具条，则保留工具条原有大小，并优先让图标保持可操作。

工具参数窗口以当前工具名作为标题，正文显示简短描述，参数与预设并排展示。展开工具条时，首次打开位于工具条上方或下方；之后可自由拖到其他位置，移动或收起工具条不带走该窗口。工具条收起时，再按当前工具键，可在鼠标附近打开，并限制在屏幕范围内。未固定时，点击画布或其他界面会关闭；固定后可继续绘图。`Esc` 先关闭颜色子面板，再关闭未固定的工具窗口；进入穿透时隐藏编辑面板。

直线工具统一设置起点和终点的箭头，可组合无箭头、单向或双向箭头，并选择实线、虚线或点线。矩形通过圆角半径变为圆角矩形；锁定宽高比后按配置比例绘制，正方形或圆可使用对应的 1:1 预设。符号工具提供三角形、星形、心形、勾叉等可改色图案；Emoji 工具提供表情选择，单击按“大小”插入，也可拖动确定本次尺寸；大小既可精确输入，也可在更大范围内拖动滑块。线型与箭头下拉选项带有图示，线宽下方显示粗细预览。闭合形状的描边向内占用指定线宽，不扩大外轮廓；描边与填色分别占用各自区域，半透明时不叠加变深。虚线从完整实线描边中裁去间隔，点线保留完整圆点。

常用工具键：`V` 选择、`E` 橡皮、`B` 自由画笔、`H` 荧光笔、`L` 直线、`R` 矩形、`O` 圆形、`T` 文字、`N` 序号、`S` 符号、`J` Emoji、`C` 画布。`A` 未绑定工具；`Ctrl+A` 仅全选，不改变当前工具。`M` 展开或收起工具条上方的“更多工具”行；展开后切换工具、打开参数或点击画布不会收起，只有再次点击“更多”（或其 `M` 快捷键）才收起，扩展行不设独立关闭按钮。收起后，当前额外工具的图标仍显示在“更多”位置。额外工具暂不分配独立快捷键。`~` 打开印章库，`+` 保存当前选择为印章。输入文字时，这些字母用于文字输入。

上排快捷键角标统一压在右边框顶部，下排统一压在左边框底部；画布 `C`、置图 `I`、截图 `P` 与其他工具共用同一布局。相邻图标的大小与线条粗细保持一致。可在设置取消“显示工具快捷键角标”，同时隐藏上下两排的字母、印章数字等角标；快捷键本身仍有效，偏好会保留到下次启动。

直线和箭头通过拖动绘制，不提供单击插入的默认长度或角度。矩形、椭圆和符号可设置默认宽高，在空白处单击时以点击位置为中心创建；拖动也可自行确定尺寸。矩形、椭圆、符号、序号和 Emoji 使用 **6 个逻辑像素**的拖拽容差，按按下时所在屏幕的缩放比例换算；容差内的轻微抖动仍按单击处理，达到容差后才按拖拽定大小。锁链开关决定是否保持配置的宽高比，按住 `Shift` 临时反转约束；图片裁剪及滤镜区域的等比约束为 1:1。截图的矩形／圆形选区默认自由比例，仅按住 `Shift` 时约束为 1:1，工具配置中没有持久等比开关。工具参数的数值可直接输入，也可拖动对应滑块调整；输入框、下拉框、颜色谱面和滑块操作期间，按键用于当前控件，不切换工具或选择印章。

符号工具提供五种官方样式：标准轮廓、浅色填充、实心填充、虚线轮廓和绿色强调，均以三角形示范、默认尺寸 **72×72**。选定样式后，在形状选择器中单击即可切换到任一图形，保留整套配色、线型和尺寸。个人预设和已有对象保留原形状与尺寸。

序号和 Emoji 单击或轻微抖动时，仍按当前配置尺寸居中插入；按下后拖动则实时预览大小，松手完成。拖动起点作为选框一角，可向四个方向展开；默认整体等比缩放，序号保持圆形，Emoji 保持自身图案比例。拖动时按住 `Shift` 可临时分别调整宽高，松开立即恢复等比预览。本次拖动只改变新对象，不写回工具的配置尺寸或新图层的默认等比偏好，一次完成产生一个撤销步骤。

### 工具预设与颜色

序号的“配色样式”可选择实心、同色空心或双色空心。两种空心样式均不填充内部，可调整外框线宽；同色空心的外框和文字共用图形颜色，双色空心可分别设置图形和文字颜色。切换样式保留暂时隐藏的颜色。工具参数决定新序号的样式，图层属性可同时修改多个已选序号；样式与颜色随工程和个人预设保存。旧工程中的序号继续使用原有颜色与字号规则。

官方文字字号为 36；符号、序号和 Emoji 大小为 72；矩形、椭圆至少一边为 108。序号和 Emoji 的“大小”直接控制图形选中框，序号文字自动适配。工具参数不提供等比开关，新图层默认勾选保持比例，可在图层属性中取消以分别拉伸宽高及图案。序号的“图形颜色”使用前景色板，“文字颜色”使用背景色板。形状的“配色样式”提供“分离颜色”和“统一颜色”，图示随形状变化；统一颜色将边框与填充合并为继承边框色的单一“颜色”控件，切回分离颜色会恢复原有填充色。该状态随预设、图层和恢复数据保存。

官方预设与“我的预设”统一为每排五个、只显示预览的圆角方形图块，名称放在悬停提示中。每个工具至少有一个官方预设；官方预设全部展开。“我的预设”只显示当前工具，区域至少容纳四排，并随左侧参数高度填满右侧剩余空间；更多预设在区域内滚动，不会撑高窗口。

首次使用工具时采用该工具自己的默认参数，官方默认前景色为色板红（`#E03E3E`），填充保持透明，序号则默认使用白色文字。每个工具分别记住基础预设及完整的当前参数；切换工具、关闭参数窗口、切换编辑／穿透模式或退出重启，都保留这些改动。工具状态在本机自动保存，频繁修改约合并 500 毫秒写入；正常退出或更新重启前等待落盘。窗口位置仍在每次启动时重置，序号的“下一个序号”仍属于画布文档。

单击预设立即应用并选中，每个工具保持一个选中项。官方预设和“我的预设”都包含完整的工具参数；每次应用都会恢复该预设确定的颜色、线宽、线型及其他参数。官方预览始终反映固定的官方定义，旧版首次使用时保存的官方基线不再影响应用或预览。旧个人预设缺少后来新增的参数时，应用会将该参数恢复为默认值，不继承点击前的当前值。

继续修改参数时保留选中项；再次点击预设会恢复其完整参数。临时改动保存在该工具的当前工作状态中，切换工具或重启后仍可继续使用；只有覆盖“我的预设”才会更新其定义。修改工具参数不会改变已有对象或保存的工程。

点击“我的预设”旁的加号保存，右键预设可覆盖、重命名或删除，保存和重命名使用统一命名窗口。左键拖动可调整顺序，右键和拖动不应用预设。删除当前关联的预设后，只将关联回退到第一个官方预设，保留当前全部工具参数；若参数与官方预设不同，继续显示改动角标。主动点击预设时才应用该预设的参数。

拖动个人工具／画布预设、我的色板、印章或图层排序时，会显示跟随鼠标的半透明预览；预览可移出滚动区和原窗口，不抢焦点或挡住鼠标。每个空隙只有一条蓝色插入线，两端各有蓝点，首行和边缘也完整显示。多选图层一起移动，预览带数量角标；把印章拖到快捷槽上时，目标槽会高亮。松手提交，按 `Esc` 或切换窗口取消，拖动不会触发点击应用。

颜色在工具参数窗口或属性窗口中调整。前景色用于描边或文字，背景色用于适用形状的填充。主行左侧用圆角色值按钮打开二级面板，右侧十个常用色按两排排列，点击即可直接设置。小色块统一为直角弱边框；二级面板的最近使用和我的色板每排十个，间距随显示缩放对齐像素。

颜色面板是带标题栏和关闭按钮的所属窗口，保持在来源窗口之上，失焦时关闭。标题栏不提供固定按钮；左侧调整颜色属性，右侧显示最近使用和我的色板，每排十个。保存／重命名色板时，命名对话框归属颜色窗口，暂时禁用下方窗口，确认或取消后返回颜色面板。

点击色值按钮打开二级面板，使用饱和度／明度谱面、色相条、不透明度和最近 20 种颜色调整。选色谱面提供更充足的垂直选色空间；下方的色相条采用彩虹轨道和细长拨杆，可从轨道或拨杆按下并连续拖动色相，拨杆按下保持原值。可拖动“前景色／背景色”标题区域移动颜色面板。有效颜色立即应用到一级色块、工具预览或所选图层；关闭时仅将最终颜色记入最近使用一次，无需确认按钮。色块和工具预览保留不透明度，与所在界面底色混合，不使用棋盘格。点击父参数窗口只关闭颜色面板，父窗口继续保留，并正常响应该次点击。只使用描边与填充的工具直接通过颜色设置不透明度，不再重复显示工具不透明度。

“我的色板”可为当前颜色命名保存，左键拖动排序，右键覆盖、重命名或删除；色板较多时滚动查看。新建、重命名对话框保留其下方的颜色面板。自定义输入接受 `#RGB`、`#RRGGBB` 或 `#AARRGGBB`，例如 `#FF2383E2`；`#00000000` 完全透明。取色时临时隐藏工具条以外的面板，尖头取色指针旁的气泡显示当前屏幕颜色；单击画布确认，`Esc` 或右键取消。完成后恢复原面板并返回二级选色器。

右键一级颜色框或二级面板中色值输入框左侧的色块，可粘贴颜色，或从“复制”子菜单选择 `#RRGGBB`、`#AARRGGBB`、`rgb(R, G, B)`、`rgba(R, G, B, A)`、`hsl(H, S%, L%)`、`hsla(H, S%, L%, A)`。RGB 通道使用 0～255 的整数，HSL 色相为 0～360，饱和度和亮度使用百分比，函数中的 Alpha 为 0～1。复制的六种格式均可原样粘贴；不带 Alpha 的格式保留当前不透明度。八位 HEX 固定按 Alpha 在前解释，不猜测其他通道顺序；无效剪贴板文本会使“粘贴”置灰。左键二级预览色块直接复制 `#AARRGGBB`。两处控件复制成功后，色块旁会短暂显示“已复制”，无需等待悬停；一级颜色框菜单底部另有“置为透明”，直接设为 `#00000000`。打开颜色右键菜单或执行复制后，来源工具参数窗口、属性窗口或颜色面板保持打开；复制提示显示在来源窗口上方。

修改工具参数影响之后创建的元素；修改已有元素，请使用属性窗口。

## 绘制、选择和调整

- **选择**：点击或框选可见内容，文字留白、透明图片区域和空心形状内部不参与选择。`Shift` 点击增减选择；组合在当前编辑层级中作为整体选择，进入组合后可选择其中的子图层或子组合，也可按住 `Ctrl` 点击组内单个元素。印章工具也显示已有选框，刚放置的印章仍不自动选中。
- **移动和缩放**：除橡皮擦和画布工具外，各工具均显示已有选框。选框可见时，左键优先操作当前选区，模糊、马赛克、裁剪、截图和文字工具也一致；从框体或边缘拖动可移动，角点用于缩放，旋转手柄用于旋转。按住 `Ctrl` 隐藏并绕过选框，执行当前工具本身的操作。
- **Shift 移动**：拖动主体时按住 `Shift`，仅沿画布平面 X／Y 轴移动。约束始终经过本次拖动最初的起点，中途按下、松开再按下都不重设起点；不包含 45° 方向。启用透视时，画布轴可能与屏幕方向不同。
- **旋转**：拖动选框上方的旋转手柄，按住 `Shift` 以 15° 吸附。普通单图层选框随图层旋转；透视放置的截图使用画布平面上的矩形外框，多图层使用整体包围盒。
- **线条端点**：单选直线或箭头后，拖动端点调整。
- **Shift 绘制**：自由画笔、荧光笔和自由套索在按住 `Shift` 的时段预览一段直线，松开时固定终点并继续自由绘制；可以在一次拖动中反复按下和松开形成折线。直线、箭头、双向箭头及其端点调整、多边形套索的下一条边，按住 `Shift` 时约束为水平、垂直或 45° 的八方向。
- **文字**：选文字工具后点击画布空白处，直接出现选框和光标。`Shift+Enter` 换行，`Enter` 完成并保留实体选中；`Esc` 取消本次输入。拖动可选字，常规光标键、复制粘贴和文字撤销可用。文字工具点击当前文本框外会提交并开始新的文字层，`Ctrl` 点击即使在框内也新建。切换图层、工具或窗口会提交；使用文字工具时，双击已选文字的字形可再次编辑。序号通过属性面板修改。

未进入文字输入时，已选文字的选框内部与边缘均用于移动，角点用于缩放，旋转手柄用于旋转；双击文字进入输入后，文本内部用于定位光标或选字，边框仍可直接开始变换。改变文字框宽高后，会重新换行并将字号适配整个新框，不保留已消失的自动换行高度；手动换行与空段落仍保留。
- **序号**：单击按配置大小加入并选中下一个序号，也可拖动确定大小；松开完成后才递增，按 `Esc` 或取消拖动不跳号。按住 `Ctrl` 可从已有选框内继续创建。数字始终单行显示，过长时自动缩小以适配标记，不改变标记外框或工具的大小设置。删除某一项不会重排其他序号。
- **擦除**：橡皮按整个元素擦除，一次拖动可整体撤销。

闭合形状、文字、序号和表情插入后自动选中，可直接拖动、缩放或旋转，无需先切换选择工具；再次点击空白会创建并选中新对象。自由画笔、荧光笔和印章放置后不自动选中，便于连续使用。直线、单箭头和双向箭头需拖动创建，在绘制中及完成后均不自动选中或显示新笔画选框；仍可用选择工具手动选中，再移动、调整端点或旋转。按住 `Ctrl` 临时隐藏并绕过已有选框，可从重叠位置直接创建新元素；松开恢复选框。按下鼠标时确定本次拖动是创建还是调整，中途按下或松开 `Ctrl` 不会切换操作。

图层的等比缩放开关随工程保存；拖动选框时，按住 `Shift` 临时反转该开关。矩形、椭圆和符号未约束比例时，可独立调整宽高；二次调整保持实际几何、线宽与圆角。文字默认不约束比例，调整边框时会改变字号和换行以适配边框，后续编辑也保留该边框。文字和序号的字体可从系统字体下拉列表中选择并预览。

序号工具可设置开始序号和步长，新建画布从开始序号计数。更换序号预设或调整开始序号时，若当前序号等于旧开始序号，当前序号随新开始序号更新；两者已不相等时保留当前序号。此判定与是否已有图层无关，也适用于步长为 0 的序列，不改写已有序号图层。步长可为 0 或负数：0 连续放置相同序号，负数倒序计数。步长滑条为 -100～100，0 位于中间；开始序号、当前序号及图层序号的滑条仍从 1 开始，手填和图标拖动允许 0 或负数。到达整数边界后保持边界值，不绕回。“当前画布的下一个序号”独立保存在该画布中，可修改和撤销；切换工具、保存预设或程序设置不把它变成全局计数。调整“大小”会改变单击插入新序号的尺寸，拖动创建时以本次手势为准。

每种基础元素，包括自由曲线、文字、序号和图片，都保留为可选择的对象。

“属性”和“图层”是两个独立窗口，可从工具条或“主菜单 → 窗口”分别打开。属性窗口随选择自动刷新，输入有效的位置、宽高、角度、描边、填充、不透明度及文字设置时实时生效；短暂输入或离开字段会合并为一次可撤销操作，无需确认。多选时显示“选中多图层”，仅展示这些对象共同适用的属性；不同数值显示为空，改动后统一应用到所选对象。

组和共享实例提供独立的不透明度，作为子图层不透明度的乘数，保留各子图层原有设置。普通多选则把每个所选项设为输入值；混合值显示为空，支持撤销。保存使用工程格式 20，旧版程序不能打开新格式。

类型专属参数也可在属性中继续调整：模糊与马赛克的强度、符号的图形种类，以及序号和表情的字号。图片包含多个效果时，先从“效果”列表选择目标，再调整该项；其它效果及原作用区域保持不变。

这些工具窗口使用统一的悬浮面板：拖动顶部空白处移动，拖动边缘或右下角双斜线调整大小，右上角关闭按钮收起窗口；从原入口可再次打开。面板不提供最小化和最大化，双击顶部也不会放大。属性优先显示文字内容等不易在画布调整的项目，位置与尺寸放在最后；只显示当前选择共同适用的字段，底部保留状态提示。

双击画布中的图层，或选中一个或多个图层后按 `Enter`，会在鼠标附近打开属性；已显示的面板保持原位置。单击画布收起未固定面板后，仍需重新双击才能再次打开。文字编辑中的双击仍用于选字。属性右上角的固定按钮可保持面板显示；未固定时，移开焦点会收起面板，衍生颜色弹窗和子对话框仍属于同一个面板。关闭面板会重置固定状态。

固定按钮启用时，图标、边框和背景一起强调，与工具条显隐按钮采用相同的二态反馈。画布按钮的蓝框表示当前选中了画布工具；矩形／梯形图标分别表示透视关闭／开启，透视开启时保留琥珀色底和图标，未选中时还有琥珀色边框，选中后边框由蓝色覆盖。透视开关在参数板中调整。

拖动数值框左侧的 X、Y、W、H、角度或线宽标识，可以左右调整。属性名称只作说明，不响应拖动。`Shift` 精细调整，`Ctrl` 加速，松手提交为一次操作，`Esc` 取消本次拖动。单个普通图层的 X/Y 是其父组局部坐标中外接框的左上角；没有父组时就是画布平面坐标，启用透视后不等同于屏幕坐标。图片按本体位置计算，外侧描边不改变坐标数值；普通对象宽高沿自身方向计量，包含现有局部缩放但不含描边，透视放置的截图则显示不含描边的局部平面本体尺寸。修改宽高沿自身方向缩放，保留旋转角度；等比缩放时可以只改宽或高。路径某个方向的几何尺寸为零时，先调整端点再修改该方向尺寸。箭头可选择实心三角、开放箭头或菱形头部，头部尺寸设为 0 时随线宽自动调整。

图层窗口采用类似文件管理器的路径导航，列表只显示当前层级的直接成员。“主画布”层级只列其直接图层和组合；进入组合后，仅列出该组合里的图层和子组合。每种图层左侧均显示静态类型图标，六点拖动把手与名称垂直居中。同一级中上方的普通图层或组合显示在前，普通组合的内部图层作为连续整体参与排序。选中多个可编辑图层或组合后按 `Ctrl+G` 编组，`Ctrl+Shift+G` 解组；新组合收拢到所选内容原先最靠前的位置，保留内部相对顺序，可能改变与未选图层的遮挡关系。

点击组合的进入箭头、双击图标或文字以外的空白区域，或选中组合后按 `Enter`，会切换到组内列表并进入组内编辑。此时画布选择以该组内的子节点为单位，新绘制内容也放入该组。顶部面包屑显示“主画布 > 组1 > 组2”这样的完整路径，点击任一上级可直接返回；“上一级”按钮、`Left` 或 `Backspace` 返回一层。`Esc` 先退出一层，返回根层级后再按才收起窗口。属性中的“进入组内编辑”也可进入所选组合。

成员以父组为参照保留局部位置和变换；移动、旋转或缩放整个组会带动所有后代，不需要逐层改动成员。进入组内单选成员时，属性按父组局部坐标显示其位置和尺寸，便于局部精调；选中组合或多个节点时，位置和尺寸显示画布平面中的整体包围盒。画布拖动按屏幕和画布位置操作，再换算回成员的局部位置。组合或多选属性提供“变换中心”的“整体／各自”：整体围绕共同中心旋转、缩放，各自围绕各个所选节点的中心操作；每个所选组合仍是一个整体，若要分别操作其成员，先进入组合再多选成员。“旋转增量”表示本次增加的角度，每次提交后重新从 0 开始。

右侧眼睛和锁图标分别切换本节点的显示、锁定。隐藏或锁定组合会作用于全部后代，重新显示或解锁组后，各成员原有的显隐和锁定选择仍保留。单独锁定的成员不能直接编辑，但仍会随未锁定父组一起移动、旋转和缩放；父组锁定时，其后代也不能直接调整。隐藏或锁定的节点仍可在列表中选中。

普通图层、组合和共享实例都能重命名：双击名称的文字笔画，或再次点击已选名称的文字，即可开始改名；`F2` 和右键菜单也可使用。文字中的空白、字形内部的空洞和图标不算名称命中，双击这些区域沿用普通操作，组合会进入下一级。新建组合默认依次命名为“组合 1、组合 2…”，印章置入创建的组合使用印章名。`Enter` 或移开焦点保存，`Esc` 取消，留空恢复默认名称。名称随工程、恢复数据及撤销／重做保留。选择至少一个可编辑图层即可编组；删除、剪切或移走最后一个成员后，空组合及其空的祖先组合自动解散，撤销可一并恢复。存在选择时，标题栏模式开关左侧显示“定位到已选”，点击滚动到选中图层；若不在当前层级，先进入其父组。多次点击遍历全部选中图层，包括其他层级的选择：按列表从上到下，遇到组合先遍历其内部，再继续后面的条目；到末尾后循环，全部选择保持不变。右键菜单提供复制、删除、置顶、置底、编组和解组；关闭按钮旁的“？”可查看操作说明。

拖动每行左侧手柄到行间可调整顺序，拖到组合行中间可移入该组，拖到上级面包屑可移出；右键“移到上一级”也可移出一层。跨组移动保留内容在画布上的位置，但新层级和顺序可能改变遮挡。不能将组合移入自身或自己的后代，也不能向锁定组内移动。

旧工程的组合可能显示 `↕` 标志，表示“保留旧图层顺序”：成员仍可与组外图层交错叠放，层级列表不能完整表示这种遮挡。打开、浏览、进入编辑和保存都不会自动改变旧遮挡。右键“收拢为普通组”才将成员移到连续层级；这会保留组内相对顺序，但可能改变与组外内容的遮挡，可撤销。主动拖动或置顶、置底这类旧组也会将其收拢到新的整体层序位置。

普通组合各自拥有内容，复制普通组或放置普通可编辑印章会得到独立副本。选中内容后使用“创建共享定义”，可将它保存为本工程的一份预制体，并放置多个实例；实例各自保留位置、显隐和锁定，共享同一份内部内容。复制本工程中的实例继续共享定义；跨工程粘贴会携带完整依赖和图片资源。

普通组、工程内共享组合和链接外部文件的组合，进入后都在图层窗口列出当前层级的内部图层。组合操作区明确显示这三种来源；外部链接同时显示实际文件路径，工程资源列表也显示来源路径。工程内共享组合保存在当前工程中，不依赖一个外部文件；外部链接则连接到磁盘上的 `.floatcanvas` 或 `.floatprefab`，并保留离线快照。

图层窗口常驻两个画布显示按钮，根级和所有组层级均可切换。组合操作区显示当前已进入的组合；单选子组不会把配置目标切到该子组。切换显示方式保留当前列表层级，不提交草稿，也不产生额外撤销记录：

- **独立画布**：把当前组作为子工程，使用自己的原点、画布颜色、网格、透视和预览透明度；祖先及实例在宿主中的放置不参与独立视图。普通组、共享组和外链组在任意嵌套层级均适用。独立编辑的显示与拾取范围覆盖当前屏幕，保存的预览尺寸仍用于原有网格与透视参考，不会裁掉右侧或下方的编辑区域。根级只显示当前创作画布；前景、背景可设置各自的独立预览透视，回到根工程合成后仍为屏幕平面。
- **根工程画布**：显示完整根工程，并在其中选中和编辑当前组合的内部内容，包括尚未提交的嵌套组修改。选中框、拖动、旋转、缩放和撤销使用当前实例的实际放置与根画布透视；组外图层保留作上下文，不会跳出当前编辑层级。两种画布编辑同一份内容；切换不会提交共享或外链草稿，也不打开独立预览窗口。外链草稿总览中的窗口来源使用保留的画面，不接用草稿的实时窗口绑定。

编辑共享或外链草稿时，根工程总览中的画布参数不可修改宿主；请切到“独立画布”调整当前子工程自己的预览配置。点击画布工具时会提示这一原因。

普通组可在操作区直接“另存为预设”，导出组内内容及所需依赖为 `.floatprefab`，无需先转换为共享定义；导出不改变原组，主画布上的组位置和容器变换属于实例放置状态。共享组合也可导出。共享或外链组合提供“解除为普通组”，仅解除当前实例并进入该组，不改变其他实例或删除外部文件；内部草稿在离开该层级时提交；外部链接只读，转换为内部工程或普通组后再编辑。

图层窗口的“工程资源”支持放置、重命名、编辑、导出和清理未使用定义。双击实例图标或名称文字以外的区域，或选择“编辑共享定义”，进入内部图层列表，保留当前画布显示方式；通过返回按钮或面包屑退出内部工程时，一次提交到全部实例，可一次撤销；未修改退出不新增历史。外部链接只读。`Ctrl+Shift+S` 可将当前草稿另存为独立 `.floatprefab`，保留当前编辑和主工程；发生发布冲突时也可用它保留草稿。

“链接文件”可把 `.floatcanvas` 工程或 `.floatprefab` 预制体作为子工程使用，随本工程保留完整离线快照。源文件缺失时继续显示已有内容，可检查更新、更新链接或重新定位；进入外部链接保留源工程自身的画布和背景，并以只读方式浏览；需要修改时，选择“转为内嵌共享定义”或“解除为普通组”。源保存后更新已打开引用，打开工程时检查外链；正在操作或有安全冲突时保留快照并显示待更新。转为内嵌共享定义后保留实例同步关系，解除链接则只将所选实例转为普通组。

源文件暂时不可用时仍可进入组合，查看已接受的离线图层并切换两种画布。此时操作区显示只读提示，重命名、拖放和内容修改停用；保存或退出不会重建源文件，也不会发布缓存为新版本。需要独立修改时，先“解除为普通组”。

要建立可复用的文件，可以使用以下任一种方式：

- 整个画布：使用“文件 → 保存工程”或“另存为”，保存为 `.floatcanvas`。
- 普通组合：选中或进入组合，在组合操作区点击“另存为预设”，保存为 `.floatprefab`。零散图层也可先在“工程资源”中“创建共享定义”，再导出该定义。

在另一张画布点击工具条“置入”或按 `I`，即可选择这两种文件，将其作为链接子工程追加到当前编辑层级，保留原画布。也可从文件管理器拖住文件，按编辑／穿透切换快捷键进入画布编辑，再在目标位置松手；已处于编辑模式时可直接拖入。图片和工程可混合置入，整批可一次撤销；读取失败或操作过期不会留下半批内容。文件名用作新实例的名称，重命名该图层不会修改磁盘文件或其他实例的名称。

链接保留离线快照，后续可在“工程资源”中查看来源、刷新或转为内嵌共享定义，也可将实例解除为普通组。缺少稳定资源身份的旧工程需先用当前版本另存一次才能建立链接；置入不会自动改写源文件。工程／预制体保留内部贴面和立牌结构，以整体实例适配当前位置，不会自动合成为图片。
预制体可导出为自包含的 `.floatprefab` 文件，只包含主画布图层和独立预览画布参数，默认去掉外部路径绑定。Windows 为两种格式提供打开方式：双击或通过文件菜单、`--open` 打开的 `.floatprefab` 置入当前画布和编辑层级，不退出尚未完成的子工程草稿；软件未运行时先建立默认新画布再置入。打开 `.floatcanvas` 则在当前实例打开完整根工程，任何未保存的修改（包括未命名工程）均先提示。已有其他默认应用时尊重 Windows 的选择，可在系统“打开方式”中选浮绘。

属性、工具配置和画布设置使用统一的数值框：拖动框内左侧图标，短距离微调、长距离加速；中间直接输入；框底轨道可单击或拖动到常用范围内的值。仅框内图标显示横向拖动光标并响应数值拖动，外部名称保持普通标签语义。常用轨道范围不限制图标拖动和直接输入，但各属性仍有合法值约束。位置与大小分别组成一行属性，X/Y/W/H 四个框等宽；两框之间固定留 36 DIP，位置行留空，大小行放比例锁链。

数值框右侧显示对应单位，例如尺寸和线宽的 `px`、角度的 `°`、不透明度的 `%`，以及行、列和编号。单位不参与编辑，只需输入数字。工具预览和面板刷新会保留当前拖动，松手后更新预设状态。混合多选和自动值的占位状态也可以直接通过图标或底轨调整。

点击圆形滑块本身保持原值，拖动时保留按下位置的偏移；点击轨道其他位置则立即从该处调整。除直接点击输入框外，点击图标、单位、边框或属性名称都会聚焦滑条，左右方向键按该属性的步长微调（网格行列每次增减 1）。拖动和模型回填默认显示最多三位小数，整数项保持整数；显示格式化不改写原有数据的完整精度。图标与滑条拖动期间实时预览，取消时恢复原值；图层及文档画布设置的调整在松手时合并为一次可撤销操作。

滑条使用独立的常用区间：普通描边 0～32 px、荧光笔 16～64 px、截图及图片边框 0～16 px；文字字号 8～144、序号及 Emoji 工具大小 16～256；圆角及箭头头部 0～64 px；模糊强度 0.1～64、马赛克强度 1～64；序号步长 −10～10。图层宽高滑条为 1～1000 px，立牌离地高度为 −1000～1000，网格线宽为 0.5～8 px。直接输入及图标拖动仍使用各属性原有的合法范围；切换工具或刷新面板不会把已有数值截断到滑条边界。

普通属性和开关名称统一使用 12 DIP 字号及相同字体、字重。栏目标题统一为 13 DIP 半粗体，首栏不加顶部分隔线；数值图标统一使用线条标识，同类属性共用图标。标准数值框、颜色编辑区、颜色值等单行文本框、下拉框与开关行统一为 34 DIP 高；长开关名称可以换行，图库和多行内容按需要增高。

属性、工具配置及画布面板的参数区默认为 440 DIP，标签列固定为 96 DIP，中英文共用尺寸。大小、位置及网格数量采用一个组名与两个数值框，其他普通属性各占一行；窗口过窄时，成组字段上下排列以保留输入空间。开关名称在左，控件固定靠右；名称可以超过普通标签列并换行。开关统一使用拨动样式；多选混合值用居中圆点和短横线表示，点击统一开启，再次点击关闭。常用标签采用简洁名称；少数超长普通标签悬停后自动滚动，按下拖动时停止文字动画。系统关闭界面动画时保留静态标签和完整提示。

普通窗口、对话框及带标题弹出面板的左右内容边距统一为 12 DIP，滚动条只在出现时占用空间，底部操作区与内容区沿用相同边界。

宽高中间的锁链按钮控制并保存“等比缩放”：蓝色连接表示锁定，断开表示独立调整，横线表示多选图层的状态不同。锁定后，输入或拖动任一尺寸都会即时更新另一尺寸；取消拖动恢复两边数值，图层改动可以撤销。多选锁定状态不同时，输入或拖动尺寸分别遵守每个图层自己的比例偏好；点击锁链才统一更改锁定状态。工具预设也保存该状态和尺寸，锁定的非正方形预设按设定比例创建，正方形和圆形预设仍为 1:1。模糊和马赛克新建的独立图层继承工具的等比偏好。`Shift` 可在拖动创建时临时解除锁定；未锁定时按住 `Shift` 可临时绘制 1:1 图形，不改变工具或新图层保存的等比偏好。

二级颜色窗口可按 `Esc` 关闭。正在修改色值或拖动色相、不透明度及选色谱面时，先按一次取消当前调整，再按一次关闭；仅进入色值输入框而未修改时，一次即可关闭。关闭不会同时收起来源窗口或退出编辑。

隐藏属性窗口或切换选择会提交已生效的有效文本输入；尚未松手的数值拖动会取消并恢复原值。不完整或无效的数值不会写入对象，选择新对象时自动载入它的当前属性。

工具条右上方的画布不透明度滑块调节标注与图片的不透明度，截图底图保持正常亮度。滑条使用渐宽色带和空心拨块，只有指针移到拨块上或拖动中才高亮；从拨块或轨道按下均可连续拖动，拨块按下保持原值，松手计为一步撤销，取消恢复原值；旁边提供新建画布和显隐按钮。灰色空白页加号用于新建，右侧红色扫把用于立即清空。隐藏不会删除内容，也不改变编辑／穿透状态；隐藏期间不能添加新元素。

标注因显示器变化完全落到屏幕外时，可用“主菜单 → 画布 → 将标注移回可见屏幕”找回。已有任何部分在当前绘图范围的屏幕内时保持原位；完全屏外的可见、未锁定对象移到最近的可放置位置。组合采用共同的画布平面平移，保留成员局部位置和变换，包括隐藏或锁定的后代；只有待移动根节点自身或其祖先隐藏、锁定时才跳过该整体。逻辑几何和截图裁剪框保持不变，透视下屏幕大小可能随新深度改变；超大对象仅移到可操作的位置，不额外缩小。整次操作可一步撤销，重复点击不会继续偏移。

### 查看画布、独立编辑与跨屏转换

工程继续使用像素尺度，不强制使用1920×1080。新建屏幕工程会记录创作范围和参考屏幕尺寸；Windows显示缩放、编辑器查看比例与工程像素尺寸分别管理。

中键拖动平移，Ctrl+滚轮围绕鼠标缩放，范围为1%～6400%。放置模式后的“浏览视图”入口提供预设取景、还原和应用；视角偏离默认时图标变橙色。第一下点击展开菜单，入口切为还原图标，再点即可还原并收起。按住 V 可临时选择和编辑对象。仅在视图偏离默认状态时，左下角显示查看比例；还原默认视图后隐藏。查看不修改图层、透视或网格，不新增内容撤销，也不触发工程保存；退出编辑的穿透展示始终显示完整根工程的正式状态，重新编辑则回到原独立层级和视角。普通导出使用作品正式状态。

画布参数板提供五个查看命令：

| 命令 | 行为 |
| --- | --- |
| 100% | 恢复原始比例，保留观察中心 |
| 居中内容 | 保留比例，把可见内容移到视野中心 |
| 适配内容 | 完整显示可见内容，允许主动放大小内容 |
| 查看完整画布 | 显示保存的创作范围，保留原构图 |
| 恢复默认视图 | 清除临时查看变换，回到作品正式状态 |

普通组、共享定义和外链首次独立打开时保留其创作位置和原始比例，不自动居中或适配；后续恢复本机记忆的视角。在工程内新建普通组合时，会建立固定的独立画布原点，让内容位于主屏尺寸的子画布中央，同时保持宿主中的位置。根层级的独立／根工程两种显示共用画布参数和观察视角，只改变其他两个根画布是否可见。多屏情况下，新画布的创作范围以及居中、适配等取景命令参考主屏的位置和大小。主动取景包含可见锁定内容及自身背景，不包含隐藏内容。另存副本和历史版本分别记忆视角；只读快照可查看，不能修改校准或应用取景。

需要远距离移动图层时，将鼠标停留在每块屏幕实际露出的外边缘，画面会自动平移，松开即停止，整次移动仍是一条撤销。相邻屏幕公共边界不触发；错位排列时露出的边段仍是外边缘，不采用多屏包络矩形。此功能只用于移动图层；绘制、缩放、旋转和校准手势不自动滚动。全选拖动仍修改真实图层，返回宿主后会反映位置变化；只想调整观看位置时使用视图平移。

**将当前取景应用到作品**会真实修改当前范围的内容和校准，包括主动居中或适配后的结果，影响宿主和正式导出，但不改变创作范围。应用后视图归零，画面保持连续，可一次撤销/重做。普通组保留对外放置矩阵；共享定义在退出层级时发布；外部链接只读，需先转换为内部工程或普通组。普通组的工程预览共用根工程视图；在组内应用取景、调整画布或转换工程分辨率也作用于根工程，其中应用取景保留当前编辑层级。共享内容在工程预览中仍不能修改宿主画布，需切换独立画布。首版不提供查看旋转。

打开参考屏幕分辨率不同的根工程时，可选择**保留原尺寸**（默认）、**转换副本**或取消。转换按等比完整适配并居中：4K转1080P后，原宽400的对象有效宽度为200，新建宽400的对象仍为400像素。不同比例不拉伸、不裁切；新增留白不参与下一次转换，避免往返累计缩小。转换后的首次保存进入另存为，默认新文件名，不自动覆盖源文件或重定向宿主链接。也可从画布参数板主动转换当前根工程。置入prefab、进入子工程及运行中换屏不会自动转换；截图画布保留原像素。

普通PNG/JPEG整幅导出采用保存的创作范围，范围外内容仍可编辑；明确截取当前视口的操作使用自己的范围。创作参考自工程格式 v18 引入；当前源码保存为 v20，旧版程序无法读取该新格式。旧工程读取时依据已有范围推导，不立即改写源文件。

显式截图按当前独立范围和视角取样，桌面背景保持实际屏幕位置，插入时不会重复缩放。透视“预览扭正”使用眼前的四点框展开截图，平面尺寸与正式校准不包含临时视角；取样期间改变视角或编辑上下文会取消该结果。

### 画布工具、网格与透视

画布工具的 `Esc` 与普通工具同级：先取消未完成的拖动或四点放置，再关闭非固定配置，空闲时直接返回穿透，保留所选画布工具。

单击工具条的“画布”，或按 `C`，选中画布工具；它与画笔等其他工具互斥，蓝框表示当前选中。矩形／梯形图标分别表示透视关闭／开启。再次选择画布，打开或关闭参数板。首次位置、再次打开的位置和右上角固定按钮与其他工具参数板一致；关闭参数板后仍可继续调整画布。输入文字时，`C` 仍用于输入，`Ctrl+C` 仍为复制。

选中画布工具即进入校准编辑。非透视画布用左键拖动移动网格原点、在工具参数中调整格距；图层位置不变，一次拖动只产生一步撤销，`Esc` 取消。透视画布直接显示参考四边形和手柄。按住空格可以临时浏览，不修改校准或预览模式；工程预览中的平移和缩放作用于根工程视图，进入或退出普通组不切换取景。取景命令位于独立的“浏览视图”菜单。

参数按“背景与网格外观”“透视与网格”两组排列，前者在前，画布类型与其动态选项同级对齐。建立透视框、逻辑尺寸与钉点在前，局部校准、格距与原点紧随其后，最后是预览扭正与重置；不增加内部章节或额外分段间距。原点 X／Y 之间的图标按钮可将网格原点对齐钉点。第一组的“显示网格”决定颜色、线宽和线型的显隐，使用统一属性变化动效；关闭后保留配置，再次开启恢复。第二组的格距和网格位置始终可调整。标题栏从左到右提供两格宽的遮挡模式、两格宽的参考网格透明度，再接固定、帮助、关闭。画布与其他工具共用固定状态：画笔、矩形与画布之间切换时替换参数内容并沿用窗口位置，关闭参数板会解除固定。

参数板可设置独立的画布背景颜色与不透明度；默认背景透明；画布底色与实体网格位于画布平面的最下层，并与标注一起受工具条整体不透明度控制；开启深度优先遮挡时，参与与立牌的空间遮挡。非透视时，逻辑文档原点保持左上角 (0,0)，网格独立围绕主屏中心部署，默认以参考屏幕中心为网格交点；明确设置或应用后的网格原点会保存，不随运行时换屏重置。按住 Shift 拖动可移动网格原点，在画布属性中调整格长；图层位置不变。平面模式提供“网格大小”和“网格原点 X／Y”。网格大小表示一个格子的边长，采用与矩形宽高相同的像素单位，可输入精确小数或拖动滑块。手动设置范围为 1～1,000,000；已有工程中更小的合法格长仍保留，不会仅因打开参数板被取整或放大。新建画布默认恢复第一个官方画布预设；在“设置 → 画布与历史”开启“新建时保留画布参数”后可沿用当前背景、网格、透视及钉点等参数。清空已有标注始终保留当前画布设置。

开启透视后，“平面宽度”和“平面高度”决定关闭透视后的逻辑像素尺寸与宽高比，四个角决定它在屏幕上的形状。在“预览扭正”弹窗内可选 A4、A5、Letter、Legal、1:1、4:3、16:9 或自定义比例，并交换横竖方向；纸张选项只设置比例，保留当前较长边的逻辑尺寸，不将毫米换算为像素。勾选保持比例后，修改一边会联动另一边。拖动四角固定逻辑平面尺寸，因此放大四点框会相应放大内容和立牌。

网格有独立的格长和原点 X/Y，“网格原点对齐钉点”可重新对齐相位。悬停网格大小可查看四点框覆盖的列数、行数，允许部分格；改格长或原点不会改变透视矩阵、图层位置或立牌尺度。普通模式保留独立的精确格长和屏幕中心原点；修改普通网格不再覆盖暂未启用的透视校准。旧工程升级保留已有矩阵、钉点、网格相位与显示外观。

“预览扭正”临时截取四点框内的桌面与三根可见内容，左右比较原始合成截图与展开结果，可继续选择纸张比例或输入宽高。“应用”只更新主画布平面尺寸与投影；“应用并加入截图”还将本次原始分辨率截图加入主画布的当前编辑层级，透视开启时与原取样框对齐，关闭透视即可查看展开效果。截图中的前景、背景像素也会随照片展开，但这些原图层始终保持屏幕平面；应用与截图插入可一步撤销。预览用的小图不会替代原始截图。取消、隐藏画布、退出编辑或切换工程会使未完成结果失效。仅凭四个角不能确定物体的真实比例，需要纸张规格、自定义比例或已知方格等参照。

“按局部方格校准”沿实际格线拖出一个局部透视矩形，再填写横向、纵向格数；无需数完整个大框。确认弹窗立即预览网格，默认勾选“外框四边对齐格线”，候选项的展开与收起使用统一属性变化动效，详细规则放在标题栏问号帮助中：局部取样估计整框整数格数，可加减、直接输入或恢复自动估计，最终四边保持贴线。不勾选时，局部取样直接决定格距和原点，外框无需贴线。边界吻合不等于整体正确，请检查中间和远处的清晰格线。应用调整逻辑比例、格距及原点，已有内容的显示可能变化，可一步撤销；原有网格显隐设置保持不变。“调整取样框”保留参数返回画布，可拖角微调或重画；Enter 返回确认，Esc／右键恢复原取样返回弹窗。在初次框选阶段按 Esc／右键，或隐藏、离开编辑、切换目标时，取消本次校准。

取样格数左右并排，中间的网格按钮打开 9×9 选择器，一次点选横纵格数；悬停只高亮，单击才更新候选网格。Esc 或点外部只关闭选择器；超过 9 格仍可直接输入。整框格数右内侧的上下箭头分别加一、减一，中间的恢复按钮同时清除横纵手动值，恢复自动估计。所有数值框保留图标、单位、直接输入及滑动调整。

“重置透视画布”恢复图层在普通画布坐标下的 1:1 显示，清除透视形变与普通模式平移，图层数据不变。保留独立的平面宽高和网格格长，将平直四点框放在目标屏幕中央，并将网格原点对齐当前钉点。只有一个活动屏幕时不显示下拉区域；多个屏幕时可选择默认“主屏幕”或显式“屏幕 N”。选择只保存目标，再点击主按钮才重置；目标不可用时回到默认项。重置不改变绘图范围或文档逻辑零点。

选中画布工具后，透视校准框、中央整体移动手柄和参考网格出现。网格从其独立原点延伸，边角允许落在半格或部分格处；原点标记表示逻辑 (0,0)，中心手柄只负责整体移动。拖动中央四向手柄或框内空白处可整体移动校准框，在“全部屏幕”范围内可跨屏搬移；四角和边缘用于调整透视。单角拖动靠近相邻角的水平或竖直方向时会轻微吸附，按 `Ctrl` 暂停吸附，按 `Shift` 沿拖动起点的水平或竖直轴移动。标题栏的“参考网格透明度”滑条可设为 0%～100%，0% 隐藏参考网格；仅在本次运行中保留，重启后恢复 100%，不写入画布、预设或用户设置。参考线是编辑辅助叠加，实体网格属于画布平面并参与深度合成。调整参考透明度不会隐藏锚点或移动手柄。切换到其他工具后隐藏校准框和参考线，只保留已开启的自定义网格。失焦或隐藏画布会取消未完成的拖动。

“4点确定透视”与“4线确定透视”并列提供两种建立透视框的方法。点击后临时隐藏工具条以外已打开的窗口，再按任意顺序点击四个角点：先预览线，再预览三角形，最后预览带网格的四边形；钉点位于九宫格所选位置，原点标记表示逻辑 (0,0)。第四点确认后完成定位，可一步撤销；`Esc` 取消未完成的定位。完成或取消后恢复此前显示的窗口，原本关闭的窗口不会被打开。画布工具选中时始终可以调整锚点，无需“完成画布调整”操作。

“4线确定透视”依次拖出两条横向、两条纵向格线的清晰片段，端点不必是交点，遮挡处的四角由延长线推算。采集时隐藏额外窗口，画布和工具栏持续提示当前步骤。完成四段后拖动端点检查，Enter 或“确认”应用；Backspace 撤回最后一段，Esc／右键取消。确认与取消后恢复此前可见窗口；参考线不写入工程。

画布模式下方集中显示该模式适用的建立透视框、网格校准、尺寸及其他属性；通用网格显隐和样式放在其后。


整体移动只改变画布的屏幕位置，保持透视形状、格长与默认参照。半透明笔迹与形状支持连续预览，并保留原来的不透明度和叠加效果；无需先将内容改为不透明。一次调整仍可整体撤销，取消则恢复调整前的状态。

地平线可以进入屏幕。调整受凹四边形、交叉边、退化、不可逆几何与数值稳定性约束；触及这些限制时，边框变为琥珀色并显示提示。网格、底色和贴面只绘制到安全边界，四点框外的安全区域仍可使用；校准时以琥珀色虚线标出远处边界。正常编辑时，鼠标进入禁区会用淡红色标出禁止区域，回到安全区或离开画布后隐藏；此提示不进入导出。创建或拖动对象进入禁区时显示禁止指针，松手取消无效创建或恢复拖动前的位置；自由笔画穿越禁区会断开，保留安全片段。立牌只检查地面锚点和有效尺度，上半部分可伸到天际线上方。

调整期间持续预览，越界部分临时裁剪。确认弹窗仅显示并突出需处理的图层数量，各选项说明可从关闭按钮旁的问号查看。松手或确认第四点后，如有越界图层，会询问取消本次调整、应用并移回图层（推荐）、应用并删除，或“应用并保留图层（慎用）”。保留时只应用透视，图层内容、位置、组合及显隐锁定状态均不变；当前不安全的部分会被裁剪或暂时隐藏，调整回安全透视后恢复显示，保存工程和重开也保留这些图层。迁回优先选择四点框内部或屏幕上的开阔位置，组合整体移动、独立图层错开，保留原始内容和逻辑尺寸；隐藏和锁定图层也计入提示。无法找到安全且可操作的位置时禁用迁回，不会自动缩小或删除。透视调整及所选处理合成一次撤销；选择前的恢复快照保持调整前状态。

画布工具在平面模式也显示原点与钉点：默认视图中，文档 (0,0) 在左上角；原点跟随文档的已有变换和观察视图，钉点在默认视图下位于主屏中心，随观察视图平移和缩放；还原或应用视图后回到默认中心。移动网格不会移动这两个参照；网格 X／Y 中间的按钮将一个网格交点对齐当前钉点，支持一步撤销。平面画布工具同样显示黑白相间的参考网格，不受“显示网格”开关影响；标题栏的参考网格透明度可调淡或隐藏它，切换工具或退出编辑后隐藏，不写入工程或导出。切换到其他工具后隐藏标记。透视模式的“钉点”通过九宫格点选择器选择，默认左下角。它锚定后续平面宽高或比例调整：修改尺寸时，此处的逻辑位置和屏幕位置保持。切换钉点本身不移动内容，不改变网格原点或立牌尺度；需要移动网格相位时，显式使用“网格原点对齐钉点”。逻辑原点 (0,0)、钉点与中央移动手柄各有独立作用。

网格使用前景色预设，可调整颜色、不透明度和线宽，并通过图示与文字选择实线、虚线或点线；点线会绘制为可见的圆点。网格延伸到校准边框之外，并与参考线共享原点和格长。屏幕间距不足 8 像素的远端网格局部按层级抽稀，保留近景可分辨的格线；虚线／点线周期低于可分辨阈值时不再展开远端线段。参考、自定义和四点定位预览共用这一绘制规则。高分辨率密网格仍会增加 CPU 绘制开销；可增大非透视格长或独立的透视网格间距，或关闭“显示网格”。透视覆盖行列数由平面范围和网格间距自动计算；对齐已有网格时，先用四点或四线确定透视，再框选容易数格的局部区域并输入横纵格数。参考线在切换离开画布工具后隐藏。

画布参数板左侧显示属性，右侧为官方预设和“我的预设”。加号保存当前设置；个人预设支持覆盖、重命名、删除和拖动排序，应用可一次撤销。预设库 v4 保存独立的平面宽高、透视网格格长与原点，以及背景、网格样式、精确非透视格长、钉点、四角和完整校准。目标画布的非透视网格原点与应用的重置屏幕偏好不属于预设。旧 v1～v3 预设仍可读取，读取不重写文件。

官方预设关闭透视并恢复默认参考平面。旧个人预设缺少校准时，按参考屏幕及预设的行列、格长生成默认参考几何，不再继承应用前的四角；预设不改变标题栏的运行时遮挡模式。旧预设未保存的校准位置无法自动恢复，需要时重新校准后覆盖保存。更换屏幕布局后，按需重新调整或选择目标屏幕重置。

透视作用于形状、文字、图片和动图，默认“贴面”对象随画布平面变形；实验性“立牌”采用下节的朝向与深度规则。动态模糊与马赛克区域随放置方式变换，但采样量仍以屏幕像素计算。固定目标平面决定逻辑比例，四角决定投影；这不能还原真实相机。游戏镜头移动后需要重新校准。截图首次粘贴时通过逆变换放回所选屏幕位置，此后随画布投影变化。

## 贴面与立牌（实验性）

“放置方式”有两种：**贴面**随画布透视变形；**立牌**始终面向屏幕，保留图案自身的比例和旋转，按地面锚点远近整体缩放。立牌开关默认关闭，位于工具条的画布调整组，主菜单也提供入口。不开启时沿用原有创建流程；通用 Shift 移动和贴面截图选区修复独立生效。

工具条和主菜单的入口统一为“放置方式”。工具提示只显示名称和当前的“默认模式”或“立牌模式”；默认模式对应贴面。先启用画布透视，再通过该按钮切换立牌模式（实验性）。全局开关只决定后续新对象的初始方式，不转换已有图层，也不随各工具预设单独保存。关闭透视时，开关置灰并重置为默认模式；已有立牌标记、锚点和高度仍保留，再次开启透视后恢复投影。属性中的“放置方式”和“离地高度”在透视开启时可用。

### 直接创建，再调整接地点

立牌模式保留一步创建：矩形、圆形、符号、序号、Emoji 和有预定尺寸的展示内容，单击时按逻辑尺寸放置，图形中心对准鼠标，视觉上近大远小。拖动则由鼠标轮廓确定几何尺寸，描边、箭头尺寸和显式圆角仍使用逻辑单位。图层框底边中点成为默认接地点，完成后可拖动主体或中心手柄调整位置与高度；透明图片的底边不一定对应图片中人物的脚底。

拖动起笔可以在地平线上方，最终框底必须进入安全地面区域。无法同时满足当前尺寸与位置时，显示无效草稿；在该状态结束会取消创建，不会保留上一次有效位置或静默缩小。图片导入、位图粘贴、外部图片拖入、合并位图印章和新窗口源准备完成后，单击指定中心；源像素作为逻辑尺寸，按目标逻辑画布的 80% 容纳，不放大，不随点击深度或观察缩放重新计算尺寸，也不重采样原图。文字保留输入起点与逻辑字号，每次换行或排版后重新求解接地点，预览与提交一致。取消、切换层级或工程不会插入迟到内容。

属性中的“保持当前画面”默认勾选。切换贴面与立牌时，只有可安全保持现有外观才转换；无法转换时保留原图层。取消该勾选可使用原有的逻辑放置转换。

### 组合与印章的整体立牌

选择普通组或共享实例，在属性中切换“平面／立牌”。组的“平面”保留成员各自的放置方式；“立牌”把完整局部图案作为一块牌放入场景，支持混合成员、多层嵌套和单图层包装组。转换按逻辑图案立起，屏幕外观可能改变。

内部立牌的接地点、高度与原有变换仍生效；它们先参与无透视的局部布局，再随最外层立牌统一缩放、参与外部遮挡。独立画布的透视仅用于编辑预览，不会连同背景或参考网格叠到牌面。进入组编辑仍可修改成员及其模式。

首次立起以局部图案外框底边中点确定接地点。以后增删、隐藏或修改成员不会重新居中、缩放或移动整组；拖动主体移动接地点，中心手柄调整高度。解除组合前须先切回平面。移入或移出整体立牌会尝试保持屏幕外观；不能安全表达时整次操作停止，不改变部分对象。

立牌模式下，新可编辑印章和共享印章使用逻辑尺寸，中心对准点击位置；按下显示实际候选轮廓，松开提交。普通印章仍是独立组，共享印章仍是链接实例。实例的外层模式只影响该实例，进入共享内容的修改仍同步所有引用；不会写回外部源。已有组和旧立牌不自动转换或清除历史缩放。

### 先固定等深线（高级）

在主菜单的画布组勾选“立牌：先固定等深线（高级）”，使用以下流程。该选择是软件偏好，不改变已有图层。

1. 选择能创建图层的工具，移动鼠标预览经过当前位置的等深线；点击固定深度。此时只显示线，不在点击处画点，也不同时开始工具输入。
2. 按原工具操作绘制：矩形仍可从一个角拖向另一个角；套索、多点工具和文字沿用各自的完成方式。等深线继续显示，并实时显示轮廓中心与到等深线的屏幕竖直连线。
3. 中心竖线与等深线的交点成为地面锚点。中心横向变化时，锚点沿等深线移动，深度不变；第一次点击的位置只用于选深度，不固定最终锚点。
4. 一次有效创建完成后，等深线消失。中心、锚点和连接线成为选中手柄的一部分，与选中轮廓共同显示或隐藏。需要再次创建时重新选深度。

高级流程下，截图也先选深度，再正常框选或套索；立牌截图保留选中的屏幕像素外观。文件导入、普通位图粘贴、外部图片拖入，以及合并位图印章，先准备图片，再在画布点击选择深度、第二次点击确定图片中心；选深度不会先生成空图层或撤销记录。切换工具、按 Esc 或取消操作会清理未完成的深度选择；异步失败或切换工程后不会插入迟到结果。

### 深度优先遮挡（实验性）

画布工具标题栏的遮挡模式开关在“图层顺序”与“深度优先”之间切换，图标随拨片移动；整个控件只有一个点击目标。平面模式保留位置并置灰，透视模式可用。每次启动默认使用图层顺序。开启后，立牌按地面锚点深度从远到近叠放；只有深度完全相同才使用图层顺序。贴面之间仍按图层顺序叠放，列表不会随锚点移动重新排序。“置顶”不能越过不同深度的空间关系。

贴面属于公共画布平面，沿等深线与立牌交替合成，因此同一贴面可以局部位于立牌前方、局部位于后方。画布底色和实体网格属于平面的最下层，沿相同等深线参与遮挡：立牌没入平面下方的部分被不透明底色盖住，半透明底色按透明度混合；只有网格时仅在线条覆盖处遮挡，格子空隙保持透明。深度相同时，底色和网格位于所有对象下方。底色、网格和对象合成后再统一应用工具条整体不透明度。桌面和背景图保持背景角色；图片内部的物体没有独立深度。负高度可以使立牌部分或全部被遮住，仍可从图层列表选中并使用选中手柄。

遮挡模式只影响本次运行的画布预览与点击选择，不产生撤销记录、不标记工程修改，也不保存到工程、恢复记录或预设。关闭透视时置灰并暂停生效，重新启用透视恢复本次选择；导航、撤销及应用预设不重置这一预览偏好。旧文件的遮挡字段仅为格式兼容保留，不控制标题栏开关。画面与选择使用同一份预览结果，切换等待新画面时暂停旧画面的点击命中。平面内容印章继续使用平面语义。实时模糊和马赛克只采样当前深度片段之前已经合成的后方内容；模糊边缘不读取尚未合成的近端片段，避免相交滤镜循环采样。启用后的贴面分段绘制可能增加复杂画布的渲染开销。

本次运行的预览偏好不改变工程格式；工程兼容范围见下方文件说明。

### 逻辑尺寸与视觉大小

新建立牌共用画布的深度比例：固定尺寸单击保留预设宽高和样式；拖出屏幕轮廓则只反算几何，不反向放大描边或字号。例如最终接地点的深度比例为 0.25，拖出屏幕 100×100 的矩形，逻辑宽高为 400×400；逻辑描边 5 显示为 1.25。预览已使用实际深度，松开时粗细不跳变。相同预设、相同父级且没有额外缩放时，移到同一深度的对象尺寸和粗细一致。高级等深线入口保留原有操作。

此规则只应用于新创建的内容。已经存在的立牌（含尚未保存、旧工程、恢复记录及资源中的对象）不自动整理变换或修改样式；旧对象可能继续存在属性线宽与实际粗细不一致的历史情况。用户主动进行的对象或组合整体缩放仍会影响整个外观。

移动到远处时，宽高、描边和离地高度一起变小，保存的逻辑值不变。关闭透视后显示逻辑尺寸：上述矩形在普通 100% 显示倍率下为 400×400、描边 5。不会强制恢复创建时的屏幕大小。

| 操作 | 效果 |
| --- | --- |
| 拖动图层主体 | 移动画布平面上的地面锚点；按新深度缩放，保留逻辑尺寸、高度和自身角度 |
| 主体移动时按住 Shift | 沿本次拖动起点的画布 X／Y 轴约束锚点，与屏幕轴、等深线方向和图案角度无关 |
| 拖动中心点 | 仅使用屏幕竖直分量改变离地高度，整个图层上下移动；锚点和逻辑尺寸保持不变 |
| 拖动外侧旋转手柄 | 在面向屏幕的平面内旋转图案，保留锚点与高度 |
| 拖动选框角点 | 以图层中心缩放，保留锚点与高度；Shift 继续临时反转等比偏好 |
| 点击地面锚点或连线 | 只作参考，不提供拖动或重新绑定入口 |

离地高度可以为负：中心点可经过锚点继续向下，不会自动夹为零。高度为零时中心和锚点重合，中心高度手柄仍可拖动。单选立牌时，属性 X／Y 表示地面锚点在父组局部坐标中的位置；没有父组时就是画布平面坐标。等深线与屏幕竖线无法形成稳定交点时，会提示当前角度无法确定落点，需选择有效位置或调整校准，不会暗改深度。

### 组合、转换与文件

普通组合和共享实例都有自己的“平面／立牌”模式。平面组合保留成员各自的放置方式；整体立牌先在无透视的局部平面解析内部内容，再由外层接地点统一决定深度缩放和遮挡。内部立牌的接地点及高度仍参与局部排布。首次立起采用内容底边中点；之后增删或隐藏成员不自动重设接地点。整体立牌须先切回平面才能解除组合。

新放置的可编辑或共享印章采用当前放置模式，内部层级、成员模式、锚点、高度与图案保持不变，不额外要求选深度；共享实例的外层模式不修改共享定义。内部复制、历史恢复和工程重开保留原有放置数据。合并位图印章保存当前可见外观，之后作为一张新图片放置，不保留内部深度关系。组的独立预览透视不会再次叠加到整体立牌上。远近不自动改变列表顺序。

透视开启时，可在属性中切换已有图层的放置方式。默认勾选“保持当前画面”，只有能安全表示现有外观时才转换，否则保留原图层。取消勾选后，转换保留原始内容与逻辑几何，外观可能改变，不保证保留全部屏幕角点。图片不因移动或切换方式反复重采样。

## 演示工具

从工具条“更多”或“主菜单 → 演示”选择“键盘演示”或“鼠标演示”。两者均使用普通工具参数窗口：左侧调整参数，右侧选择官方或自定义预设。键盘演示可单击按字号生成默认显示区，也可拖动设置大小；默认保持比例，按住 Shift 可临时非等比拖动。鼠标演示不需要先画区域，两种工具的配置彼此独立。

**鼠标演示**的“启用鼠标演示”总开关位于标题栏，占两个按钮宽度。开启后默认显示光标高亮和点击效果，也可分别关闭高亮、点击或轨迹。左键、右键和中键可分别设置启用、颜色、圆环或实心形状、半径、圆环宽度及时长；高亮可调整颜色与半径，轨迹可调整颜色、宽度及时长。透明度统一由对应颜色的 Alpha 控制。总开关只控制演示效果，关闭后属性仍显示并可编辑；关闭子功能或某个鼠标按键的点击效果才会隐藏对应配置，重新开启仍沿用原设置。官方提供高亮、点击和轨迹预设，也可保存自己的效果组合；预设不保存当前总开关状态，选择预设会保留当前开关。

鼠标标记覆盖浮绘响应的所有屏幕，始终位于真实光标的物理屏幕位置，不受键盘区域、画布大小、平移、透视、组合或实例限制，也不创建图层。鼠标效果绘制在前景内容最上方，并跟随画布整体显隐及不透明度；隐藏画布或整体不透明度为零时不显示，恢复后沿用鼠标演示总开关和效果设置。当前鼠标效果属于个人偏好，不随工程保存；调整这些参数不修改当前编辑图层，也不增加撤销记录。点击和短时轨迹不会自动成为画布笔迹。

选择鼠标演示时，画布点击、拖动和滚轮只做演示预览，不显示或编辑图层选框，按住 V 可临时选择对象；切换到其他工具后恢复原有操作规则。

**键盘显示区**创建后即自动响应按键，编辑模式也继续记录。键盘图层没有独立启用开关，可见即记录；要停止某层的键盘展示，隐藏或删除该层。“记录范围”是每层自己的属性，可选“所有应用（含浮绘）”“仅其他应用”或“仅浮绘内部”：工具参数决定新层的默认值，已有层在属性窗口修改，支持撤销、保存和重开，不影响其他键盘层。没有可见键盘图层，或隐藏整个画布时，不记录键盘；鼠标效果仍由自己的总开关控制。

先选择“按键记录”或“实时键盘”模式；按键记录内再选择“简洁”或“仿真键帽”外观：

- **按键记录**：按完整操作显示日志，例如 `Ctrl+C` 只保留一项，不把最后松开的 `Ctrl` 另列。单独按住修饰键时显示待定预览；随后按下其他键时合并为组合键，单独松开则保留为一次操作。“简洁”显示文字，“仿真键帽”将每个按键显示为立体键帽。默认记录所有物理按键，也可使用“快捷键”过滤；长按保持显示，释放后整项按配置时长淡出。
- **实时键盘**：默认显示完整 104 键物理布局，按下时对应键帽改变外观，松开立即恢复。左右修饰键、主键盘与数字区 Enter，以及数字区和独立导航键分别响应；键盘语言布局或 NumLock 改变不会把同一物理键移到另一位置。

实时键盘的“编辑键盘布局…”打开二级布局窗口。单击选择键位，Ctrl/Shift 点击增减选择；在键位区 Ctrl+A 全选，空格统一启用或禁用所选键（混合状态先统一启用），双击切换单个键。多选可一起拖动，保持相对位置；标签与数值需单选编辑。右侧显示对应的物理按键名称；拖动调整位置，或输入 X、Y、宽、高，数值以普通按键宽度为单位，滑轨左右键每次调整 0.25 单位。也可改显示标签、隐藏单个键位，使用“全显示／全隐藏”，或恢复标准键盘。隐藏保留该键的位置和尺寸，适合只展示 WASD、空格等游戏布局。默认尺寸按已启用键位的外接范围生成；解除图层比例锁定后，可单独拉伸水平方向。布局窗口内的改动先保留在草稿中，取消不应用；应用一次提交布局，恢复标准后应用会使用默认布局。

显示的是物理按键标签，不读取输入框文字。识别到应用报告的密码框时会清除并暂停按键状态，实时键盘恢复正常键帽外观，鼠标效果可继续。密码框识别依赖应用提供的元数据，部分自绘输入框可能无法识别，不能作为所有密码输入的屏蔽保证。

工具参数中，模式专属属性紧跟在模式选择下：按键记录提供过滤、显示条数、停留时长和对齐，实时键盘提供布局编辑；字体、字号和前景／背景色等共有属性放在下面。工具不提供整体透明度，创建后可在图层属性中调整。默认区域按字号、显示条数或键盘布局生成；按键记录按内容自然展开，不再设置最大宽度。图层缩放时，垂直尺寸同步调整字号，水平尺寸控制横向展开程度。按键内容像其他图层一样随位置、大小、组合和透视变化。编辑模式仅为两种按键记录样式显示虚线外框和浅蓝色背景，即使当前没有按键也能看清、选中和调整；实时键盘不显示这层辅助效果；穿透时空闲记录区域保持透明。复制和共享实例分别按自己的图层放置显示同一全局键盘输入。

工程、恢复和 `.floatprefab` 只保存键盘样式和布局等图层配置，不保存最近按键、点击或轨迹。普通 PNG／JPEG 导出和资源缩略图显示实时键盘的正常键帽布局，不叠加真实按下状态或日志输入。需要保留当前键盘展示时，可用截图工具的“背景＋画布”或“仅画布”来源，将此前实际显示的按键帧冻结为静态图片；全局鼠标标记不属于这类画布输出，也不会随截图变成工程内的实时记录。
## 印章库与快捷栏

库窗口上方提供按 `1`～`9`、`0` 排列的紧凑十槽。把下方印章拖到槽位上可固定或替换；也可先单击选中一个槽，再单击印章固定。成功设置一次后，槽位自动回到未选中状态；设置失败则保留选中，方便重试。再次点击已选槽也可退出槽位选择。槽位右上角的 `×` 清空绑定，印章仍留在库中。搜索框内有放大镜，与操作按钮共用一行；操作说明收在关闭按钮旁的 `?` 中。默认窗口按完整的印章列宽展开，全部印章在同一个列表中连续滚动。库内印章支持拖动排序，并显示“组合／图片”类型及带首个固定槽数字的图钉角标；顺序会保存。

工具条印章槽的右键菜单仅提供重命名、覆盖、删除和取消固定四项维护操作；使用和使用可编辑源仍位于印章库。槽位取消固定只移除当前槽，删除印章会清除所有对应槽位。

未固定印章的右键菜单提供“固定”二级菜单；已固定时改为“取消固定”，每次按快捷栏顺序（`1`～`9`、`0`）取消一个绑定。同一印章可以固定到多个槽，需重复取消才会全部清空。

印章用于复用自己绘制的图案。选中一个或多个元素，点击工具条下排的“新建印章”，或从“印章库”使用保存选择的操作，输入名称并选择保存方式。新印章会自动填入第一个空快捷槽；槽位已满时仍保存在库中：

| 保存方式 | 放置后的内容 |
| --- | --- |
| 可编辑编组 | 复制形状、文字、裁剪图片、动图及嵌套组、样式和变换；可整体调整，也可进入组内或用 `Alt` 选择成员继续编辑 |
| 合并为图片 | 将当前一帧合并为静态图片，同时在库中保留可编辑源对象；选择“以源对象使用”可重新放置原始元素 |

可编辑编组保留 GIF／动态 WebP 的原始数据；保存、重新打开印章库后再盖出，动图仍会播放。工具条和印章库列表中的小缩略图保持静止，普通动图印章在悬停的大预览中播放。含实时桌面模糊或马赛克的组合使用保存时的静态缩略图预览，即使其中还包含动图；放到画布后仍按对象类型工作。从库中选用印章时，印章库按钮保持选中并显示该印章预览；再次点击仍打开印章库。

在库中搜索或滚动选择印章，点击“使用”或双击缩略图，再在画布点击放置。每次点击按保存时的视觉尺寸和旋转关系放置，中心对准点击位置；无需拖出大小，可以连续盖印。每次放置可单独撤销，放置后不自动选择副本。鼠标停留在快捷槽或库内印章上，可查看名称、快捷键、大图及预览与实际尺寸的比例。新印章的大预览与小缩略图使用预制体自己的预览透视、背景、网格和透明度，并按内容适配预览区域；预览配置不改变置入后的尺寸与宿主配置。含实时桌面滤镜时仍使用保存时的静态画面。

选中库内印章后，可重命名、用当前画布选择覆盖，或删除。新印章的三种保存模式均使用 `.floatprefab`，合并图片印章的可编辑原稿也使用该格式；预览参数保留在包中，置入时不覆盖宿主画布。旧印章库仍可读取，保留名称、顺序和快捷槽，重新保存时改用新格式。普通印章每次放置复制独立内容；修改副本或覆盖库内原件不会更新此前的副本。保存时选择“共享预制体（本工程内同步）”，则同一工程中的多次放置引用同一定义，完成定义编辑后同步全部实例；覆盖库中原件仍不会改动已经放置的工程内容。

将印章固定到 `1`～`9`、`0` 中的某个位置，即可从工具条第二行或对应数字键选用。数字键先选择印章，随后点击画布放置；文字输入期间数字用于输入。取消固定只清除快捷位置，删除印章则同时清除它占用的快捷位置。当前选用的快捷印章失效时，工具返回“选择”。

## 置入图片或工程、替换和裁剪

可以按 `Ctrl+V` 粘贴剪贴板图片，或点击工具条“置入”选择一个或多个文件。“置入”也支持前述可链接的 `.floatcanvas` 与 `.floatprefab` 文件。新图片默认放在当前可见画布区域中央。支持 PNG、JPEG、BMP、GIF 和 WebP，透明图片保留透明区域；GIF 和动态 WebP 保留原始数据并播放。

也可以从文件管理器或浏览器拖住图片，保持拖动，按编辑／穿透切换快捷键（默认 `` Ctrl+` ``）展开画布，再在目标位置松开鼠标。图片中心对准落点；同时拖入多张图片时，后续图片会略微错开，整次导入可一步撤销。

拖动或粘贴来源需要提供实际图像数据或受支持的图片文件。文件导入、文件复制粘贴／拖入，以及提供原始 GIF／WebP 数据的剪贴板来源可以保留动画。若来源只提供 PNG 或 Bitmap，导入结果就是静态图，无法恢复原动画。网址、网页链接本身不能作为图片导入，浮绘不会联网追取原图；浏览器未提供原始动图时，可以先保存文件再导入。

隐藏画布会停止动画刷新，重新显示后继续；进入穿透时仍播放。动画推进不修改画布内容，不增加撤销步骤，也不触发自动保存。工程、恢复文件和浮绘内部的对象复制保留动画数据。截图、PNG／JPEG 导出及“合并为图片”印章取操作时的静态一帧；暂不支持播放控制、跨重启保存播放进度或导出动画。

图片是独立对象，不会自动替换背景。选中图片后，可以移动、旋转、缩放、调整不透明度，以及设置描边宽度和颜色。图片与新截图按当前可见像素的轮廓描边：将所有非全透明像素向外扩展指定宽度，在原图下方铺上描边色。透明 PNG 的边沿跟随主体；主体的半透明部分会与下方描边色混合，完全透明的图片不产生描边。动图的描边随每帧轮廓更新。位置和宽高数值均按图片本体计算；选择框与命中范围包含全部外边，并保留原图的透明边距，不随动图轮廓跳动。

图片置入仍直接选择文件，不增加工具配置面板。旧图片默认不新增边框；旧截图中已经合成进像素的边框保留原样，新截图的描边可在属性面板中修改或设为 0。

图片描边的底图按需缓存，静图和动图中已出现的各帧均可复用。改变源图、裁剪、效果、本体尺寸或边宽后，下次绘制时重新生成；只修改颜色或整体不透明度时复用底图。缓存按实际显示清晰度生成，放大或改变透视后按需重建，避免放大低分辨率底图。缓存有内存上限，较久未使用的内容会被淘汰，需要时再生成。

- **替换原图**：单选图片，使用“主菜单 → 图像与效果 → 替换选中图片…”。保留原对象的位置、尺寸、裁剪和效果区域。对窗口源执行此操作会改为普通静态图片，撤销可恢复原窗口源。
- **裁剪图片**：只选择一张可编辑、未锁定的图片，再点击主工具条导入与截图后方的“裁剪”，拖出保留范围。未选、多选、图文混选或图片锁定时按钮禁用，不会在空选时裁剪截图背景。原图片资源保留，裁剪可撤销。窗口源会打开独立的源内容裁剪窗口，使用下节的规则。
- **模糊／马赛克**：从“更多”选择工具并拖出区域。在实时画布上，区域持续处理下方桌面及更低图层的浮绘对象，即使已选中图片也按屏幕区域处理；可移动、缩放、旋转并保存到工程。移动区域后会处理新位置的内容。冻结截图和图片中的对应效果仍为静态处理。
- 旧工程中的实色效果继续显示；不再提供创建实色工具的入口。图片效果随目标图片变换。

实时模糊和马赛克需要 Windows 10 2004（内部版本 19041）或更新版本，以可靠排除浮绘自身窗口。应用最低系统基线仍为 Windows 10 1607。较早系统新建这两种桌面区域时，使用操作时的静态截图效果并显示说明；已有动态区域用实色占位并提示，原对象保持不变。冻结截图和图片效果不受此版本门槛影响。

新建实时滤镜时先准备有效画面，成功后才添加对象；准备期间隐藏、切换工具、离开浮绘或修改文档会取消添加。隐藏画布停止采集，重新显示时先沿用同一画布的最后有效画面，再替换为新帧；切换文档或显示布局后不复用旧缓存。采集失败时提示原因，有兼容缓存则保留最后画面，否则用实色覆盖。

动态区域按桌面新帧更新，采集目标跟随显示刷新率、最高 60 FPS；实际速度取决于区域大小、设备和系统调度，不能保证与下层应用逐帧同步。导出、复制为图片或合并印章取操作时的快照，工程中的动态区域保持可编辑；效果和区域变换可撤销。

**外部截图兼容：**系统支持会话级窗口排除时，实时滤镜仅在浮绘自己的采集中排除浮绘界面，其他截图软件仍可捕获可见的标注。应用根据实际接口能力选择采集方式；不支持时使用兼容采集，并在状态屏提示画布可能不会出现在第三方截图中。兼容采集期间，需要完整合成时可使用浮绘内的导出，或删除、隐藏所有动态区域后再截图。此机制不表示 Windows 截图的窗口识别限制已解决。

## 窗口源（实验性）

使用“主菜单 → 窗口源 → 添加窗口源…”，在列表中搜索并选择目标窗口，再预览完整画面、拖出需要保留的区域，或选择“使用完整画面”。列表只展示窗口信息，选择后才准备画面；取消不会创建图层。普通模式下插入当前编辑层级，立牌模式下还需在画布上确定放置位置；高级等深线流程仍可使用。

窗口源是可移动、旋转、缩放和调整透明度、边框的图片图层，显示所选窗口的持续画面。初始尺寸按源内容比例适配可见画布，默认等比容纳；源窗口改变尺寸或长宽比时，目标图层框保持不变，必要时留白。它只显示画面，不向源窗口转发画布点击或键盘输入。

单选一张未锁定的真实窗口源图层，可在属性或“窗口源”菜单中使用以下操作：

| 操作 | 效果 |
| --- | --- |
| 重新绑定窗口 | 明确选择一个窗口替换来源；即使名称相同，也建立新的绑定。保留目标位置和尺寸，可一步撤销 |
| 裁剪源内容 | 始终基于完整源画面重新选择范围，目标图层框保持不变。工程仍保留完整源画面，便于以后重新裁剪 |
| 冻结为普通图片 | 将当前可用画面及裁剪、等比容纳和图片效果合成为静态图片，保留图层位置、尺寸、透明度和可编辑边框；一步撤销可恢复窗口源 |

“暂停源／继续源”只改变本次运行状态，暂停时保留最后画面，不增加撤销步骤。多选真实窗口源可一起暂停、继续或冻结；重新绑定与裁剪要求单选。共享实例显示来源摘要；要修改源内容，请进入共享定义编辑。同一定义的多个实例共用一个窗口源，各自保留放置与变换。

属性会显示实时、暂停、源窗口最小化、已关闭或捕获不可用等状态。隐藏画布、没有可见引用或源窗口最小化、隐藏时暂停采集；可恢复时继续，源窗口关闭后需重新绑定。最多同时显示 **4 个不同实时源**，超出时显示保存画面并提示。实际可用性取决于系统和目标应用，受保护内容或部分窗口可能无法捕获。

保存工程、恢复文件和预制体会保留来源描述与可用的完整离线画面，裁剪不会从这些文件中删除源画面的其他区域。实时帧不会逐帧加入撤销记录或标记内容修改。重新打开、恢复工程或将内容带到另一个工程后，不会按标题自动连接窗口；先显示保存画面，需明确“重新绑定窗口”。需要分享当前可见结果时，可导出图片或冻结为普通图片。画布截图可使用此前实际显示的一帧；没有可用实时帧时使用保存画面。

## 截图与原位静像

点击工具条的截图工具，或使用“主菜单 → 画布 → 截图”。先在实时画面上选择范围，完成后才采集该时刻的内容，并将一张静态图片按原位置、原尺寸插入当前画布。不会切换到另一张画布，范围外的桌面继续实时显示。

再次选择截图工具可打开参数板，设置选区形状、内容来源和可选边框。默认为矩形、只截背景、不加边框；这些设置和当前预设会随工具状态保存。

| 选区形状 | 操作 |
| --- | --- |
| 矩形／圆形 | 按住鼠标自由比例拖动，松开完成；按住 `Shift` 临时约束为正方形／正圆，释放即恢复自由比例 |
| 自由套索 | 按住鼠标沿轮廓拖动；按住 `Shift` 拉直当前段，松开 `Shift` 继续曲线，松开鼠标自动闭合 |
| 多边形套索 | 单击逐个添加顶点，移动鼠标预览下一条边，`Shift` 约束八方向；回到起点单击、双击或 `Enter` 完成，`Backspace` 撤回最后一个顶点 |

“圆形”是圈选方式的名称，自由比例时可以圈选椭圆，并不强制为正圆。旧工具状态或个人预设中的等比值不再约束截图创建，也不会在读取时改写旧文件；创建好的图片图层仍可在属性中独立开启等比缩放。

透视开启、放置方式为贴面时，矩形和圆形选区是画布平面上的形状，圈选预览会随平面投影；关闭透视后截图内容的轮廓恢复为对应矩形或椭圆。自由／多边形套索始终沿屏幕上的鼠标轨迹圈选。立牌截图默认保留屏幕框选范围和捕获像素，仅反算图像逻辑宽高；边框使用逻辑线宽，预览粗细随最终接地点变化。高级流程可先固定等深线。模糊强度、马赛克采样等屏幕单位属性不随此规则换算。

新建的透视贴面截图，选择框按截图轮廓在画布平面上的最小外接矩形计算，并包含可见的外描边；无描边矩形截图的选框与截图范围重合。截图文件为保存倾斜区域而产生的透明角落不会扩大选框。此轮廓随工程、内部复制和裁剪保留；旧截图未记录轮廓时仍沿用原图片范围。

截图不会因单击而创建默认大小的图片；没有面积的选区不会插入对象。套索交叉时按奇偶规则填充，跨越轮廓的次数为偶数的区域保留透明。

| 内容来源 | 图片包含什么 |
| --- | --- |
| 仅背景 | 下层桌面及应用，不含浮绘标注和工具界面 |
| 背景＋画布 | 下层画面与当前可见的浮绘内容合成为一张图片 |
| 仅画布 | 只截浮绘自身内容，保留透明通道 |

三种来源都排除工具条、面板、选框和圈选提示。非矩形选区外保持透明；仅画布模式下，动态滤镜取当前画面，其余空白仍透明。若结果完全透明，会提示选区内没有内容，不插入不可见图片。

选区使用黑白轮廓预览，不会先冻结整个桌面。正在选择时按 `Esc` 只取消本次选区，继续编辑；没有进行中的操作时，`Esc` 仍按通用规则关闭面板或进入穿透。取消、空选区或采集失败不会清空已有内容。系统保护区域可能无法采集，届时会提示。

新图片自动选中，截图工具保持启用，便于继续截取。可以直接移动、旋转、缩放、裁剪或删除图片，也可一步撤销插入。从已选中对象内部开始新选区时，按住 `Ctrl`，避免变成调整该对象。可选边框写入图片，之后随图片整体变换。

采集背景时，浮绘保留当前编辑和输入状态，并从结果中排除自己的界面；必要时，部分界面会短暂隐藏，完成后恢复。不会为了截图先退出再进入绘制。每次都重新采集当前桌面，不复用上一次截图；画面静止时也无需先移动鼠标或改变内容。

采集失败不会清空已有内容；只要仍在浮绘中正常编辑，就会保留编辑状态。切换到其他应用、主动退出编辑、隐藏画布或切换／修改当前画布会取消正在进行的采集，不插入迟到的图片，也不会抢回前台。意外失败会提示诊断日志的位置，便于排查原因。

原有标注始终保留。选择“背景＋画布”或“仅画布”得到的是静态副本；透明内容与原标注原位重叠时，颜色可能加深。截图不会随下层应用继续变化。保存工程会保留这张可编辑图片；选中后复制可取得截图，或通过文件菜单导出画布的合成结果。

旧版的独立冻结截图工程和历史草稿仍可打开、编辑和导出。旧草稿在进入穿透时保留，并切回实时画布。

关联文件时，工具条上方显示文件名气泡，未保存修改显示独立的“未保存”标识，悬停可查看完整路径。气泡随工具条折叠隐藏；右键菜单依次提供“还原改动”“打开文件所在位置”，分隔线下方为“取消文件关联”。“还原改动”从关联文件重新载入上次保存的内容，无未保存改动时置灰；还原作为一步撤销记录，可按 Ctrl+Z 回到还原前，按 Ctrl+Y 重做。取消关联保留当前内容和撤销记录，之后作为未命名画布编辑。

### 新建、清空和历史版本

工具条灰色空白页加号用于新建画布并解除文件关联，默认恢复第一个官方画布预设；“新建时保留画布参数”开启时沿用当前参数。工具条、菜单和 Ctrl+N 共用新建确认：未绑定文件且有新绘制内容时，再执行一次新建确认，随后正常归档，不再弹保存框；空画布、未修改的历史副本、已保存且无修改的工程均一次新建。已绑定工程有修改时只弹“保存／不保存／取消”。“不保存”不写工程文件，但仍按历史设置归档；“取消”留在当前画布。打开其他工程仍保留保存保护。右侧红色扫把立即清空绘制对象，保留背景、网格、校准及文件关联；无需确认，不推入历史，可用 Ctrl+Z 撤销。清空后的工程只有再次保存才更新磁盘文件。

历史按进入画布时的内容判断新版本，在切换、新建或退出时归档。临时画布自动保留；工程编辑后即使保存过，离开时仍记录最终版本。仅打开未编辑、纯空白（包括只改画布参数）和重复内容不新增。恢复得到未命名副本，不自动覆盖原工程；只查看不改变旧条目时间和排序，继续编辑后再形成新的置顶版本。后台自动恢复独立保存空状态。

设置中的“历史版本上限”默认为 60，接受 0–1000 的整数，滑动条覆盖 0–200。0 表示不保留历史版本。保存设置或新增历史时移除超出上限的最旧版本；当前画布的恢复数据和故障隔离备份不计入。历史是有限容量的本地记录，长期保留请保存工程。

印章提示中的预览按图像本身的比例展示。带透视实时效果的印章使用保存时的截图缩略图，可能与平面中的标称宽高不同；预览不会拉伸，必要时分别显示水平和竖直比例。

## 保存工程、导出和恢复

ZIP 版和当前用户安装在普通启动时为当前用户注册 `.floatcanvas` 打开方式；系统安装由安装器注册所有用户可用的打开方式。也可在设置中点击“注册 .floatcanvas 打开方式”。双击工程，或在 Windows“打开方式”中选择浮绘，即可打开文件；应用已运行时会把文件交给同一实例，并保留替换前的保存确认。Windows 已有的默认应用选择不会被覆盖；如需默认使用浮绘，请在“打开方式”中选择“始终”。移动便携目录后，先从新位置运行一次以更新文件关联路径；登录启动需要重新确认路径。命令行也支持 `FloatCanvas.exe "工程.floatcanvas"` 或 `FloatCanvas.exe --open "工程.floatcanvas"`。

未运行浮绘时，双击工程会启动浮绘、打开工程并进入编辑模式。已运行时，打开工程保持当前模式：编辑中通过 `Ctrl+O` 或菜单打开后继续编辑；穿透中双击工程只切换画布，保持穿透。成功打开工程会自动显示画布并打开小眼睛；取消或打开失败保留原来的显隐状态。

| 操作 | 得到什么 | 之后能否继续编辑对象 |
| --- | --- | --- |
| 保存／另存工程 | `.floatcanvas` 文件，包含当前画布、原图片和效果 | 可以；使用“打开工程”重开 |
| 导出合成图片 | 背景、标注和图片合成的 PNG／JPEG | 结果是图片；当前工程仍可编辑 |
| 导出透明标注 | 只有标注和图片的透明 PNG | 结果是图片；当前工程仍可编辑 |
| 选中对象后复制 | 浮绘内可编辑对象，同时提供通用图片 | 在浮绘内粘贴继续编辑；其他软件通常取得图片 |

新截图作为图片随当前画布保存；旧版独立截图草稿仍分别保留。导出不会清空当前内容。工程保存原图以便再次编辑；需要分享处理后的结果时使用导出的合成图片。

工程使用独立于软件版本号的格式版本，工程、恢复和预制体包当前为 **v20**；可打开旧 **v1～v19** 工程并在内存中迁移，读取不重写原文件。工程保存组层级、局部变换、组级显隐、锁定、不透明度和层序、共享定义与实例及子工程离线快照，以及独立的平面宽高、透视网格格长与原点、背景、非透视网格、透视、钉点、普通模式平移和图层放置，包括立牌锚点、离地高度及组合／共享实例的整体立牌放置；键盘图层保留显示样式与自定义布局，旧键盘区域迁移为原有按键日志。窗口源保留来源描述与离线画面，不保存当前窗口连接。旧画布迁移直接保留矩阵与原有钉点，不重新校准内容；旧组合保留原有交错遮挡。缺少放置标记时按贴面处理，旧遮挡字段保留兼容，但本次运行的预览开关不写入工程。保存写入 v20，旧版应用会拒绝该格式，以免静默丢失三根画布归属、独立预览配置或逐层键盘采集范围；需要交换旧版工程或降级时请保留原文件。

浮绘会在提交编辑后约 1 秒保存恢复数据，退出前等待恢复保存完成。正常启动仍为空白画布；从“主菜单 → 文件 → 恢复历史画布…”选择最近或更早的工作区，可以一起恢复实时画布和截图草稿。恢复成功、取消或失败均保留发起时的编辑／穿透模式；中途切到其他应用或主动退出编辑时，不会再抢回前台。撤销历史不跨重启保留。

历史列表显示保存时间和画布缩略图，便于区分同名记录。缩略图保存浮绘自身的透明标注图层，不采集桌面背景，也不包含工具条或选择控制点。没有预览的旧历史会按需生成；无法生成时显示“暂无预览”，不妨碍恢复。

默认数据位置：

“主菜单 → 系统与调试”可以打开安装目录或当前用户数据目录。设置、工具状态、工具预设、画布预设和颜色配置会兼容读取未知字段及枚举；缺失、无法解析或越界的字段在内存中使用默认值，其余配置保持可用。正常读取不会改写文件，之后修改其他设置也会保留未知字段和未更改的原始值，便于切换版本。旧序号工具预设会保留原来的图形颜色与白色文字。

如果 JSON 损坏、存在重复字段或结构无法安全读取，启动时可选“退出”保留全部文件，或“备份并修复配置”。修复会先将上述五类配置复制到当前用户数据目录的 `configuration-backups` 时间戳子目录，再仅重置出错文件；任一备份失败便停止修复。正常使用中，只有保存确实需要替换当前版本无法读取的原值时，才另行提示备份确认；取消会保留原文件。工程、画布、印章和恢复数据不会重置。完整技术错误保存在日志中。

- 设置：`%LOCALAPPDATA%\FloatCanvas\settings.json`
- 最近恢复：`%LOCALAPPDATA%\FloatCanvas\recovery\workspace.floatcanvas`
- 前代恢复：`%LOCALAPPDATA%\FloatCanvas\recovery\workspace.previous.floatcanvas`
- 历史画布：`%LOCALAPPDATA%\FloatCanvas\recovery\history`
- 工具预设：`%LOCALAPPDATA%\FloatCanvas\tool-presets.json`
- 画布预设：`%LOCALAPPDATA%\FloatCanvas\canvas-presets.json`
- 各工具当前状态与选中预设：`%LOCALAPPDATA%\FloatCanvas\tool-state.json`
- 颜色历史与我的色板：`%LOCALAPPDATA%\FloatCanvas\colors.json`
- 印章库：`%LOCALAPPDATA%\FloatCanvas\stamps`
- 运行诊断：`%LOCALAPPDATA%\FloatCanvas\diagnostics.log`
- 未处理异常：`%LOCALAPPDATA%\FloatCanvas\errors.log`

遇到疑似错误时，请记下发生时间和操作步骤，并保留 `diagnostics.log`；发生未处理异常时也保留 `errors.log`。可在资源管理器地址栏输入 `%LOCALAPPDATA%\FloatCanvas` 找到它们。日志自动记录采集方式、准备和取帧阶段、选区边界、显示信息、取消／失败原因、版本与异常堆栈；相关输入附带类别、时间及是否被本应用抑制，可区分按键尾流与真正外部操作。日志不保存按键内容、连续鼠标轨迹、画布图像或标注正文，异常信息可能包含文件路径。每类日志最多保留当前文件及 `.1`、`.2` 两个旧文件，每个不超过 1 MiB；自定义 profile 的日志保存在对应目录。

手动恢复时，如果所选工作区的最新数据损坏，会尝试其前代；读取失败会提示并保留原文件。空白启动后尚未编辑便退出，不会用空白覆盖之前的恢复内容。恢复数据用于找回最近工作，重要内容仍应保存为自己的工程文件。

关闭工具条或返回穿透不会退出软件。需要结束运行时，使用系统托盘或“主菜单 → 退出浮绘”。默认不开机自启。

## 操作方式、提示与个人资源

浮绘以鼠标绘画和选取为主，快捷键用于加快操作。应用内不使用 `Tab`／`Shift+Tab` 遍历按钮和表单控件，也不追加键盘焦点虚框；`Tab` 保留展开／收起工具条的作用。Windows 系统文件对话框仍使用原生键盘导航。Windows 高对比度启用时，界面跟随系统窗口、文字和选中颜色；普通浅色／深色偏好在关闭高对比度后继续使用。预设和印章槽以边框显示当前项，不叠加勾号；基于选中预设改动参数后，在选中框右上角内侧显示与边框同色的三角封角，保持预览图标完整。错误同时显示文字及警示符号。

工具预设、画布预设和“我的色板”的新建、删除、覆盖、重命名和排序，与画布编辑共用当前画布的操作历史，按实际操作顺序使用 `Ctrl+Z` 撤销、`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做，也可使用工具条及编辑菜单的撤销／重做。切换到另一画布后使用该画布的历史；历史不跨应用重启保留。撤销新建会移除该预设，重做可恢复；撤销色板更改不影响最近使用的颜色。颜色输入框、预设命名框等文字编辑区域优先使用本地文字撤销。名称不能为空或只含空格，修正前保存按钮不可用。

没有可撤销／重做的内容，或对象选择不满足命令要求时，相应操作不可用，悬停可查看原因。混合选择包含锁定对象时，属性面板显示锁定数量，并说明需先解锁这些对象才能编辑属性。文字所用字体未安装时，字体栏保留原名称并说明实际替代字体；选择已安装字体才会替换原设置。

点击工具条状态屏，可阅读并复制本次运行中最近 20 条完整消息。关闭 Windows 界面动画时，长消息不再自动滚动。历史列表和印章库按可见区域加载预览；印章库继续连续滚动，空库、无搜索结果、加载失败各有说明和后续操作。工具参数和画布设置缩窄时，预设区移到参数下方。

## 帮助、诊断与卸载

“主菜单 → 帮助”提供随程序附带的离线用户指南、快捷键和“报告问题”。报告问题先显示版本、系统信息及填写提示；只有点击“打开反馈页面”才打开浏览器，不会自动发送或上传内容。

从“主菜单 → 系统与调试 → 导出诊断包…”先预览即将导出的版本、系统、运行模式和脱敏日志，也可取消包含日志。确认后选择本地 ZIP 保存位置；应用不自动上传。附给维护者前仍应检查包内信息。诊断包不包含画布、工程、印章或设置文件；原始日志继续留在用户数据目录。

**安装版**：先退出浮绘，再从 Windows“已安装的应用”中卸载。卸载器按当前文件清单清理程序文件、快捷方式、安装登记，以及仍指向本安装的登录启动和文件打开方式注册；ZIP 更新新增的程序文件也包含在清理范围中。它不接管或删除其他版本拥有的注册，也不改变 Windows `UserChoice`。

清理由卸载器本身执行，不再依赖 .NET 或应用宿主。清理失败会列出未完成项目，请处理占用或权限问题后重试；卸载器不会把部分失败报告成完整成功。

**个人资料默认保留。** 卸载界面按账户和完整目录列出已找到的默认资料，只有主动勾选并再次确认，才删除相应目录中的配置、预设、印章和画布历史。系统安装可分别选择已发现的用户资料，不会自动删除所有账户的数据。资料可能与 ZIP 版共用，删除前请退出所有浮绘实例并备份重要内容。另存到其他位置的作品、程序目录中的非程序文件、自定义 `--profile` 目录均保留。静默卸载默认保留资料；显式 `/DELETEUSERDATA` 只请求删除执行卸载的账户的默认资料，不代表删除所有用户数据。

**ZIP 版**：删除程序目录前，先退出浮绘，在该目录运行 `FloatCanvas.exe --unregister-integration`，移除属于此安装的当前用户启动项和文件打开方式注册。命令完成后可删除这个程序目录。

ZIP 版的取消注册命令保留其他安装的注册、Windows `UserChoice` 和用户资料；删除程序目录也不会自动删除 `%LOCALAPPDATA%\FloatCanvas`。若正在使用自定义 `--profile`，资料位于指定目录。

从源码开发构建需要 **.NET SDK 10.0.402** 或仓库 `global.json` 允许的后续补丁，以及 **Visual Studio C++ Build Tools**（含 MSVC 和 Windows SDK），用于构建原生组件。普通用户运行已发布包只需前文所述桌面运行时。ZIP 与 EXE 安装包均无签名，不需要配置发布密钥或代码签名证书；下载与更新仍校验 SHA-256、文件大小及包结构。

## 支持范围与限制

最低系统基线为 **Windows 10 1607（内部版本 14393）x64**，包含 LTSB 2016、LTSC 2019、LTSC 2021，亦面向 Windows 11 x64。应用不再以 Windows 10 22H2 作为启动门槛；较新系统专有功能单独降级或提示，不阻止基本绘图功能启动。

需安装该系统可用的 **.NET 10 Windows Desktop Runtime x64**，并保持系统与运行时更新。应用的最低版本基线与微软官方支持承诺不同；微软的支持范围还取决于具体 Windows 版本、版本类型及生命周期，详见 [.NET 10 支持平台](https://github.com/dotnet/core/blob/main/release-notes/10.0/supported-os.md)。当前实测仍主要在 Windows 11，较早 Windows 10／LTSB／LTSC 尚待实机确认，源码检查与兼容分支测试不能替代这些设备上的实际验收。

新配置默认全部屏幕，也可选择仅主屏；完整跨屏、混合 DPI、竖屏、热插拔、锁屏恢复及双 4K 体验仍在完善。不同设备和应用的表现可能有所差异。

浮绘面向普通桌面与全屏应用，不要求统一改成窗口化或无边框；具体全屏兼容性取决于应用和显示方式，不保证所有独占全屏场景。

系统打开／另存为文件框使用 Windows 自身的输入与前台；关闭或取消后返回浮绘编辑。弹出文件框时，部分游戏可能离开全屏。

使用 Windows 截图工具或其他截图软件的窗口吸附功能时，绘图层可能成为截图目标。需要保留标注时，可使用浮绘自己的截图或导出功能；只需要下层应用画面时，可先按“隐藏画布／显示画布”快捷键（默认 `` Ctrl+Shift+` ``）隐藏画布，截图后再显示。穿透模式不会隐藏标注；画布显隐保持当前编辑／穿透状态，按编辑／穿透切换快捷键可另行切换输入方式。

HDR 色彩准确性、压感笔、触控、OCR、录屏、滚动截图、云同步和上传不在当前版本范围内。

透视画布导航沿画布平面的X、Y方向平移，屏幕上的方向与远近变化由四边形决定，四角校准本身不变。图层窗口顶部统一切换独立/根工程视图，完整面包屑可逐层返回；内部工程退出层级时自动提交，无需完成或取消按钮。顶部固定三排：标题、定位到已选与图标式视图切换、画布图标菜单与面包屑、组信息与操作。前景、背景从画布图标菜单选择。

### 图层范围与整理

图层列表逐层显示组合内容。路径栏使用统一外框；点击父级返回，点击当前项或省略入口展开完整导航菜单。菜单中的原图标带深度角标，并区分父级、当前位置和历史上展开过的深层。返回上层会保留同一分支的深层入口；进入另一分支后替换旧的深层记录。图层路径栏也显示可继续进入的历史层级，主文件条只显示当前路径。删除、移动或清空使当前路径失效时，所有路径显示及设置目标自动回到最近有效父级或对应根画布，失效的深层记录会被移除；新建画布重置导航记录。列表中的左方向键或 Backspace 返回父级。图层面板内 Esc 只取消改名、拖动或弹出界面，之后关闭面板；不会退出普通组或应用共享草稿，再次打开仍保留原位置、选择与显示模式。

标题栏的拨动控件将当前模式图标放在强调色拨片上，图标随拨片左右移动；另一侧保留中性图标。点击整个控件的任意位置均切换“独立画布／工程预览”。独立画布仅显示当前范围；工程预览显示完整工程并仅编辑当前范围。文件条用精简图标标签显示模式，悬停或打开菜单可查看完整模式名称；导航菜单顶部以单行提供模式切换，分隔线下列出图层路径。工程文件收起为图标时，图标右上角内侧的黄色圆点表示未保存改动，展开时仍显示“未保存”标签。前景或背景画布在路径前显示单独的“返回主画布”图标按钮。关闭图层窗口后，仍可从文件条查看当前位置并导航；浮绘主菜单不重复列出导航项。

右键菜单可批量显隐、锁定和解锁；行内眼睛与锁仍只作用于该行。批量操作跳过祖先锁定或已处于目标状态的对象，并可一步撤销。显示所选不会自动显示隐藏祖先。使用“移动到…”可搜索目标名称或完整路径；同画布可移入普通组，跨画布仅可移到前景、主、背景根层级。跨画布保留逻辑坐标，透视外观可能变化。移动后留在来源位置，使用“查看目标”跳转；撤销、重做、文档切换或目标失效时旧入口失效。拖动长列表时，在上下边缘停留会自动滚动。

正常外链显示“外部链接 · 只读”；源缺失时显示“源文件不可用 · 使用保存快照”。转为内嵌保留工程内共享关系，解除则成为普通组；这些操作不写回外部源文件。浏览菜单打开后，再次点击原按钮重置视图；Esc 或点击菜单外只关闭菜单。


### 图层整理与只读浏览

图层窗口底部常驻显示总计、本级和已选数量。总计包含当前编辑文档三个画布中的图形、普通组和共享实例（每个实例计为一层）；本级仅统计当前列表的直接子层。操作结果与数量统计分开显示。

锁定组合可以进入查看、浏览路径和切换预览；锁定范围内不能修改内容。锁定共享实例以只读方式打开，解锁后重新进入才能编辑。图层眼睛表示自身显隐，继承隐藏标识及提示说明哪一级祖先隐藏了内容；独立预览可能仍显示这些内容。

“移动到…”支持目标路径搜索。移动后留在来源层级，“查看目标”在无关图层改名或显隐后仍可使用；撤销重做、文档切换或目标失效会清除入口。外链源无法读取或格式不可用时，使用有效保存快照只读浏览；可通过“重试源文件”重新读取，浏览不自动更新工程快照或写回源文件。

读取支持版本的工程时，无法识别的图层类型或图片效果会被忽略，其余内容仍可编辑；再次保存时不再写入被忽略内容。已移除的旧实色遮盖效果也采用这一规则。

### 跨层整理与校准反馈

跨层选择的删除、显隐、锁定、排序、编组和移动按整个有效选择集执行，不受图层列表当前浏览位置影响。锁定项按操作权限跳过；自身锁定不阻止自身显隐或解锁。排序仍在各自绘制上下文内进行。跨层编组在参与对象的最近共同父级建立新组，保持相对绘制顺序；收拢交错内容可能改变与未选对象的遮挡关系。

“移动到…”支持按名称和完整路径搜索。当部分选择已在目标时，全部可移动对象一起按相对顺序放到目标顶部；全部已在目标时不产生历史。移动后保留来源浏览位置及未处理项，通过“查看目标”主动前往。锁定组和共享实例允许只读浏览。

局部方格校准先检查候选网格对实际内容的安全性。检查中或不安全时恢复原画面，保留取样和填写的格数；只有安全候选可以应用。最终提交遇到暂时繁忙或拒绝时不会关窗，可调整后重试。边界对齐仅保证外框贴线，不保证整张背景的精度。扭正窗口的比例名称随实际尺寸及横竖方向更新。

跨层选择时，图层底部和批操作菜单会注明已选对象中有多少位于本层、多少位于其他层级。移动目标失效后，“刷新目标”在原窗口更新，保留搜索、展开和滚动位置；有效目标继续选中，失效目标需要重选。搜索结果以名称为主、父路径为辅；没有结果时可清空搜索返回浏览。

校准窗口分别展示“取样格数”和“整框推算”，并注明自动估计或已手动调整。修改取样格数会重新自动推算；可用“恢复自动估计”清除手动候选。校准不安全时，展开“查看受影响对象”可检查对象名称及路径，并临时在原画面标记受影响区域；这不会改变图层选择、编辑范围或画布视图。先尝试调整取样或格数；需要处理对象或对象在视野外时，取消校准后再定位。扭正窗口把“交换横竖方向”放在比例旁，“应用画布尺寸”只应用尺寸；“应用并加入截图”还会插入截图，详细规则见标题栏帮助。
